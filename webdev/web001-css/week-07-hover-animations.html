호버 효과와 애니메이션

Concept

:hover — mouse over

.btn:hover {
  background-color: red;
}

Style applies only when mouse is on top.

The : = "in this state".

마우스 올렸을 때만 적용

Concept

transition — smooth change

.btn {
  background-color: orange;
  transition: background-color 0.2s;
}
.btn:hover {
  background-color: red;
}

Without transition: snap. With: smooth fade. ✨

Concept

transform: scale()

.card:hover {
  transform: scale(1.05);
}

1.0 = original. 1.05 = 5% bigger. 0.9 = smaller.

Bouncy button

  background-color: #d4380d;
  color: white;
  padding: 12px 24px;

  border-radius: 8px;

  transition: transform 0.2s,
              background-color 0.2s;

.btn:hover {
  background-color: #b32d09;
  transform: scale(1.05);
}
Tune it

Transition speed

⚡
0.1s
snappy
👍
0.2-0.3s
just right
🐢
1s+
too slow

Sweet spot for buttons: 200ms.

More transforms

Other moves

scale(1.1)bigger
rotate(5deg)tilt
translateY(-4px)lift up
skew(5deg)slant
Bonus

Box shadow on hover

.card {
  box-shadow: 0 4px 12px rgba(0,0,0,.08);
  transition: box-shadow 0.2s,
              transform 0.2s;
}
.card:hover {
  box-shadow: 0 12px 24px rgba(0,0,0,.18);
  transform: translateY(-4px);
}

Card lifts up. Premium feel. ✨

⚠️ Watch

Don't animate everything

.card {
  transition: all 0.2s;  # 🚫 lazy
}

Be specific. all can transition unwanted properties → janky.

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
