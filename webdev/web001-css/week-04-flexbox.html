Code

Build a nav menu

.menu {
  display: flex;
  justify-content: center;
  gap: 24px;
  background-color: #1a3a52;
  padding: 16px;
}
.menu a {
  color: white;
  text-decoration: none;
}
⚠️ Watch

flex applies to parent

# 🚫 won't line up
.card { display: flex; }

# ✅ wrap them in a parent
.cards { display: flex; }
  <div class="card">...</div>
  <div class="card">...</div>

display:flex aligns the children inside.

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
