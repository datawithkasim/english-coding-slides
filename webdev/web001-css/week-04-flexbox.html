Code

Build a nav menu

.menu {
  display: flex;
  justify-content: center;
  gap: 24px;
  background-color: #1a3a52;
  padding: 16px;
}
.menu a {
  color: white;
  text-decoration: none;
}
⚠️ Watch

flex applies to parent

# 🚫 won't line up
.card { display: flex; }

# ✅ wrap them in a parent
.cards { display: flex; }
  <div class="card">...</div>
  <div class="card">...</div>

display:flex aligns the children inside.
