Concept

What is a tag?

An opening + a closing wrap content.

<h1>Hello!</h1>

<h1> = start. </h1> = end. / means close.

시작 태그 + 끝 태그

Tags

Most common tags

<h1>big heading
<h2>smaller heading
<p>paragraph
<img>image
Code

Your first page

<!DOCTYPE html>
<html>
<head>
  <title>About Me</title>
</head>
<body>
  <h1>Hi, I'm Minjun</h1>
  <p>I love games and drawing.</p>
</body>
</html>
Concept

head vs body

🧠
<head>
title, settings
(not visible)
👀
<body>
content
(visible on page)
Code

Adding an image

<img src="my-photo.jpg" alt="My photo">

<img> is self-closing — no </img>.

  • src — file name or URL
  • alt — text if image fails
⚠️ Watch

Don't forget the /

# 🚫 not closed
<h1>Hello

# ✅ closed
<h1>Hello</h1>

Browsers may guess but the page can break.
