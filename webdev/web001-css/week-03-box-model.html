Concept

Class selectors with .

# HTML
<div class="card">...</div>

# CSS
.card { ... }

Dot . = "any element with this class". Multiple cards = same style.

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
