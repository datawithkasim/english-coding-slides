Concept

What's a "hero" section? 🦸

The first thing visitors see.

Hi, I'm Minjun

A 12-year-old who loves coding ✨
Concept

background-image

.hero {
  background-image: url('bg.jpg');
  background-size: cover;
  background-position: center;
  height: 400px;
}

cover = fill the area, crop if needed. ✅

Concept

Center text with flexbox

.hero {
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: center;
  text-align: center;
  color: white;
}

Text centered both ways. Big & bold!

Concept

flex-direction = stack vertically

↔️
row
default — horizontal
↕️
column

Code

Full hero section

<div class="hero">
  <h1>Hi, I'm Minjun</h1>
  <p>Coding + games = my life</p>
</div>

.hero {
  background-image: url('bg.jpg');
  background-size: cover;
  height: 100vh;
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: center;
  color: white;
}
.hero h1 { font-size: 64px; }
Bonus

vh = viewport height

height: 100vh;  # full screen tall
height: 50vh;   # half screen

Hero takes the whole window on every device. 📱💻

Bonus

Image overlay for readability

.hero {
  background:
    /* dark layer */
    linear-gradient(rgba(0,0,0,.5), rgba(0,0,0,.5)),
    url('bg.jpg');
  background-size: cover;
}

Two backgrounds stacked → text always readable.

⚠️ Watch

Image path

# wrong path = no image, no error 🤫
url('bg.jpg')        # same folder
url('/images/bg.jpg') # subfolder

Check spelling + folder. No error message — just blank!

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.

🐛 Debug

The bug

Bug: justify-content only works on a flex (or grid) container. Without display: flex; it does nothing.
fixed
.row {
  display: flex;
  justify-content: center;
}
