⚠ Edge cases

Gotchas + pitfalls

Self-closing void tags
<img> and <br> have no closing tag in HTML5.
Specificity wars
Inline > #id > .class > tag. Stop adding !important.
Box-sizing default
Set box-sizing: border-box on everything or padding will lie.
Flex container ≠ items
Properties on the container vs the items — easy to mix up.
