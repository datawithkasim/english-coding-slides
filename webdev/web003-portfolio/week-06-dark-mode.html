Tool

classList.toggle()

document.body.classList.toggle("dark");

Class on? → remove it. Class off? → add it.

한 줄로 토글

Code

Toggle button

<button id="darkBtn">Dark Mode</button>

<script>
  const btn = document.querySelector("#darkBtn");

  btn.addEventListener("click", () => {
    document.body.classList.toggle("dark");

    if (document.body.classList.contains("dark")) {
      btn.textContent = "Light Mode";
    } else {
      btn.textContent = "Dark Mode";
    }
  });
</script>
Bonus

Remember user choice

// when toggling, save it
localStorage.setItem("theme",
  document.body.classList.contains("dark") ? "dark" : "light");

// on page load, restore it
if (localStorage.getItem("theme") === "dark") {
  document.body.classList.add("dark");
}

User's choice sticks on refresh!

Concept

localStorage

A tiny database in the browser.

  • Saves text values
  • Survives page refresh
  • Per site (each domain has its own)
