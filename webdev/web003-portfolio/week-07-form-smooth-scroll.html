Form handling + UX polish

연락처 폼 + 부드러운 스크롤

Tool

<form> tag

<form id="contactForm">
  <input type="text" id="name"
         placeholder="Name" required>

  <textarea id="msg"
            placeholder="Message" required></textarea>

  <button type="submit">Send</button>
</form>

required = browser blocks empty submit.

Concept

submit event

document.querySelector("#contactForm")
  .addEventListener("submit", function(event) {
    event.preventDefault();   // stop reload

    let name = document.querySelector("#name").value;
    let msg  = document.querySelector("#msg").value;

    console.log(name, msg);
    // show thank-you message
  });
Why

preventDefault() ?

By default, forms reload the page on submit.

For a fancy site → don't want that. Stop it with preventDefault().

⚠ Edge cases

Gotchas + pitfalls

Off-by-one is everywhere
range(10) gives 0–9, not 1–10.
Infinite loop
Forgot to update the condition in a while? Ctrl-C to exit.
Don't mutate during for
Modifying the list you're looping over is a common source of bugs.
break vs continue
break exits the loop. continue skips this iteration only.
