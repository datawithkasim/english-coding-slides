Hero rules

What makes a hero great?

  • Big, clear name
  • One-line tagline (under 10 words)
  • Plenty of space — don't cram
  • Optional: background image / gradient

Less is more.

Use 100vh for hero

Hero takes the whole window.

Visitors see ONLY hero before scrolling. Strong first impression.

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
