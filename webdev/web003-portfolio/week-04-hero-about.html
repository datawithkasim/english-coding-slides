Hero rules

What makes a hero great?

  • Big, clear name
  • One-line tagline (under 10 words)
  • Plenty of space — don't cram
  • Optional: background image / gradient

Less is more.

  color: white;
  display: flex;

  justify-content: center;

  text-align: center;
}

Mobile

Stack on small screens

@media (max-width: 600px) {
  #hero h1 { font-size: 40px; }
  #about { flex-direction: column; }
}

Hero text shrinks. About goes vertical. ✅

Tip

Use 100vh for hero

height: 100vh;

Hero takes the whole window.

Visitors see ONLY hero before scrolling. Strong first impression.

⚠️ Watch

Image file size

Big photos = slow page!

  • Resize photo to ~600px wide
  • Use .jpg for photos
  • Use .png for logos/transparent
