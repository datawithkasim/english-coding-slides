Publish

Option 1: Replit

The easiest:

  • Click "Run" in Replit
  • Copy the Webview URL
  • Send it to friends/parents 📲

URL looks like: your-name.repl.co

Publish

Option 2: GitHub Pages

  • Push code to GitHub
  • Settings → Pages → enable
  • Get URL: username.github.io/repo
  • Free forever 💪
