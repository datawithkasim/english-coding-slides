Tool

CSS Grid for galleries

.project-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 24px;
}

Magic: cards fill rows, wrap on small screens. Auto-responsive!

Decoded

repeat(auto-fill, minmax(...))

repeat(auto-fill, ...)
→ as many columns as fit
minmax(280px, 1fr)
→ at least 280px, share extra equally

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
