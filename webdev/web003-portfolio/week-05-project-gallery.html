Pokémon Pokédex

Tool

CSS Grid for galleries

.project-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 24px;
}

Magic: cards fill rows, wrap on small screens. Auto-responsive!

Decoded

repeat(auto-fill, minmax(...))

repeat(auto-fill, ...)
→ as many columns as fit
minmax(280px, 1fr)
→ at least 280px, share extra equally

Card CSS

.project-card {
  background: white;
  padding: var(--s2);
  border-radius: 12px;
  box-shadow: 0 4px 12px rgba(0,0,0,.08);
  transition: transform 0.2s;
}
.project-card:hover {
  transform: translateY(-4px);
}
.project-card img {
  width: 100%;
  border-radius: 8px;
}
Tip

What goes in cards?

  • Future ideas you'll build
