HTML 섹션 만들기

Concept

Semantic tags = meaning

<nav>menu
<section>page section
<header>top area
<footer>bottom area

Better than plain <div> — tells browser what the box is.

Concept

IDs = anchor links

<section id="about">...</section>

<nav>
  <a href="#about">About</a>
</nav>

Click "About" → page jumps to that section. Free with HTML!
