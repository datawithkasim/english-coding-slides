Tool

CSS variables

:root {
  --primary: #d4380d;
  --secondary: #1a3a52;
  --text: #333333;
}

h1 {
  color: var(--primary);
}

Define in :root. Use with var(). Change once → updates everywhere!

Concept

Spacing scale (multiples of 8)

:root {
  --s1: 8px;
  --s2: 16px;
  --s3: 24px;
  --s4: 32px;
  --s5: 48px;
}

Stick to these values. Never use 13px or 27px.

8의 배수로 통일

Code

Apply spacing variables

section {
  padding: var(--s4);
}

.menu {
  gap: var(--s2);
  padding: var(--s2);
}

h2 {
  margin-top: var(--s5);
}
Tool

Google Fonts

<head>
  <link rel="stylesheet"
        href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap">
</head>

<style>
  body { font-family: 'Inter', sans-serif; }
</style>

Free fonts from Google. Pick one and apply to body.

Tip

Pick fonts that pair

📰
Heading
Bold + display
e.g. Pretendard, Inter
📄
Body
Same font lighter weight
or simple sans-serif

One family is fine. Two = max.

Why?

Wins

  • Change palette once → whole site updates
  • Spacing always feels right
  • Looks designed, not just typed
  • Easy to maintain

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
