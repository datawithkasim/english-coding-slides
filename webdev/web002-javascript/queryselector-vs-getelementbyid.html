둘 다 요소 하나를 찾음

getElementById

The id — no #

let el = document.getElementById("hero");

Just the id name. No #, no dots. Only works with id.

id 이름만 — #없음

querySelector

A CSS selector — needs #

let el = document.querySelector("#hero");

Same as in CSS: # for id. The first match wins.

CSS처럼 #붙임

Superpower

querySelector takes any selector

document.querySelector("#hero");    // id
document.querySelector(".card");    // class
document.querySelector("button");   // tag

getElementById only does ids. querySelector does them all.

querySelector는 무엇이든 선택

⚠ Watch

The # trips people up

✅
Correct
getElementById("hero")
querySelector("#hero")
❌
Returns null
getElementById("#hero")
querySelector("hero")

Wrong # → JS finds nothing → null.

#을 잘못 쓰면 null
