Big idea

Both find one element

Same goal, different spelling.

🆔
getElementById
by id only
"hero"
🎯
querySelector
by CSS selector
"#hero"

둘 다 요소 하나를 찾음

getElementById

The id — no #

let el = document.getElementById("hero");

Just the id name. No #, no dots. Only works with id.

id 이름만 — #없음

querySelector

A CSS selector — needs #

let el = document.querySelector("#hero");

Same as in CSS: # for id. The first match wins.

CSS처럼 #붙임

Superpower

querySelector takes any selector

document.querySelector("#hero");    // id
document.querySelector(".card");    // class
document.querySelector("button");   // tag

getElementById only does ids. querySelector does them all.

querySelector는 무엇이든 선택

⚠ Watch

The # trips people up

✅
Correct
getElementById("hero")
querySelector("#hero")
❌
Returns null
getElementById("#hero")
querySelector("hero")

Wrong # → JS finds nothing → null.

#을 잘못 쓰면 null

Grab by id — set it up 🆔

Step 1 — HTML: give it an id

One name tag, two ways to grab it on the next slide.

id 하나, 잡는 방법은 두 가지

Follow along · A

Grab by id — two ways ⚡

Step 2 — JS: both find the same element

let el = document.getElementById("title");
// or the querySelector way:
let el = document.querySelector("#title");

el.textContent = "Hi!";

No # for id · # for the selector. Then change the text.

id는 #없이 · 선택자는 #붙임

Follow along · B

Grab by class — set it up 🏷️

Step 1 — HTML: a paragraph with a class

<p class="note">Read me</p>

Step 2 — CSS: style the class

.note { color: gray; }

클래스로 만들고 꾸미기

Follow along · B

Grab by class — make it react ⚡

Step 3 — JS: use a . for class

document.querySelector(".note").textContent = "Changed!";

. means class — just like in CSS. getElementById can't do this.

클래스는 점(.) — CSS와 똑같이

Follow along · C

Grab a tag — set it up 🔖

Step 1 — HTML: just a plain tag

No id, no class — we'll grab it by its tag name.

id·클래스 없이 태그 이름으로

Follow along · C

Grab a tag — make it react ⚡

Step 2 — JS: name the tag, no symbol

document.querySelector("button").textContent = "Click me";

No #, no . — just the tag. The first match wins.

기호 없이 태그 이름 · 첫 번째가 선택됨
