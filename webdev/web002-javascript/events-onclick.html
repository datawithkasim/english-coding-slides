Events
(onclick)

The user acts · your code reacts

사용자가 행동하면 코드가 반응

Big idea

An event is something the user does

JS can listen, then run code when it happens.

👆
click
press a button
⌨️
type
enter text
🐭
hover
move the mouse

이벤트 = 사용자의 행동

onclick

Run a function on click

<button onclick="sayHi()">Click me</button>

<script>
  function sayHi() {
    alert("Hi!");
  }
</script>

onclick names the function to run. The () calls it.

클릭하면 함수 실행

The function

Where the action lives

function sayHi() {
  let el = document.getElementById("msg");
  el.textContent = "You clicked!";
}

Click runs the function. The function changes the page.

함수 안에 할 일을 적음

Grown-up way

addEventListener

let btn = document.getElementById("go");
btn.addEventListener("click", sayHi);

Same idea, kept out of the HTML. Notice: sayHi with no () here.

HTML 밖에서 이벤트 연결

⚠ Watch

The () rule

✅
onclick
onclick="sayHi()"
call it — keep ()
⚠️
addEventListener
"click", sayHi
pass the name — no ()

In addEventListener, sayHi() runs it now by mistake. Pass sayHi.
