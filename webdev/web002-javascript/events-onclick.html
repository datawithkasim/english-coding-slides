Events
(onclick)

The user acts · your code reacts

사용자가 행동하면 코드가 반응

Big idea

An event is something the user does

JS can listen, then run code when it happens.

👆
click
press a button
⌨️
type
enter text
🐭
hover
move the mouse

이벤트 = 사용자의 행동

onclick

Run a function on click

<button onclick="sayHi()">Click me</button>

<script>
  function sayHi() {
    alert("Hi!");
  }
</script>

onclick names the function to run. The () calls it.

클릭하면 함수 실행

The function

Where the action lives

function sayHi() {
  let el = document.getElementById("msg");
  el.textContent = "You clicked!";
}

Click runs the function. The function changes the page.

함수 안에 할 일을 적음

Grown-up way

addEventListener

let btn = document.getElementById("go");
btn.addEventListener("click", sayHi);

Same idea, kept out of the HTML. Notice: sayHi with no () here.

HTML 밖에서 이벤트 연결

⚠ Watch

The () rule

✅
onclick
onclick="sayHi()"
call it — keep ()
⚠️
addEventListener
"click", sayHi
pass the name — no ()

In addEventListener, sayHi() runs it now by mistake. Pass sayHi.

addEventListener엔 괄호 없이

Practice
🛠️

Build these step by step

Follow along, then fly solo.

Every one is the same shape: 1) HTML — give it an id · 2) JS — onclick · 3) change it.

전부 같은 흐름: id → onclick → 바꾸기

Follow along · A1

Change text on click — set it up 💬

Step 1 — HTML: a button and a paragraph, each with an id

<button id="btn">Tap</button>
<p id="msg">Hello</p>

No CSS this time — JS will change the text for us.

버튼과 글자에 id만 붙임

Follow along · A2

Change text on click — make it react ⚡

Step 2 — JS: grab both, change the text on click

let btn = document.getElementById("btn");
let msg = document.getElementById("msg");

btn.onclick = () => {
  msg.textContent = "Clicked!";
};

클릭하면 글자가 바뀜

Follow along · B1

Toggle show / hide — set it up 🌗

Step 1 — HTML: name the box

<div id="box">Peekaboo</div>

Step 2 — CSS: a class that hides it

.hidden { display: none; }

HTML + CSS 먼저

Follow along · B2

Toggle show / hide — make it react ⚡

Step 3 — JS: flip the class on and off

let box = document.getElementById("box");

box.onclick = () => {
  box.classList.toggle("hidden");
};

toggle adds the class if it's off, removes it if it's on.

toggle = 있으면 빼고, 없으면 더함

Follow along · C1

Click counter — set it up 🔢

Step 1 — HTML: a button that shows a number

<button id="box">0</button>

It starts at 0. JS will count up from there.

버튼에 숫자 0부터 시작

Follow along · C2

Click counter — make it react ⚡

Step 2 — JS: keep a count, add 1 each click

let box = document.getElementById("box");
let count = 0;

box.onclick = () => {
  count = count + 1;
  box.textContent = count;
};

변수로 세서 버튼에 표시
