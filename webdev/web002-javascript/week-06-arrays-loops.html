배열과 반복문

Concept

What's an array?

let quotes = [
  "It's okay to mess up.",
  "Try again tomorrow.",
  "Small steps win."
];

Square brackets. Items separated by ,.

여러 값을 담는 리스트

Concept

Index starts at 0

console.log(quotes[0]);  // "It's okay..."
console.log(quotes[2]);  // "Small steps..."
console.log(quotes.length);  // 3

.length = how many items.

Random pick

Math.random()

Math.random()  // 0 to 1, like 0.7234

// pick a random index 0-2
let i = Math.floor(Math.random() * 3);

let picked = quotes[i];

Multiply by length → floor → integer index.

Concept

Math.floor()

Math.floor(2.7)  // 2
Math.floor(0.99) // 0

Round down to whole number. Always.

소수점 버리기 (내림)

Code

Quote of the day

document.querySelector("#btn").addEventListener("click", function() {
  let i = Math.floor(Math.random() * quotes.length);
  document.querySelector("#out").textContent = quotes[i];
});

Click → random quote shows.

Concept

for loop = repeat N times

for (let i = 0; i < quotes.length; i++) {
  console.log(quotes[i]);
}

Three parts: start — condition — step.
