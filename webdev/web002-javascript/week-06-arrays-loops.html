Math.random()

Concept

Math.floor()

Math.floor(2.7)  // 2
Math.floor(0.99) // 0

Round down to whole number. Always.

⚠ Edge cases

Gotchas + pitfalls

Off-by-one is everywhere
range(10) gives 0–9, not 1–10.
Infinite loop
Forgot to update the condition in a while? Ctrl-C to exit.
Don't mutate during for
Modifying the list you're looping over is a common source of bugs.
break vs continue
break exits the loop. continue skips this iteration only.

The bug
