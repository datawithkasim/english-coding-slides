What's an array?

let quotes = [
  "It's okay to mess up.",
  "Try again tomorrow.",
  "Small steps win."
];

Square brackets. Items separated by ,.

여러 값을 담는 리스트

Concept

Index starts at 0

console.log(quotes[0]);  // "It's okay..."
console.log(quotes[2]);  // "Small steps..."
console.log(quotes.length);  // 3

.length = how many items.

Random pick

Math.random()

Math.random()  // 0 to 1, like 0.7234

// pick a random index 0-2
let i = Math.floor(Math.random() * 3);

let picked = quotes[i];

Multiply by length → floor → integer index.

Concept

Math.floor()

Math.floor(2.7)  // 2
Math.floor(0.99) // 0

Round down to whole number. Always.

⚠ Edge cases

Gotchas + pitfalls

Off-by-one is everywhere
range(10) gives 0–9, not 1–10.
Infinite loop
Forgot to update the condition in a while? Ctrl-C to exit.
Don't mutate during for
Modifying the list you're looping over is a common source of bugs.
break vs continue
break exits the loop. continue skips this iteration only.
