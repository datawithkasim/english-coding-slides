if / else + comparisons

정답 판단

Concept

If this, do that

if (guess === 7) {
  alert("Correct! 🎉");
} else {
  alert("Wrong, try again.");
}

Two paths. Code chooses based on the test.

조건에 따라 다른 행동

Concept

Three or more paths: else if

if (guess < 7) {
  msg = "Bigger!";
} else if (guess > 7) {
  msg = "Smaller!";
} else {
  msg = "Got it! 🎉";
}

Top to bottom. First match wins.

Comparisons

Operators

===equal
!==not equal
>greater than
<less than
>=≥
<=≤
Concept

Combine with && and ||

// both must be true
if (age >= 10 && age <= 12)

// either works
if (color === "red" || color === "blue")

&& = AND. || = OR.

&& = 그리고, || = 또는

Code

Hidden number game

let secret = 7;

document.querySelector("#check").addEventListener("click", function() {
  let guess = Number(document.querySelector("#g").value);
  let result = document.querySelector("#result");

  if (guess === secret) {
    result.textContent = "Correct! 🎉";
  } else if (guess < secret) {
    result.textContent = "Try bigger";
  } else {
    result.textContent = "Try smaller";
  }
});
Bonus

Track tries

let tries = 0;

// inside the click function:
tries = tries + 1;
if (guess === secret) {
  result.textContent = "Got it in " + tries + " tries!";
}

Counter outside the function so it persists between clicks.
