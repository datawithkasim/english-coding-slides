if / else + comparisons

정답 판단

Concept

If this, do that

if (guess === 7) {
  alert("Correct! 🎉");
} else {
  alert("Wrong, try again.");
}

Two paths. Code chooses based on the test.

조건에 따라 다른 행동

Concept

Three or more paths: else if

if (guess < 7) {
  msg = "Bigger!";
} else if (guess > 7) {
  msg = "Smaller!";
} else {
  msg = "Got it! 🎉";
}

Top to bottom. First match wins.

Comparisons

Operators

===equal
!==not equal
>greater than
<less than
>=≥
<=≤
Concept

Combine with && and ||

// both must be true
if (age >= 10 && age <= 12)

// either works
if (color === "red" || color === "blue")

&& = AND. || = OR.

&& = 그리고, || = 또는

Code

Hidden number game

let secret = 7;

document.querySelector("#check").addEventListener("click", function() {
  let guess = Number(document.querySelector("#g").value);
  let result = document.querySelector("#result");

  if (guess === secret) {
    result.textContent = "Correct! 🎉";
  } else if (guess < secret) {
    result.textContent = "Try bigger";
  } else {
    result.textContent = "Try smaller";
  }
});
Bonus

Track tries

let tries = 0;

// inside the click function:
tries = tries + 1;
if (guess === secret) {
  result.textContent = "Got it in " + tries + " tries!";
}

Counter outside the function so it persists between clicks.

⚠️ Watch

=== not =

// 🚫 sets value (always true)
if (x = 5) ...

// ✅ compares
if (x === 5) ...

Common bug. Always 3 equals to compare in JS.

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
