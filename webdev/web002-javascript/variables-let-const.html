Variables
let / const

Boxes that hold a value

값을 담는 상자

Big idea

A box with a name

Store a value, use it later by its name.

let name = "Minjun";
let age = 12;

이름 붙인 상자에 값 저장

let

let — can change

let score = 0;
score = score + 1;   // now 1
score = score + 1;   // now 2

let = "I'll let this change later."

let = 나중에 바뀔 수 있음

const

const — stays the same

const pi = 3.14;
const school = "English Coding";

const = constant. Set once, never reassigned.

const = 고정, 안 바뀜

Which one?

Pick by: does it change?

🔄
let
value will change
score, count, name
🔒
const
value stays fixed
pi, maxLives

Tip: start with const. Switch to let only if you must change it.

바뀌면 let, 고정이면 const

⚠ Watch

Can't reassign a const

✅
let changes
let x = 1;
x = 2; ✔
❌
const errors
const y = 1;
y = 2; → error

Reassigning a const stops your program with an error.

const 재할당하면 에러
