Inside <script> tags. Usually at end of body.

Tool 1

console.log() — for you

console.log("button was clicked");

Prints to the browser console (F12 → Console tab).

For debugging. User doesn't see it.

Tool 2

alert() — for users

alert("Hello, friend!");

Shows a popup to the user. They click OK to dismiss.

사용자에게 메시지

Concept

Functions group code

function sayHello() {
  alert("Hello!");
}

Define once. Use sayHello() to run it.

함수로 코드 묶기

Code

Button → action

<button onclick="sayHello()">Click</button>

<script>
  function sayHello() {
    alert("Hello!");
  }
</script>

onclick = "when clicked, run this function".

⚠️ Watch

Semicolons + curly braces

function sayHi() {   # open brace
  alert("Hi");  # end with ;
}                      # close brace

JavaScript loves curly braces {} and semicolons ;.

Tip

Open the console!

Press F12 in Chrome → "Console" tab.

  • See your console.log() output
  • See errors in red
  • Type JS commands directly

Best friend for debugging.
