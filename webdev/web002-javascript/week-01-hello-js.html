사용자에게 메시지

Concept

Functions group code

function sayHello() {
  alert("Hello!");
}

Define once. Use sayHello() to run it.

함수로 코드 묶기

Code

Button → action

<button onclick="sayHello()">Click</button>

<script>
  function sayHello() {
    alert("Hello!");
  }
</script>

onclick = "when clicked, run this function".

⚠️ Watch

Semicolons + curly braces

function sayHi() {   # open brace
  alert("Hi");  # end with ;
}                      # close brace

JavaScript loves curly braces {} and semicolons ;.

Tip

  • See your console.log() output
  • See errors in red
  • Type JS commands directly

Best friend for debugging.

⚠ Edge cases

Gotchas + pitfalls

== vs ===
Always use === (strict equality). == does weird type coercion.
var vs let vs const
Use const by default, let if you'll reassign. Never var.
this is weird
this changes meaning by call site. Arrow functions inherit this.
Async ≠ parallel
async/await is concurrent, not multi-core.

What's wrong with this code?

buggy
const items = ['a', 'b', 'c'];

  setTimeout(() => console.log(items[i]), 100);

🐛 Debug

The bug

Bug: var isn't block-scoped, so i is shared across timeouts — they all log undefined. Use let instead.
fixed
const items = ['a', 'b', 'c'];
for (let i = 0; i < items.length; i++) {
  setTimeout(() => console.log(items[i]), 100);
}
