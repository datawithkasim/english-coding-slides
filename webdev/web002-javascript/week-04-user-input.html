⚠ Edge cases

Gotchas + pitfalls

input() returns str
Even if user types '7', it's the string '7'. Cast with int(input(...)) to do math.
Name = case sensitive
hp and Hp are different variables. Pick a style and stick to it.
Snake_case in Python
PEP 8: player_name, not playerName or PlayerName.
Re-assign freely
x = 5 then x = 'hello' is legal. Python infers the type from the value.

The bug

Bug: input() always returns a string. Comparing a string to a number with > raises TypeError. Cast with int(input(...)).
fixed
age = int(input('Age? '))
if age > 18:
    print('adult')

Coding practice

Ask the user for a number. Keep asking until they type a valid one. Then print it.
starter
while True:
    raw = input('Number? ')
    try:
        n = int(raw)
        break
    except ValueError:
        print('Not a number — try again.')

print(f'You typed {n}')
