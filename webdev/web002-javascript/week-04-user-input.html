Tool

The <input> tag

<input id="nameBox"
       type="text"
       placeholder="Your name">

A box where users can type. Always self-closing.

Tool

Get the value with .value

let name = document.querySelector("#nameBox").value;
console.log(name);

.value = whatever the user typed.

.value로 입력값 가져오기

Code

Greet with their name

<input id="nameBox" placeholder="Name">
<button id="greetBtn">Greet</button>
<h1 id="output"></h1>

<script>
  document.querySelector("#greetBtn").addEventListener("click", function() {
    let name = document.querySelector("#nameBox").value;
    document.querySelector("#output").textContent = "Hi, " + name;
  });
</script>
Concept

Empty input check

if (name === "") {
    alert("Please enter your name!");
} else {
    output.textContent = "Hi, " + name;
}

Validate before using. No empty greetings!

빈 값 처리

Concept

=== = strict equal

name === ""     // strict (recommended)
name == ""      // loose (avoid)

Three equals = "exactly the same". Use this in JS!

JS에서는 ===를 쓰세요

⚠️ Watch

Numbers come as strings

let raw = document.querySelector("#age").value;
// raw = "12" — a STRING, not a number!

let age = Number(raw);
// age = 12 — now a number ✅

Wrap with Number() for math.
