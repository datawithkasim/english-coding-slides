함수로 정리

Concept

What's a function?

A reusable block of code with a name.

function greet() {
  alert("Hello!");
}

greet();
greet();

Define once. Call as many times as you want.

Concept

Parameters — pass info in

function greet(name) {
  alert("Hello, " + name);
}

greet("Minjun");
greet("Kasim");

name changes each call. Same code, different result.

Concept

return — pass info out

function add(a, b) {
  return a + b;
}

let total = add(3, 5);
console.log(total);  // 8

return sends a value back to whoever called.

Code

Calculator

<input id="a" type="number">
<input id="b" type="number">
<button onclick="showSum()">Add</button>
<p id="result"></p>

<script>
  function add(x, y) { return x + y; }

  function showSum() {
    let a = Number(document.querySelector("#a").value);
    let b = Number(document.querySelector("#b").value);
    document.querySelector("#result").textContent = add(a, b);
  }
</script>
Why?

Functions = power

  • Less typing — write once, reuse
  • Easier to debug — find bug in one place
  • Code reads like English
  • Build big things from small pieces
Bonus

Arrow function shortcut

// classic
function add(a, b) { return a + b; }

// arrow (modern)
const add = (a, b) => a + b;

Both work. Arrow is shorter for tiny functions.

⚠️ Watch

Define ≠ run

function hi() {
  alert("hi");
}
// nothing happens — never called

hi();  // ✅ now it runs

Need () at the end to actually call.

⚠ Edge cases

Gotchas + pitfalls

Mutable default trap
Never use def f(x=[]). Use x=None + check inside.
Forgot return?
No return statement = returns None. Easy to miss when tired.
self first
Inside a class method, first param is always self — Python passes it automatically.
Don't shadow builtins
Avoid list = [1,2,3] — you just broke list() for the rest of the file.
