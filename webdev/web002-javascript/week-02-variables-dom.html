What's the DOM?

A map of every HTML element.

JS can grab any element and change it.

DOMDocument Object Model

JS가 HTML 요소를 조종

Tool

document.querySelector()

<h1 id="greeting">Hello</h1>

let el = document.querySelector("#greeting");

#greeting = element with id="greeting".

id로 요소 선택

Tool

.textContent — change text

let el = document.querySelector("#greeting");
el.textContent = "Hi from JavaScript!";

Set the text. Page updates instantly.

Code

Click → change heading

<h1 id="greeting">Hello</h1>
<button onclick="change()">Change</button>

<script>
  function change() {
    let name = "Minjun";
    let el = document.querySelector("#greeting");
    el.textContent = "Hi, " + name + "!";
  }
</script>
Concept

String concat with +

"Hi, " + name + "!"
// → "Hi, Minjun!"

+ joins strings together.

Bonus: backticks `Hi, ${name}!` are even cleaner.

⚠ Edge cases

Gotchas + pitfalls

input() returns str
Even if user types '7', it's the string '7'. Cast with int(input(...)) to do math.
Name = case sensitive
hp and Hp are different variables. Pick a style and stick to it.
Snake_case in Python
PEP 8: player_name, not playerName or PlayerName.
Re-assign freely
x = 5 then x = 'hello' is legal. Python infers the type from the value.
