Code

Build a counter

<h1>Score: <span id="score">0</span></h1>
<button id="plus">+1</button>

<script>
  let score = 0;
  let scoreEl = document.querySelector("#score");

  document.querySelector("#plus").addEventListener("click", function() {
    score = score + 1;
    scoreEl.textContent = score;
  });
</script>
Bonus

Add a reset

document.querySelector("#reset").addEventListener("click", function() {
    score = 0;
    scoreEl.textContent = score;
});

Two buttons, same score variable.

Bonus

Stop at zero

document.querySelector("#minus").addEventListener("click", function() {
    if (score > 0) {
        score = score - 1;
        scoreEl.textContent = score;
    }
});

Add if → only decrease when score > 0.

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
