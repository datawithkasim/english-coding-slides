if / else

Run code only when it's true

조건이 맞을 때만 실행

Big idea

Code that decides

Check a condition. True → do this. False → skip or do that.

iftrue 일 때만 실행
else그 외에는

조건에 따라 갈라짐

if

Do it only when true

let score = 12;

if (score > 10) {
  alert("You win!");
}

The { } code runs only if the condition is true.

참이면 { } 실행

else

Otherwise, do this

if (score > 10) {
  alert("You win!");
} else {
  alert("Try again");
}

else catches every other case. One of the two always runs.

아니면 else 실행

else if

More than two paths

if (score > 90) { grade = "A"; }
else if (score > 80) { grade = "B"; }
else { grade = "C"; }

Checked top to bottom. The first true one wins.
