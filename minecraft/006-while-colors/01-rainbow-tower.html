Concept

Every while loop needs three blocks

set level to 0
while level < 6 do
fill this level
change level by 1
1
Start. Give the counter a first value.
2
Check. The question in the while slot.
3
Change. The counter has to move.

Miss block 3 and the loop never ends.

no ending.

Common mistake 2

Right block, wrong slot

Dropped inside the if branch:

if level = 0 then
fill Red Wool …
change level by 1

Only level 0 is red, so only that branch runs. The counter moves once, then stops.

Correct, after the whole if:

if level = 0 then
fill Red Wool …
change level by 1

The change block sits at the bottom of the while, lined up with the if.

Colour

The loop paints. The if picks.

if level = 0 then
fill Red Wool …
else if level = 1 then
fill Orange Wool …
else if level = 2 then
fill Yellow Wool …

Each turn level holds a new number, so a different branch runs.

Fill the while slot

🎯 Your job: build the yes/no question and drop it in the empty slot.

1. Logic → find the compare block 0 < 0.

Build · step 4

The fill block, and the important drag

🎯 Your job: put level into the middle number of both positions.

1. Blocks → drag fill inside the while loop.
2. Type the six numbers: -3, 0, -15 and 3, 0, -9.
3. Variables → drag level on top of each 0 in the middle. That is the height.
fill Red Wool from ~ -3 ~ level ~ -15 to ~ 3 ~ level ~ -9 with Replace

The middle number is Y. Y is height. Because level climbs, every turn paints higher up.

Build · step 5

Six colours, one if block

🎯 Your job: wrap the fill in an if, then add 5 more branches.

1. Logic → drag if then else inside the while, above the fill.
2. Move the fill block inside the if part.
3. Condition: level = 0. Change the sign from < to =.
4. Click the + on the if block four times. That adds four else if branches.
5. Right-click the fill block → Duplicate. Drop one copy in each branch.
6. Change each copy's colour dropdown, and each branch's number: 1, 2, 3, 4. Last one is else.
0 Red
1 Orange
2 Yellow
3 Lime
4 Purple
else Pink
