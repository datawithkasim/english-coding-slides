How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Concept

The three-step pattern

1 · EVENTplayer walks somewhere
2 · CHECKwhat block is there?
3 · ACTIONdoor opens / trap fires

이벤트 → 확인 → 행동

Concept

Event + check together

def on_walk():
    if agent.inspect(DOWN) == GOLD_BLOCK:
        player.say("Welcome to my world!")
player.on_travelled(on_walk)

Event fires every step — the check decides if the action runs.

이벤트는 매번, 행동은 조건이 맞을 때만

Concept

Action can be a function

def spring_trap():
    agent.place(AIR, DOWN)
    player.say("You fell in my trap!")

def on_walk():
    if agent.inspect(DOWN) == RED_CARPET:
        spring_trap()
player.on_travelled(on_walk)

행동을 함수로 깔끔하게 정리해요
