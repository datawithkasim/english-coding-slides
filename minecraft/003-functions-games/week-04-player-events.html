Concept

What's an event?

Code that runs by itself when the player does something.

def on_walk():
    if agent.inspect(DOWN) == GOLD_BLOCK:
        player.say("Treasure room!")
player.on_travelled(on_walk)

No typing — it fires every time the player walks.

What's wrong with this code?

Goal: the reward fires once on the start tile — but it floods diamonds.

buggy
def on_walk():
    if agent.inspect(DOWN) == REDSTONE_BLOCK:
        agent.place(DIAMOND_BLOCK, DOWN)
player.on_travelled(on_walk)

It fires on every step on redstone.

🐛 Debug

The bug

Bug: nothing remembers the reward was given, so it repeats. Use a flag variable.
fixed
reward_given = False
def on_walk():
    global reward_given
    if agent.inspect(DOWN) == REDSTONE_BLOCK and not reward_given:
        agent.place(DIAMOND_BLOCK, DOWN)
        reward_given = True
player.on_travelled(on_walk)
