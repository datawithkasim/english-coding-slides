How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Concept

Loop a function call

def on_dungeon(rooms):
    for i in range(rooms):
        build_room()
        agent.move(FORWARD, 6)
player.on_chat("dungeon", on_dungeon)

Type dungeon 3 → 3 rooms, each 6 apart.

반복이 함수 호출을 여러 번 실행해요

Concept

Randomness makes it feel alive

def on_towers(count):
    for i in range(count):
        build_tower(randint(3, 8))
        agent.move(FORWARD, 4)
player.on_chat("towers", on_towers)

Each tower gets a random height — no two the same.
