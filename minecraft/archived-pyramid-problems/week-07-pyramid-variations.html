Concept

Hollow = edges only

Place a block only when it's on the edge of the square.

Edge means: first row, last row, first column, or last column.

가장자리에만 블록을 놓으면 속이 빕니다

Code

The edge condition

if row == 0 or row == size-1 or \
   col == 0 or col == size-1:
    agent.place(DOWN)
agent.move(FORWARD, 1)

On the edge → place. In the middle → skip.

Code

Stepped — bigger steps

size = 9
while size > 0:
    build_layer(size)
    agent.move(UP, 1)
    size = size - 4   # 9 → 5 → 1: chunky steps

Change the step number → change the look. −4 = a stepped pyramid.

🐛 Debug

The fix

Bug: It places a block on every cell, so the layer is solid, not hollow. Add an if so it only places on the edge.
fixed
        if row==0 or row==size-1 or col==0 or col==size-1:
            agent.place(DOWN)
        agent.move(FORWARD, 1)
