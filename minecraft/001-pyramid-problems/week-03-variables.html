How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Concept

What is a variable?

A name that holds a value you can use later.

size5
height6

변수 = 값을 담는 이름표

Watch it!

The value flies into the box

5 ➡️ size5
range(size) # → 5 times

size에 5를 저장 → 어디서든 size 사용

Code

Use the variable in a loop

size = 5

for i in range(size):
    agent.place(DOWN)
    agent.move(FORWARD, 1)

The loop runs size times — here, 5.

Code

Change one number

# build a size-5 wall
size = 5

# now make it huge — change ONE line
size = 12
for i in range(size):
    agent.place(DOWN)
    agent.move(FORWARD, 1)

No retyping the loop — just edit size.

What's wrong here?

buggy
# goal: build a row of `size` blocks, size is 5
size = 5
for i in range(3):
    agent.place(DOWN)
    agent.move(FORWARD, 1)

Think first — then click next.

🐛 Debug

The fix

Bug: The loop uses the number 3, not the variable size. It builds 3 blocks, not 5. Put size inside range().
fixed
size = 5
for i in range(size):
    agent.place(DOWN)
    agent.move(FORWARD, 1)
