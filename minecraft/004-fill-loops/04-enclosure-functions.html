What changes between cage 1 and cage 2?

cage 1
blocks.fill(OAK_FENCE,
    pos( 0 , 0, 0),
    pos( 4 , 3, 4), FillOperation.HOLLOW)
cage 2
blocks.fill(OAK_FENCE,
    pos( 6 , 0, 0),
    pos(10 , 3, 4), FillOperation.HOLLOW)

Only the x numbers move. Everything else repeats.

So make x a blank

def make_cage(x: number):
    blocks.fill(OAK_FENCE,
        pos(x, 0, 0),
        pos(x + 4, 3, 4), FillOperation.HOLLOW)

Every orange x gets filled in when you call it.

Common mistake

The blank never gets used

broken
def make_cage(x: number):
    blocks.fill(OAK_FENCE,
        pos(1, 0, 1),
        pos(5, 3, 5), FillOperation.HOLLOW)
fixed
def make_cage(x: number):
    blocks.fill(OAK_FENCE,
        pos(x, 0, 1),
        pos(x + 4, 3, 5), FillOperation.HOLLOW)

Broken: all six cages stack in one spot.

Debug 1

Nothing appears. Why?

1def make_cage(x: number, z: number):
2    blocks.fill(OAK_FENCE,
3        pos(x, 0, z),
4        pos(x + 4, 3, z + 4), FillOperation.HOLLOW)
Answer

You defined the recipe and never called it. Add make_cage(0, 0).

Debug 2

The llama vanishes

1def make_cage(x: number, z: number):
2    mobs.spawn(LLAMA, pos(x + 2, 1, z + 2))
3    blocks.fill(OAK_FENCE,
4        pos(x, 0, z),
5        pos(x + 4, 3, z + 4), FillOperation.HOLLOW)
Answer

The llama spawns first, then the fill runs over it. Spawn last.

Debug 3

Cage 2 sits inside cage 1

make_cage(0, 0)
make_cage(2, 0)

The cage is 5 blocks wide, from x to x + 4.

Answer

2 is smaller than 5, so they overlap. Use 6 or more.
