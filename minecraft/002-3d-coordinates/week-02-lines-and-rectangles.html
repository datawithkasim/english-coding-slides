How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Put the numbers into Minecraft ⌨️

yup ↑
zforward ⤴

  • Open Code Builder (press C in the world)
  • Type the numbers in order — (x, y, z)

Concept

A loop repeats a step

Instead of placing 5 blocks by hand, a loop does it 5 times for you.

x = 0
repeat 5 times:
    place stone block at (x, 0)
    add 1 to x

한 칸씩 옮기며 같은 동작을 반복해요

Code

A line across (grow x)

for x in range(5):
    blocks.place(STONE, pos(x, 0, 0))

range(5) gives x = 0, 1, 2, 3, 4 — a line 5 blocks long, all at y = 0.

range(5) → x가 0부터 4까지

Code

A line up (grow y)

for y in range(4):
    blocks.place(GOLD_BLOCK, pos(3, y, 0))

x stays 3, y climbs 0 → 3. A tower-line 4 tall standing on the wall.

Code

Two edges at once

for x in range(6):
    blocks.place(STONE, pos(x, 0, 0))  # bottom
    blocks.place(STONE, pos(x, 4, 0))  # top

One loop, two lines: a bottom edge at y = 0 and a top edge at y = 4.

See it

Grow x → across · grow y → up

x를 키우면 가로선, y를 키우면 세로선이 돼요
