How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Concept

The three directions

xacross →
yup ↑
zforward ⤴

On the flat floor we keep y = 0 and move with x and z.

바닥은 y를 0으로 두고 x, z만 움직여요

Code

A path running forward (grow z)

for z in range(5):
    blocks.place(STONE, pos(2, 0, z))

x stays 2, y stays 0 (on the ground), z grows 0 → 4. A path going forward.

z가 자라면 앞으로 길이 생겨요

Code

Filling a whole floor

for z in range(3):        # 3 forward
    for x in range(4):    # 4 across
        blocks.place(STONE, pos(x, 0, z))

Inner loop runs x across, outer steps z forward: a floor pad 4 × 3.
