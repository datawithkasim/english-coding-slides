Big picture

Flat layers → tall world 🍄

🟫➡️🍄

You know the floor (x, z). New move: fill a flat slab, raise y, fill again.

바닥(x, z) 위에 fill 한 층씩 y를 올리면 입체가 돼요

How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x & z → walk on the ground to pick the spot (across + forward).
3y → the layer number. Add +1 to stack the next slab on top.

Each fill is one flat layer at one y. Order is always (x, y, z).

y는 층 번호 — +1 하면 다음 층이 위에 쌓여요

fill 블록 → from·to 두 모서리 → 둘 다 y가 같으면 한 층, y를 올리면 다음 층

Concept

One fill = one flat layer

Keep y the same in from and to → a flat slab. Bump y up by 1 → the next layer sits on top.

fill RED from (2, 2, 2) to (10, 2, 10)   # layer y=2
fill RED from (3, 3, 3) to (9,  3, 9)    # layer y=3

from·to의 y가 같으면 납작한 한 층, y를 +1 하면 그 위에 다음 층

Code

The stem: a small box up

fill with BROWN
   from (4, 0, 4)
   to   (8, 1, 8)  replace

From y = 0 up to y = 1 — a short brown stem 2 layers tall, ready for a cap.

y 0 → 1 까지 채우면 2층짜리 갈색 줄기(기둥)

See it

One spot (x, z) · stacked up (y)

바닥 격자(x, z) 위로 y가 솟아요 — 갈색 줄기를 쌓고 꼭대기에 빨간 모자를 올리면 버섯!

Code

A mushroom, layer by layer 🍄

# stem
fill BROWN from (4,0,4)  to (8, 1,8)
# cap — raise y each line, shrink the spread
fill RED   from (2,2,2)  to (10,2,10)
fill RED   from (3,3,3)  to (9, 3,9)
fill RED   from (4,4,4)  to (8, 4,8)
fill RED   from (5,5,5)  to (7, 5,7)

y climbs 2 → 5. Each layer is a little narrower → a round cap.

y가 2→5로 오르고, 층마다 좁아져서 둥근 모자가 돼요

Real code

The Python it makes 🐍

def on_run():
    blocks.fill(BROWN_CONCRETE,
        pos(4, 0, 4), pos(8, 1, 8),
        FillOperation.REPLACE)        # stem
    blocks.fill(RED_CONCRETE,
        pos(2, 2, 2), pos(10, 2, 10),
        FillOperation.REPLACE)        # cap, y = 2
    # ...3 more cap layers: y = 3, 4, 5
player.on_chat("run", on_run)

pos(x, y, z) is the spot · REPLACE overwrites what's there · type run in chat to build.

블록을 파이썬으로 보면 — pos(x, y, z)가 자리, REPLACE는 덮어쓰기. 채팅창에 run 입력

Concept

Terrain = layers of different height

Move along x. Give each spot a taller top y. Bumpy ground = terrain.

x를 따라가며 자리마다 꼭대기 y를 다르게 = 울퉁불퉁한 땅(지형)

Code

Build a slope of terrain

fill DIRT from (0,0,0) to (0,1,5)   # low
fill DIRT from (1,0,0) to (1,2,5)
fill DIRT from (2,0,0) to (2,3,5)
fill DIRT from (3,0,0) to (3,4,5)   # high

Each strip stops at a taller y — the ground rises into a hill.

줄마다 꼭대기 y가 더 높아져 언덕이 생겨요
