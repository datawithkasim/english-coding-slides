How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Type it in

Put the numbers into Minecraft ⌨️

xacross →
yup ↑
zforward ⤴
place STONE at (x, y, z)
  • Open Code Builder (press C in the world)
  • Type the numbers in order — (x, y, z)
  • Press Run ▶ — your block appears at that spot

코드 빌더(C) 열고 → (x, y, z) 순서로 숫자 넣고 → Run ▶

Concept

What is a nested loop?

A loop inside another loop. The inner one finishes a whole row before the outer one steps up.

한 줄을 다 그린 다음 한 칸 위로 올라가요

Concept

Inner vs outer

➡️
inner loop
grows x
(one row across)
⬆️
outer loop
grows y
(next row up)

안쪽 = 가로 한 줄, 바깥쪽 = 다음 줄

Code

A grid of red blocks

for y in range(2):        # 2 rows up
    for x in range(3):    # 3 across
        blocks.place(RED_WOOL, pos(x, y, 0))

3 blocks per row × 2 rows = 6 blocks total.

Code

A patterned row: red, yellow, red

for y in range(3):
    blocks.place(RED_WOOL, pos(0, y, 0))
    blocks.place(YELLOW_WOOL, pos(1, y, 0))
    blocks.place(RED_WOOL, pos(2, y, 0))

A yellow stripe runs straight up the middle (x = 1).
