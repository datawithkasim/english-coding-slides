How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Concept

What is a coordinate?

A coordinate is a block's address — two numbers: (x, y).

xhow far across →
yhow far up ↑

x = 가로 (옆으로), y = 세로 (위로)

Concept

Same x, different y

place gold block at (3, 0)
place gold block at (3, 5)

Both at x = 3, so they line up. Only y changed — one is 5 blocks higher.

x가 같으면 한 줄로 서고, y만 바뀌면 위아래로 떨어져요

Code

Placing a block in Python

blocks.place(GOLD_BLOCK, pos(3, 0, 0))
blocks.place(GOLD_BLOCK, pos(3, 5, 0))

The first number is x, the second is y (height). Same as (x, y) on the wall.

첫 번째 = x, 두 번째 = y

Code

Using a variable for y

# move the block up by changing y
y = 2
blocks.place(GOLD_BLOCK, pos(0, y, 0))
y = 6
blocks.place(GOLD_BLOCK, pos(0, y, 0))

Same x, but y goes 2 → 6, so the second block lands higher.
