세 숫자를 같이 주면 공간 어디든 — fill로 상자도 통째로

How to count

Count the axis — all three together 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right, +1 each block.
3y → jump up, +1 each block.
4z → walk forward, +1 each block.

Now you change all three at once. Order is always (x, y, z).

이제 셋을 동시에 바꿔요 — 순서는 늘 (x, y, z)

Type it in

Put the numbers into Minecraft ⌨️

xacross →
yup ↑
zforward ⤴
place GOLD_BLOCK at (2, 5, 3)
  • Open Code Builder (press C in the world)
  • Set all three numbers in order — (x, y, z)
  • Press Run ▶ — the block lands at that exact spot

코드 빌더(C) → (x, y, z) 세 숫자 → Run ▶ → 정확히 그 자리에

Concept

Place one block anywhere

place GOLD_BLOCK at (2, 5, 3)

x = 2 across, y = 5 up, z = 3 forward — all chosen together. With nothing under it, the block floats in the air.

세 숫자를 동시에 정하면 공중 어디든 놓여요

Concept

What is fill?

Give fill two corner coordinates — each a full (x, y, z). It fills everything between them. No loops.

fill stone from (0, 0, 0) to (4, 3, 4)

두 모서리 좌표(각각 x, y, z)만 주면 사이를 다 채워요

Concept

Solid → hollow

🧱
fill stone
solid box
(all stone)
💨
fill air
empties the inside
(now a room)

돌로 채우고, 안쪽은 공기(air)로 비워요

Code

A solid box

fill with STONE
   from (0, 0, 0)
   to   (4, 3, 4)  replace

Small corner first, big corner second. The middle number 3 is the height (y).

작은 모서리 먼저, 큰 모서리 나중에 — 가운데가 높이

Code

Hollow it out + cut a door

fill STONE from (0,0,0) to (4,3,4)  # solid box
fill AIR   from (1,1,1) to (3,2,3)  # hollow inside
fill AIR   from (2,1,0) to (2,2,0)  # doorway

Line 2 hollows the inside. Line 3 cuts a doorway from the floor up.
