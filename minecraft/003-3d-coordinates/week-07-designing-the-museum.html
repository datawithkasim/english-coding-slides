How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Type it in

Put the numbers into Minecraft ⌨️

xacross →
yup ↑
zforward ⤴
place STONE at (x, y, z)
  • Open Code Builder (press C in the world)
  • Type the numbers in order — (x, y, z)
  • Press Run ▶ — your block appears at that spot

코드 빌더(C) 열고 → (x, y, z) 순서로 숫자 넣고 → Run ▶

Concept

What is a blueprint?

A plan that lists every coordinate before you build — so nothing overlaps and each statue lands on its stand.

미리 좌표를 정해두면 겹치지 않아요

Concept

Each piece, its own coordinates

floor(x, z) flat
picture(x, y) on wall
pedestal(x, y, z) box

바닥은 (x,z), 그림은 (x,y), 받침대는 (x,y,z)

Code

Pedestal + statue on top

# pedestal fills up to height 1
blocks.fill(STONE, pos(2,0,2), pos(4,1,4), FillOperation.REPLACE)
# statue rests one block higher
blocks.place(GOLD_BLOCK, pos(3, 2, 3))

Stone ends at y = 1, so the statue sits at y = 2 — right on top.

Code

Two pedestals, no overlap

blocks.fill(STONE, pos(1,0,1), pos(2,1,2), FillOperation.REPLACE)
blocks.fill(STONE, pos(6,0,6), pos(7,1,7), FillOperation.REPLACE)

Different (x, z) footprints — one near front-left, one far back-right. They never crash.
