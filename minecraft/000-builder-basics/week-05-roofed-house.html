How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Type it in

Put the numbers into Minecraft ⌨️

xacross →
yup ↑
zforward ⤴
place STONE at (x, y, z)
  • Open Code Builder (press C in the world)
  • Type the numbers in order — (x, y, z)
  • Press Run ▶ — your block appears at that spot

코드 빌더(C) 열고 → (x, y, z) 순서로 숫자 넣고 → Run ▶

Concept

Go up first, then build the roof

A roof must sit on top of the walls — so the agent climbs up before placing it.

move up by 1
repeat 3 times:
    place block down
    move forward

Without move up, the roof lands on the floor.

먼저 위로 올라가서 지붕을 놓아요

Spot the difference

These should do the same thing — but one is buggy.

clean
repeat 4 times:
    place block down
    move forward
turn right
buggy
repeat 4 times:
    place block down
    move forward

🐛 Debug

The bug

Bug: in the buggy version turn right is indented, so it turns on every loop — the agent spins in a tiny circle instead of laying one straight side then turning once.

Indentation decides what's inside the loop.
