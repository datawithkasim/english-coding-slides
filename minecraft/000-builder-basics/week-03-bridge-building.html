How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Concept

What is a loop?

A loop repeats the same steps a number of times.

repeat 5 times:
    place block down
    move forward

The indented lines run 5 times → a 5-block bridge.

repeat 5 times = 5번 반복

Concept

Indent = inside the loop

➡️
indented
runs every loop
⬅️
not indented
runs once, after

들여쓰기한 줄만 반복돼요

Code

Blocks: a 5-block bridge

repeat 5 times:
    place block down
    move forward

Without a loop, that's 10 lines of code. With a loop, 3.

Code

The same loop in Python

for i in range(5):
    agent.place(DOWN)
    agent.move(FORWARD, 1)

range(5) = repeat 5 times. The indented lines are the body.

블록의 repeat 와 똑같아요
