Concept

Inside the loop = changes every time

height = 1
repeat 4 times:
    place block down
    move up by height
    move forward
    height = height + 1

Step 1 climbs 1, step 2 climbs 2, step 3 climbs 3… a staircase.

반복문 안에 있으니 매번 커져요

See it

Drag start and step 🪜

숫자가 커질수록 계단이 가팔라져요

Concept

It can shrink too

gap = 7
repeat 4 times:
    place block down
    move forward by gap
    gap = gap - 2
7531

Take away instead of adding, and the build gets tighter each time.

빼면 점점 좁아져요 — 경사 지붕이 이 방법이에요

Code

Blocks: a growing staircase

set height to 1
repeat 4 times:
    place block down
    move up by height
    move forward
    change height by 1

In Code Builder the change … by 1 block is the one that makes it grow.

change 블록이 숫자를 키워요

Code

The same idea in Python

height = 1
for i in range(4):
    agent.place(DOWN)
    agent.move(UP, height)
    agent.move(FORWARD, 1)
    height = height + 1
