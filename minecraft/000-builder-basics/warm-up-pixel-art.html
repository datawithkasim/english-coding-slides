Pixel Art

Count squares → fill the wall

칸 세고 → 벽 채우기

Big idea

The wall is graph paper 📐

X goes across →  Y goes up ↑

Y\X01234 2 1 0

Z is how deep the wall is — it never changes. Leave it alone.

X = 가로, Y = 세로, Z는 안 바뀜

Step 1

Read X — left → right 👉

Count the columns starting at 0: 0, 1, 2, 3 …

Y\X01234 1123 0

Red begins at X 1, ends at X 3.

왼쪽부터 칸 세기 — 시작 X, 끝 X

Step 2

Read Y — bottom → up 👆

Count the rows starting at 0: 0, 1, 2, 3 …

Y\X01 33 22 11 0

Red begins at Y 1, ends at Y 3.

아래부터 칸 세기 — 시작 Y, 끝 Y

Step 3

Every square has an address 📍

Always read it in order: X first → then Y

Y\X0123 2● 1 0

Count across: X = 3.  Then count up: Y = 2.  Address = (3, 2).

칸 주소 = (X, Y) · 항상 X 먼저, 그 다음 Y

The command

Put the address into fill

blocks.fill(YELLOW_WOOL,
   world(X, Y, Z),   # where the color starts
   world(X, Y, Z))   # where the color stops

 green  = the first two numbers → X first, then Y

 gray  = Z, the depth → always the same, leave it

앞 두 숫자 = X 먼저, 그 다음 Y · Z는 그대로

Example A

One square

Y\X012 2 1● 0

X first = 2, then Y = 1. One square → same address twice.

blocks.fill(YELLOW_WOOL, world(2,1,0), world(2,1,0))

한 칸 = 주소 두 번 똑같이

Example B

A row of one color ➡️

Y\X01234 2●●● 1

Fill the whole row at once: first square (1, 2) → last square (3, 2). Y stays 2.

blocks.fill(YELLOW_WOOL, world(1,2,0), world(3,2,0))

같은 색 한 줄 = 한 번에 채우기 · Y 그대로

Remember 🔑

One block thick = one number stays

➡️
row (1 tall)
Y is the same in both
⬆️
column (1 wide)
X is the same in both

Same number = correct, not a mistake.

한 칸 두께면 숫자 하나는 안 바뀜 — 맞는 거예요

PREDICT
Predict 🤔

What shape is this?

Predict first — then reveal
blocks.fill(YELLOW_WOOL, world(1,0,0), world(1,4,0))
Reveal
A column, 5 tall. X is 1 in both (same), Y goes 0 → 4. That is 5 squares.
