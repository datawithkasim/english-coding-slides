How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Type it in

Put the numbers into Minecraft ⌨️

xacross →
yup ↑
zforward ⤴
place STONE at (x, y, z)
  • Open Code Builder (press C in the world)
  • Type the numbers in order — (x, y, z)
  • Press Run ▶ — your block appears at that spot

코드 빌더(C) 열고 → (x, y, z) 순서로 숫자 넣고 → Run ▶

Concept

The place block command

The agent drops a block where you tell it: down, forward, or to a side.

place block down

This puts one block under the agent.

place block down = 발밑에 블록 놓기

Concept

Move + place = a trail

place block downdrop a block
move forwardstep ahead
move up by 1go up 1
repeat ↻do it again

놓고 → 이동 → 놓고 → 이동

Concept

Line vs stack

➡️
place + move forward
blocks in a line
⬆️
place + move up
blocks stacked tall

앞으로 가면 한 줄, 위로 가면 탑

Code

Blocks: a 3-block line

# place, step, place, step, place
place block down
move forward
place block down
move forward
place block down

3 blocks in a straight line on the ground.

Code

The same idea in Python

agent.place(DOWN)
agent.move(FORWARD, 1)
agent.place(DOWN)
agent.move(FORWARD, 1)
agent.place(DOWN)

DOWN = where the block goes (below the agent).
