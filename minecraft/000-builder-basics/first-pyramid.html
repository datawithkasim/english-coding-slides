First Pyramid

Stack shrinking squares.

Big picture

Layers that shrink 🔻

9️⃣→7️⃣→5️⃣→3️⃣→1️⃣

Each layer is a square, 2 smaller than the one below.

한 층씩 2칸 작아지며 위로

How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Concept

Why shrink by 2?

A pyramid narrows on both sides each layer — left and right.

Lose 1 block each side = size - 2 per layer. That keeps it centered.

양쪽에서 1칸씩 → 2칸 줄어듭니다

Concept

The while loop

while size > 0:
    build_layer(size)
    agent.move(UP, 1)
    size = size - 2

while repeats as long as the condition is true.

while = 조건이 참인 동안 반복

Code

The full pyramid

size = 9

while size > 0:
    for row in range(size):
        for col in range(size):
            agent.place(DOWN)
            agent.move(FORWARD, 1)
        agent.turn(RIGHT)
    agent.move(UP, 1)
    size = size - 2

The fix

Bug: size - 1 shrinks only one side, so the layers are not centered and it looks lopsided. A real pyramid loses a block on each side: size - 2.
fixed
    size = size - 2
