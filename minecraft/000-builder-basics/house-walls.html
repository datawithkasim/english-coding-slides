How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Type it in

yup ↑
zforward ⤴
place STONE at (x, y, z)
  • Open Code Builder (press C in the world)
  • Type the numbers in order — (x, y, z)
  • Press Run ▶ — your block appears at that spot

코드 빌더(C) 열고 → (x, y, z) 순서로 숫자 넣고 → Run ▶

Concept

A wall has length and height

Long loop builds across. Tall loop builds up.

repeat 10 times:
    place block down
    move forward

This is a flat wall 10 long on the ground.

길이 + 높이 = 벽

Concept

Nested loop = a loop inside a loop

repeat 10 times:       # 10 columns
    repeat 10 times:   # 10 tall each
        place block down
        move up by 1
    move forward

Inner loop = one tall column. Outer loop = move along 10 times.

안쪽 반복이 기둥, 바깥 반복이 길이

Concept

How many blocks?

10 long× 1 tall = 10
10 tall× 1 wide = 10
10 × 10= 100 blocks
nestedmultiplies!

for col in range(10):
