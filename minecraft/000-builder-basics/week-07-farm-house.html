How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Concept

What is a variable?

A variable is a name that stores a number. Change it once, and every loop that uses it changes too.

set size to 3
set height to 2

size remembers 3. height remembers 2.

변수 = 숫자를 담는 이름표

Concept

Use the variable in the loop

set size to 3

repeat 4 times:
    repeat size times:
        place block down
        move forward
    turn right

Change size to 5 and the whole house grows — no other edits.

size 하나만 바꾸면 전체가 커져요

Code

Variables in Python

size = 3

for side in range(4):
    for step in range(size):
        agent.place(DOWN)
        agent.move(FORWARD, 1)
    agent.turn(RIGHT_TURN)

range(size) uses the variable. Change size, change everything.
