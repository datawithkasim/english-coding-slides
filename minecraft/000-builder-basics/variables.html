Concept

What is a variable?

A variable is a name that holds a number.

length = 5

Now the name length holds 5. Wherever you write length, the computer reads 5.

변수 = 숫자를 담아 두는 이름

Concept

Set it first, then use it

1️⃣
length = 5
give the name a number
2️⃣
repeat length times
use the name

Order matters. Use a name before you set it and the agent builds nothing.

값을 먼저 정하고, 그다음에 써요

See it

Drag the number, watch the build 🧱

length = 5
repeat length times: place block down, move forward

한 줄만 바꿔도 다리 길이가 바뀝니다

Concept

One name, two walls

length = 6
repeat length times:
    place block down
    move forward
turn right
repeat length times:
    place block down
    move forward

Both sides use length. Change the first line to 9 and both sides grow.

이름 하나로 두 벽을 함께 바꿔요

Code

Blocks: a path with a variable

set length to 5
repeat length times:
    place block down
    move forward

In Code Builder, drag Variables → set, name it length, then drop the name into the repeat.

Variables 서랍에서 set 블록을 꺼내요

Code

The same idea in Python

length = 5
for i in range(length):
    agent.place(DOWN)
    agent.move(FORWARD, 1)

range(length) reads the number inside the name.
