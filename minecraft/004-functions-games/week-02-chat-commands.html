Concept

What's a chat command?

Code that runs when you type a word in the chat box.

def on_bridge():
    for i in range(6):
        agent.place(PLANKS, FORWARD)
        agent.move(FORWARD, 1)
player.on_chat("bridge", on_bridge)

Type bridge → the agent builds a bridge.

단어를 입력 → 코드 실행

Concept

Commands can take a number

def on_tower(n):
    for i in range(n):
        agent.place(STONE, FORWARD)
        agent.move(UP, 1)
player.on_chat("tower", on_tower)

Type tower 4 → n becomes 4. tower 8 → taller!

명령어에 숫자를 함께 보낼 수 있어요

Concept

Pass the number into a function

def build_tower(height):
    for i in range(height):
        agent.place(STONE, FORWARD)
        agent.move(UP, 1)

def on_tower(n):
    build_tower(n)
player.on_chat("tower", on_tower)
