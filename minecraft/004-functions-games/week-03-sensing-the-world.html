How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

yup ↑

Concept

agent.detect — look ahead

Ask the agent: is something blocking the way?

if agent.detect(DETECT_BLOCK, FORWARD):
    agent.turn(LEFT_TURN)
else:
    agent.move(FORWARD, 1)

Wall ahead? Turn. Path open? Walk on.

앞에 막혀 있으면 돌고, 아니면 전진

Concept

agent.inspect — what's below?

if agent.inspect(DOWN) == LAVA:
    agent.place(STONE, DOWN)
    agent.move(FORWARD, 1)
else:
    agent.move(FORWARD, 1)

Lava below? Cover it first, then move. Safe? Just move.
