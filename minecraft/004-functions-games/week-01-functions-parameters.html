Concept

What is a function?

A named block of steps you can reuse as many times as you want.

def build_tower():
    agent.place(STONE, FORWARD)
    agent.move(UP, 1)

Define once. build_tower() runs it again and again.

한 번 정의 → 여러 번 호출

Concept

A parameter — an input

A parameter is a number the function uses inside.

def build_tower(height):
    for i in range(height):
        agent.place(STONE, FORWARD)
        agent.move(UP, 1)

height changes each call — same code, different tower.

매개변수 = 함수가 안에서 쓰는 입력값

Concept

return — give an answer back

A function can give back a value instead of building.

def count_steps(distance):
    return distance + 2

steps = count_steps(4)
player.say(steps)   # 6

return = 값을 돌려주기
