How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Concept

What is a piston?

A piston pushes a block when it gets a redstone signal. A sticky piston can also pull it back.

lever ON  → piston pulls block → path opens
lever OFF → piston pushes back  → path closes

신호가 있으면 열리고, 끊기면 닫혀요

Concept

Only flip when there's a gap

if agent.detect(BLOCK, FORWARD):
    agent.interact(FORWARD)   # power the piston
else:
    agent.move(FORWARD, 1)

Interact only at the blocked spot — not on every step.

막힌 곳에서만 레버를 작동시켜요

Code

Power, then cross

agent.move(FORWARD, 1)
agent.interact(FORWARD)   # piston opens the gap
agent.move(FORWARD, 2)   # cross while it's open

Cross before the signal turns off and the bridge vanishes.

Code

Loop across the maze

while not agent.detect(BLOCK, DOWN):
    if agent.detect(BLOCK, FORWARD):
        agent.interact(FORWARD)
        agent.move(FORWARD, 1)
    else:
        agent.move(FORWARD, 1)

At a gap → power + cross. On solid ground → just walk.
