How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Concept

Place + move = a line of blocks

for i in range(5):
    agent.place(DOWN)
    agent.move(FORWARD, 1)

Drop a block, step forward, repeat 5× → a 5-long wall.

블록 놓고 한 칸 이동하기를 반복

Concept

A conditional decides each spot

if on_edge or on_top_layer:
    agent.place(DOWN)
else:
    # leave it empty (air)
    pass

Edges and the top get a block; the inside stays hollow.

가장자리와 윗면만 블록을 놓아요

Code

Fill a layer, then go up

for layer in range(5):
    fill_layer()
    agent.move(UP, 1)

Finish the whole layer before moving up — order matters.

한 층을 다 채운 뒤에 위로 올라가요

Code

Break a hole and climb out

# make the hole FIRST, then move into it
agent.destroy(UP)
agent.move(UP, 1)

Carve the block above, then climb. Never the other way around.

먼저 구멍을 뚫고 그다음에 올라가요
