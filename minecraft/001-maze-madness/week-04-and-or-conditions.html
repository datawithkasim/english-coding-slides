Concept

or — either one is enough

A or B is true when at least one side is true.

no wall ahead or no wall below
# True if EITHER path is open

Only false when both sides are false.

하나만 참이어도 전체가 참

Code

OR to keep moving

if not agent.detect(BLOCK, FORWARD) or \
   not agent.detect(BLOCK, DOWN):
    agent.move(FORWARD, 1)

Move if the front or the way below is clear.

앞 또는 아래가 열려 있으면 전진

Code

AND and OR in one loop

while not agent.detect(BLOCK, DOWN):
    if agent.detect(BLOCK, FORWARD) and agent.detect(BLOCK, RIGHT):
        agent.turn(LEFT_TURN)
    elif not agent.detect(BLOCK, FORWARD) or not agent.detect(BLOCK, LEFT):
        agent.move(FORWARD, 1)
    else:
        agent.turn(RIGHT_TURN)

Corner → turn left. Open front or left → move. Else → turn right.
