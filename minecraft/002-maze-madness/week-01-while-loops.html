Concept

What is a while loop?

It repeats the body again and again while a condition is true.

while no wall ahead:
    move forward

Check → run → check again. Stop the moment it's false.

Code

Detect the wall

# True when a block is right in front
agent.detect(AgentDetection.BLOCK, FORWARD)

agent.detect(...) answers a yes/no question: is there a block ahead?

앞에 벽이 있는지 알려줘요

Code

Move until the wall

while not agent.detect(AgentDetection.BLOCK, FORWARD):
    agent.move(FORWARD, 1)

not flips it: loop while there is NO wall ahead.
