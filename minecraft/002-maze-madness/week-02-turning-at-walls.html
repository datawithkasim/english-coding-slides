Concept

if / else — pick a branch

The agent asks one question, then runs one of two paths.

if wall ahead:
    turn right
else:
    move forward

Only one branch runs each time — never both.

조건에 따라 둘 중 하나만 실행돼요

Code

The turning rule

if agent.detect(AgentDetection.BLOCK, FORWARD):
    agent.turn(RIGHT_TURN)
else:
    agent.move(FORWARD, 1)

Wall in front → spin right. Clear → take one step.

벽이면 오른쪽으로, 아니면 한 칸 전진

Code

Repeat it to solve the maze

while not agent.detect(AgentDetection.BLOCK, DOWN):
    if agent.detect(AgentDetection.BLOCK, FORWARD):
        agent.turn(RIGHT_TURN)
    else:
        agent.move(FORWARD, 1)

A while loop wraps the rule so it runs again and again.

Concept

Choosing a turn with elif

direction = "right"

if direction == "left":
    agent.turn(LEFT_TURN)
elif direction == "right":
    agent.turn(RIGHT_TURN)
else:
    agent.move(FORWARD, 1)

elif = "else, if instead…". Checked only if the first was false.
