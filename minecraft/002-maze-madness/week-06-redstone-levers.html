How to count

Count the axis — one block, one number 🧭

1Stand on the start block — that spot is (0, 0, 0).
2x → walk right. Add +1 for every block.
3y → jump up. Add +1 for every block.
4z → walk forward. Add +1 for every block.

Say them in order every time: (x, y, z) = across, up, forward.

한 칸 움직이면 +1 — 오른쪽 x, 위로 y, 앞으로 z. 순서는 늘 (x, y, z)

Type it in

Put the numbers into Minecraft ⌨️

xacross →
yup ↑
zforward ⤴
place STONE at (x, y, z)
  • Open Code Builder (press C in the world)
  • Type the numbers in order — (x, y, z)
  • Press Run ▶ — your block appears at that spot

코드 빌더(C) 열고 → (x, y, z) 순서로 숫자 넣고 → Run ▶

Concept

What is interact?

agent.interact presses or flips whatever the agent faces.

agent.interact(FORWARD)
# flips the lever right in front

Be standing right in front of the lever first.

앞에 있는 레버를 작동시켜요

Concept

Order is everything 🔑

🕹️
flip first
door opens
then walk through
🚪
walk first
door is shut
agent gets stuck

먼저 레버, 그다음 통과

Code

Flip then pass through

agent.move(FORWARD, 1)
agent.interact(FORWARD)   # lever ON, door opens
agent.move(FORWARD, 2)   # walk through

Reach the lever, flip it, then go through the now-open door.

레버까지 가서 당기고 문을 통과해요

Walk to the lever first

while not agent.detect(BLOCK, FORWARD):
    agent.move(FORWARD, 1)
