        if event.type == pygame.QUIT:
            running = False

⚠️ Don't forget

Three musts

  • pygame.init() at start
  • pygame.display.flip() each frame
  • pygame.QUIT handler — or window won't close!

⚠ Edge cases

Gotchas + pitfalls

Frame rate matters
Without a clock, the game runs as fast as the CPU allows — chaos.
Coordinates start top-left
y increases as you go DOWN, not up.
Always handle QUIT
Forget pygame.event.QUIT and your window won't close.
Convert images
img.convert() or .convert_alpha() — way faster than not.
