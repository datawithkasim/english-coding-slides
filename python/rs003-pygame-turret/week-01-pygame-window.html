Code

Full game loop

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((135, 206, 235))  # sky blue
    pygame.display.flip()

⚠️ Don't forget

Three musts

  • pygame.init() at start
  • pygame.display.flip() each frame
  • pygame.QUIT handler — or window won't close!
