Concept

Speed as a constant

GUN_SPEED = 5

if keys[pygame.K_LEFT]:
    gun_x = gun_x - GUN_SPEED
if keys[pygame.K_RIGHT]:
    gun_x = gun_x + GUN_SPEED

Easy to tune — change one value, gun feels different!

Two parts

⬛
Base
FIXED at center
🔫
Gun
moves with arrow keys

Use two variables: BASE_X (constant), gun_x (changes).

Code

Full setup

WIDTH = 800
GUN_SPEED = 5
BASE_X = WIDTH // 2
gun_x = BASE_X  # start at center

while running:
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:  gun_x -= GUN_SPEED
    if keys[pygame.K_RIGHT]: gun_x += GUN_SPEED

    draw_turret(gun_x)
    pygame.display.flip()
Tip

Pass gun_x to function

def draw_turret(x):
    pygame.draw.rect(screen, GREY, base_rect)  # fixed
    pygame.draw.rect(screen, GREY,
        (x, y, BARREL_W, BARREL_H))  # uses x!

Function takes x, draws gun there.

⚠️ Watch

+= and -= shortcuts

gun_x = gun_x + 5   # long way
gun_x += 5           # short way

gun_x = gun_x - 5
gun_x -= 5

Both work the same. += is faster to type.

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
