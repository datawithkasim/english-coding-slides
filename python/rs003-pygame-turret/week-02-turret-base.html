Y goes DOWN! (not up like math class)

Concept

What's a constant?

WIDTH = 800
HEIGHT = 600
CENTER_X = WIDTH // 2

A value you don't change. ALL CAPS by tradition.

// = integer divide (no decimal).

상수 = 변하지 않는 값

Why constants?

Change one place, fix everywhere

# BAD: magic numbers everywhere
pygame.draw.rect(screen, color, (400, 580, 60, 20))

# GOOD: named
CENTER_X = WIDTH // 2
pygame.draw.rect(screen, color, (CENTER_X, 580, 60, 20))
Code

Draw a rectangle

pygame.draw.rect(screen, color, rect)

Need 3 things:

  • screen — where to draw
  • color — RGB tuple
  • rect — (x, y, width, height)
Code

Turret base in middle

WIDTH = 800
HEIGHT = 600
BASE_W = 80
BASE_H = 40
CENTER_X = WIDTH // 2

base_rect = (CENTER_X - BASE_W//2,
             HEIGHT - BASE_H,
             BASE_W, BASE_H)

pygame.draw.rect(screen, (100,100,100), base_rect)
Bonus

Circles too

pygame.draw.circle(screen, color, (cx, cy), radius)

Center at (cx, cy), size = radius pixels.

⚠️ Mistake

Forgot flip()

screen.fill(...)
pygame.draw.rect(...)
# forgot pygame.display.flip()

Without flip() nothing shows on screen!

Always call it after drawing each frame.
