Problem

Game loop getting big 😅

while running:
    pygame.draw.rect(...)  # base
    pygame.draw.rect(...)  # gun barrel
    pygame.draw.circle(...)  # gun head
    pygame.draw.line(...)  # gun aim line

Hard to read. Let's group it!

Concept

What's a function?

A reusable block of code with a name.

def draw_turret():
    pygame.draw.rect(...)
    pygame.draw.circle(...)
    pygame.draw.line(...)

def = "define". Group lines under one name.

Code

Define + call

def draw_turret():
    pygame.draw.rect(screen, GREY, base_rect)
    pygame.draw.rect(screen, GREY, barrel_rect)
    pygame.draw.circle(screen, GREY, (cx, cy), 15)

while running:
    screen.fill(SKY)
    draw_turret()  # 1 line!
    pygame.display.flip()
Why?

Big wins 🏆

  • Game loop is short and clear
  • Change turret style once → done
  • Reuse the function in any frame
  • Code reads like English: "draw turret"

⚠️ Don't forget

Indent matters

def draw_turret():
    pygame.draw.rect(...)  # inside
pygame.draw.circle(...)  # 🚫 outside!

4 spaces = inside the function. No spaces = outside.

⚠️ Watch

Define ≠ run

def draw_turret():
    ...
# nothing happens — never called

draw_turret()  # now it runs!

Need () to actually call the function.
