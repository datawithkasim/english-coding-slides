Problem

pygame.draw.circle(screen, YELLOW, (50, 50), 5)

Repetitive! There's a better way.

Concept

What's a for loop?

Repeat code N times.

for i in range(10):
    print("⭐")

Prints ⭐ exactly 10 times.

Code

Use loop variable for position

for i in range(10):
    x = 50 + i * 60
    pygame.draw.circle(screen, YELLOW, (x, 50), 5)

Each loop, i changes → x changes → new position!

Stars at: 50, 110, 170, 230, ...

In your game

Draw the ground

for i in range(20):
    x = i * 40
    pygame.draw.rect(screen, BROWN,
        (x, GROUND_Y, 38, 10))

20 small bricks across the screen → looks like ground.

In your game

Draw 5 targets

for i in range(5):
    target_x = 100 + i * 120
    pygame.draw.circle(screen, RED,
        (target_x, 100), 20)

5 targets, evenly spaced. Easy to add more!

⚠️ Mistake

range(5) stops before 5

for i in range(5):  # i = 0,1,2,3,4 (5 numbers!)
    print(i)

5 iterations, but the last i is 4. Always.

range(5) → 0,1,2,3,4
