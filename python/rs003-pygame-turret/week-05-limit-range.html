On Screen

Min / max + conditionals

이동 범위 제한

Problem

Gun escapes! 🏃

┌─────────screen─────────┐
│ │ 🔫 ←off screen!
└────────────────────────┘

Hold right too long → gun disappears off the edge.

Concept

Min & max values

⬅️
MIN
smallest allowed x
➡️
MAX
biggest allowed x

Gun must stay between MIN and MAX.

Code

Define limits

WIDTH = 800
GUN_W = 20

MIN_X = 0
MAX_X = WIDTH - GUN_W

MAX is WIDTH - GUN_W so gun's right edge stays inside.

Code

Block movement at edges

if keys[pygame.K_LEFT] and gun_x > MIN_X:
    gun_x -= GUN_SPEED

if keys[pygame.K_RIGHT] and gun_x < MAX_X:
    gun_x += GUN_SPEED

Only move if there's room. Combined with and!

Concept

Comparison operators

>greater than
<less than
>=greater or equal
<=less or equal
Alternative

Clamp after moving

if keys[pygame.K_LEFT]:  gun_x -= GUN_SPEED
if keys[pygame.K_RIGHT]: gun_x += GUN_SPEED

# clamp to range
if gun_x < MIN_X: gun_x = MIN_X
if gun_x > MAX_X: gun_x = MAX_X

Move first, then snap back if out of bounds.

⚠️ Off-by-one

Watch the edge

MAX_X = WIDTH       # 🚫 gun's right edge goes off
MAX_X = WIDTH - GUN_W  # ✅ stays inside

Pixel positions start at the left edge of the gun.

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
