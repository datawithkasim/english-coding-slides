Run it

Re-ask with while

locations = ["mine", "cave"]
choice = input("Where? ").lower().strip()

while choice not in locations:
    print("Try again.")
    choice = input("Where? ").lower().strip()

⚠️ Watch out

Forgot to update inside loop

✗ broken

    print("Try again")

infinite loop! choice never changes

✓ fixed 
while choice not in places:
    print("Try again")
    choice = input("? ")

re-asks → loop ends
