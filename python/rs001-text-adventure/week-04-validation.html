⚠ Edge cases

Gotchas + pitfalls

input() returns str
Even if user types '7', it's the string '7'. Cast with int(input(...)) to do math.
Name = case sensitive
hp and Hp are different variables. Pick a style and stick to it.
Snake_case in Python
PEP 8: player_name, not playerName or PlayerName.
Re-assign freely
x = 5 then x = 'hello' is legal. Python infers the type from the value.

The bug

Bug: A 3-item list has indexes 0, 1, 2. colors[3] raises IndexError: list index out of range. The last index is len - 1.
fixed
colors = ["red", "green", "blue"]
print(colors[2])
💻 Practice

Coding practice

Ask the user for a number. Keep asking until they type a valid one. Then print it.
starter
while True:
    raw = input('Number? ')
    try:
        n = int(raw)
        break
    except ValueError:
        print('Not a number — try again.')

print(f'You typed {n}')

Open your editor. Save as practice.py (or .html). Run it. Iterate.
