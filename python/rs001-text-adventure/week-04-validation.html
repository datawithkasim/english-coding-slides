The problem

What if player types nonsense?

"banana"
😵 ...what?

"banana" isn't a location. Game breaks!

존재하지 않는 답을 입력하면?

Concept 1

in — is it inside the list?

locations = ["diamond mine", "gold mine"]

print("gold mine" in locations)
print("banana" in locations)
▸ Output
True
False
Concept 2

not in — is it missing?

locations = ["diamond mine", "gold mine"]

if "banana" not in locations:
    print("That's not a real place!")

not in = opposite of in.

목록에 없으면 True

In your game

Reject bad answers

locations = ["diamond mine", "gold mine",
             "dark cave", "blocked cave"]

choice = input("Where? ").lower().strip()

if choice not in locations:
    print("Try again — pick a real place!")
Better still

Give them another chance

choice = input("Where? ").lower().strip()

while choice not in locations:
    print("Not a real place. Try again.")
    choice = input("Where? ").lower().strip()

while keeps asking until input is valid.

Concept 3

Default value when empty

name = input("Name? ").strip()

if name == "":
    name = "unknown traveler"

print(f"Hello, {name}!")

Empty input → use a backup. Game never breaks. 🛡️
