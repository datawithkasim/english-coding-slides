Concept 1

What is random?

🎲

random picks something by chance.

Like rolling a dice or pulling a card.

무작위로 고르기

First step

Get the random tool

Add this line at the top:

import random

Now you can use random.choice().

Concept 2

random.choice()

Pick ONE item from a list:

import random

rewards = ["sword", "shield", "gem", "potion"]

prize = random.choice(rewards)
print(f"You found a {prize}!")

Output: You found a sword! ... or shield ... 🎰

In your game

Random enemy encounter 🐉

import random

enemies = ["dragon", "goblin", "slime"]

enemy = random.choice(enemies)
print(f"A wild {enemy} appears!")

Each play of your game = new enemy. 🌀

Combine

Random + if for outcomes

enemy = random.choice(enemies)

if enemy == "dragon":
    print("🔥 Tough fight!")
elif enemy == "goblin":
    print("😈 Sneaky...")
else:
    print("🟢 Easy!")

Backpack idea

Reward = put in backpack

backpack = []

prize = random.choice(rewards)
backpack.append(prize)

print(f"You got: {prize}")
print(f"Backpack: {backpack}")

.append() adds to the list. 🎒

⚠️ Common bug

Forgetting import

prize = random.choice(rewards)
# NameError: name 'random' is not defined

Always add import random at the top!
