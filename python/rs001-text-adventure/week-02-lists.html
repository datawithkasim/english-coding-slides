Concept 1

What is a list?

A list = a row of boxes, each holds a value.

"diamond mine"
"gold mine"
"dark cave"
"blocked cave"

리스트 = 여러 값을 담은 박스 줄

Code

Make a list with [ ]

locations = ["diamond mine", "gold mine",
             "dark cave", "blocked cave"]
  • Square brackets [ ] wrap the list
  • Items separated by commas ,
  • Strings need quotes "
Concept 2

Each item has a number — index

"diamond mine"
"gold mine"
"dark cave"
"blocked cave"
0
1
2
3

Counting starts at 0, not 1!

Code

Get an item: list[index]

locations = ["diamond mine", "gold mine",
             "dark cave", "blocked cave"]

print(locations[0])
print(locations[2])
▸ Output
diamond mine
dark cave
Practice

Index quiz 🧠

fruits = ["apple", "banana", "grape"]
  • fruits[0] → "apple"
  • fruits[1] → "banana"
  • fruits[2] → "grape"

Always start at 0!

⚠️ Mistake

Out of range error

fruits = ["apple", "banana", "grape"]
print(fruits[3])  # 💥 ERROR!

3 fruits → indexes 0, 1, 2 only.

Index 3 doesn't exist. Python crashes.

3개 항목 → 인덱스는 0, 1, 2만 있어요.

In your game

Show 4 location choices

locations = ["diamond mine", "gold mine",
             "dark cave", "blocked cave"]

print(f"option 1: {locations[0]}")
print(f"option 2: {locations[1]}")
print(f"option 3: {locations[2]}")
print(f"option 4: {locations[3]}")
Output

What player sees

▸ Output
option 1: diamond mine
option 2: gold mine
option 3: dark cave
option 4: blocked cave

Now player knows where to go! 🗺️

Why use lists?

Lists = easy to change

locations = ["diamond mine", "gold mine",
             "haunted forest", "blocked cave"]

Change one item → all your print lines update automatically. ✨

리스트의 한 항목만 바꾸면 모든 출력이 같이 바뀌어요.
