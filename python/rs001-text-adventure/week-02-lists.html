⚠ Edge cases

Gotchas + pitfalls

Lists are 0-indexed
First item is items[0], not items[1].
IndexError out of range
items[99] on a 3-item list raises IndexError. Use len(items) to check first.
Mutating during a for
Don't append to a list while looping over it — behavior gets weird.
== vs is for lists
[1,2] == [1,2] is True. [1,2] is [1,2] is False (different objects).
