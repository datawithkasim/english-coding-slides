Today's mission

Make the computer say hi 👋

"My name is Kasim"
"Hello, Kasim!"

Player types name. Computer remembers it and greets them.

Concept 1

What is a variable?

A variable is a box that holds a value.

hero_name "Kasim"
age 12
hp 100

변수 = 값을 담는 상자

Code

Make your first variable

hero_name = "Kasim"
age = 12
  • name goes on the left
  • = means "store this"
  • value goes on the right
Code

Show it with print()

hero_name = "Kasim"
print(hero_name)
▸ Output
Kasim

print() shows the value on screen.

Code

Ask the player with input()

hero_name = input("What is your name? ")
print(hero_name)

input() waits for the player to type.

Whatever they type → stored in hero_name. ✅

Concept 2

Mix text + variable: f-string

hero_name = "Kasim"
print(f"Hello, {hero_name}!")
▸ Output
Hello, Kasim!

Put f before ", then {var} inside.

Together

Full greeting program

hero_name = input("What is your name? ")
print(f"Welcome, {hero_name}!")
print("Your adventure begins...")

3 lines = a greeting that knows your name. 🎮

⚠️ Problem

What if they press Enter?

(empty)
"Welcome, !"

Awkward! The greeting looks broken.

이름 없이 엔터를 누르면 인사가 이상해져요.

Fix it

Use if to check

hero_name = input("What is your name? ")

if hero_name == "":
    hero_name = "unknown traveler"

print(f"Welcome, {hero_name}!")

Empty? → use a default name. ✅

Bonus

Clean output with \n

print("Welcome!\nYour adventure begins...")
▸ Output
Welcome!
Your adventure begins...

\n = new line. Press enter inside text.
