Big idea

Choices create different stories 📖

⚔️
Diamond mine
→ find a sword
🐉
Dark cave
→ meet a dragon!

Same game. Different outcome.

Concept 1

if / else — two paths

if choice == "diamond mine":
    print("You find a sword!")
else:
    print("Nothing here...")

if = first path. else = backup path.

if = 만약, else = 아니면

Concept 2

Many paths: if / elif / else

if choice == locations[0]:
    print("diamond mine — find a sword!")
elif choice == locations[1]:
    print("gold mine — find gold!")
elif choice == locations[2]:
    print("dark cave — a dragon!")
else:
    print("blocked cave — try again")
How it flows

Python checks top → bottom

if choice == "diamond mine": match? ✅
elif choice == "gold mine": skip
elif choice == "dark cave": skip
else: skip

First match wins. The rest are skipped.

Enemy data

Enemies in a list 🐉

enemies = ["dragon", "goblin", "slime"]
print(f"A wild {enemies[0]} appears!")
▸ Output
A wild dragon appears!

Enemy info lives in a list — easy to add more!

Together

Choice → enemy

if choice == "dark cave":
    print(f"You meet a {enemies[0]}!")
elif choice == "gold mine":
    print(f"You meet a {enemies[1]}!")
else:
    print("It's quiet...")

Player's choice → which enemy shows up. ⚔️

⚠️ Order matters

First match wins

if hp > 0:
    print("alive")
elif hp > 50:  # 🚫 never runs!
    print("healthy")

If hp = 80, both are true — but only the first runs.

Put the most specific case first.
