.strip() & .lower()

플레이어 입력 정리하기

The problem

Players type messy text

" Gold Mine "
😕 "Gold Mine" ≠ "gold mine"

Extra spaces. Big letters. Computer thinks it's different!

Concept 1

.strip() — remove spaces

name = "  Kasim  "
clean = name.strip()
print(clean)
▸ Output
Kasim

Strips off blank space at start and end.

앞뒤 공백 제거

Concept 2

.lower() — make lowercase

choice = "GOLD MINE"
small = choice.lower()
print(small)
▸ Output
gold mine

Big letters → small letters.

대문자 → 소문자

Why?

Computer is picky 🤖

"Gold Mine" ≠
"gold mine" ≠

Same word to humans. Different to Python!

Combine!

Chain them together

choice = input("Where? ").lower().strip()

One line:

  • Get player input
  • .lower() → small letters
  • .strip() → no spaces

Always clean! ✨

In your game

Match player choice to list

locations = ["diamond mine", "gold mine",
             "dark cave", "blocked cave"]

choice = input("Where? ").lower().strip()

if choice == locations[0]:
    print("You go to the diamond mine!")
Result

All these work the same now ✅

  • "diamond mine"
  • "Diamond Mine"
  • "DIAMOND MINE"
  • " Diamond Mine "

All become "diamond mine" after cleaning. 🧼

⚠️ Order matters

Method order

# works:
choice = input("? ").lower().strip()

# also works:
choice = input("? ").strip().lower()

Both are fine here. Each method runs left → right.
