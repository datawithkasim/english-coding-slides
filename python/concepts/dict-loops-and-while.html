A dictionary = key → value pairs

Use the key to grab its value

for name in scores:

3 ways

Choose what to loop

.keys() just the keys — "Min", "Ye", "Bo" 키만 .values() just the values — 90, 75, 88 값만 .items() both together — key AND value 키 + 값 함께

Plain for x in scores: gives the keys (same as .keys()).

Watch it 👀

.items() grabs both at once

for name, score in scores.items():
    print(name, "got", score)
"Min":90◄ name, score
"Ye":75◄ name, score
"Bo":88◄ name, score
▸ Output
Min got 90
Ye got 75
Bo got 88

The while loop

Repeat while a condition stays True.

조건이 참인 동안 계속 반복

for vs while

Two jobs, two loops

for 
for i in range(3):
    print(i)

Know the count → for

while 
while lives > 0:
    play()

Repeat till something changes → while

횟수 아는 for · 조건 기반 while

Watch it 👀

Count up while count < 3

count = 0123
count < 3
print(count) · count += 1
▸ Output
0
1
2
→ 3 is not < 3, exit

조건이 거짓 되면 멈춤

⚠️ Watch out

The forever loop

✗ never stops 
n = 5
while n > 0:
    print(n)

n never changes → infinite

✓ makes progress 
n = 5
while n > 0:
    print(n)
    n = n - 1

n shrinks → reaches 0, stops

while 안에서 조건 값을 꼭 바꿔라

🐛 Debugactivity

Find the bug — wrong loop

# print every score
for s in scores:
    print(s)
Reveal fix
Prints the names (keys), not the numbers.

Loop values: for s in scores.values(): — or print scores[s].

그냥 for는 키가 나온다 — 값은 .values()

Remember 🧠

  • for key in d: → keys · d[key] → value
  • .items() → key AND value in one loop
  • while repeats until its condition is False
  • Always change the condition inside — or it loops forever
