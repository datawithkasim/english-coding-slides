Words

Three new words

for do the same lines again and again 반복문 range(1, 6) the numbers 1, 2, 3, 4, 5 1부터 5까지 i the loop number — it changes every time 반복 변수
Idea 💡

A loop is a worker

The worker reads one number,
does the job,
then takes the next number.

1 → job. 2 → job. 3 → job. Stop.

숫자 하나씩 → 작업 반복

Careful ⚠

Start at 0 → empty first row

Broken 
for i in range(5):
    print("👾" * i)

First row: 0 monsters. Empty!

Fixed 
for i in range(1, 6):
    print("👾" * i)

Starts at 1.
