Monster Parade

One loop. Different monsters.

리스트로 여러 몬스터 행진

Recap

Part 1: you built this

for i in range(1, 6):
    print("👾" * i)

Same monster, five times. Now: different monsters.

Predict 🤔

We want this parade

▸ Output

🐙🐙🐙🐙🐙🐙
👻👻👻👻👻👻

Each row is a different monster. How?

몬스터가 매번 바뀌어요

Words

Three new words

list a box that holds many things in order 리스트 [ ] square brackets make a list 대괄호 for monster in army take one thing from the list, each time 하나씩 꺼내기
Idea 💡

A list is a line of boxes

The worker takes box 1,
does the job,
then takes box 2.

👾 → job. 🐙 → job. 👻 → job. Stop.

상자 하나씩 → 작업 반복

STEP 1

Make the list

army = ["👾", "🐙", "👻", "🤖"]
print(army)
▸ Output
['👾', '🐙', '👻', '🤖']

One name, four monsters inside.

No numbers. The loop walks the list.

STEP 2

Loop the list

army = ["👾", "🐙", "👻", "🤖"]

for monster in army:
    print(monster)
▸ Output
👾
🐙
👻
🤖

4 things in the list = 4 rows.

Play with it 🎮

Add monsters — watch the parade

longer list = more rows
Careful ⚠

A missing comma glues two together

Broken 
army = ["👾" "🐙", "👻"]

Now the list has 2 things: "👾🐙" and "👻".

Fixed 
army = ["👾", "🐙", "👻"]

Comma between every item. 3 things.

STEP 3

Make each row long

army = ["👾", "🐙", "👻", "🤖"]

for monster in army:
    print(monster * 6)

print("🔥 MONSTER PARADE!")
