Concept

What's a for loop?

Repeat code N times.

for i in range(10):
    print("⭐")

Prints ⭐ exactly 10 times.

Code

Use loop variable for position

for i in range(10):
    x = 50 + i * 60
    pygame.draw.circle(screen, YELLOW, (x, 50), 5)

Each loop, i changes → x changes → new position!

Stars at: 50, 110, 170, 230, ...

In your game

Draw a starfield

for i in range(20):
    x = i * 40
    pygame.draw.circle(screen, WHITE,
        (x, STAR_Y), 2)

20 little stars across the screen → looks like deep space.

In your game

Spawn a row of 5 enemies

for i in range(5):
    enemy_x = 100 + i * 120
    pygame.draw.rect(screen, RED,
        (enemy_x - 18, 80, 36, 36))

5 enemies across the top, evenly spaced. Easy to add more!

⚠️ Mistake

range(5) stops before 5

for i in range(5):  # i = 0,1,2,3,4 (5 numbers!)
    print(i)

5 iterations, but the last i is 4. Always.

range(5) → 0,1,2,3,4

⚠ Edge cases

Gotchas + pitfalls

Off-by-one is everywhere
range(10) gives 0–9, not 1–10.
Infinite loop
Forgot to update the condition in a while? Ctrl-C to exit.
Don't mutate during for
Modifying the list you're looping over is a common source of bugs.
break vs continue
break exits the loop. continue skips this iteration only.
