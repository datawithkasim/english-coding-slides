Step 6 · Clean up

Bullets that fly off the top never come back

They are gone from the screen — but still in the list.
bullets list after 30 shots

len(bullets) = 0

Why it mattersThe move loop runs over every bullet, every frame — even the invisible ones. A thousand ghosts make the game lag.
The ruleIf bullet[1] < 0, the bullet is above the window. Delete it.
The trap

Never delete from a list you are looping over

Python walks by position. Delete one, and everything shuffles left.

Watch which item the loop skips.

The fixbullets[:] means "a copy of the list". Loop over the copy, delete from the real one.
for bullet in bullets[:]:   # copy
    bullets.remove(bullet)   # real list

Two characters. Whole class of bugs gone.

Step 7 · Hits

Type the hit check

Type this
Under your clean-up loop, BEFORE the drawing section.
    # bullet hits enemy #
    for bullet in bullets[:]:
        bullet_rect = pygame.Rect(bullet[0], bullet[1], bullet_width, bullet_height)
        for enemy in enemies[:]:
            enemy_rect = pygame.Rect(enemy[0], enemy[1], enemy_width, enemy_height)
            if bullet_rect.colliderect(enemy_rect):
                bullets.remove(bullet)
                enemies.remove(enemy)
                score = score + 10
                break
Both lists get [:]You delete from both inside the loop, so both need a copy.
Why breakThe bullet is gone after one hit. break stops it trying to hit a second enemy — which would crash.
Run itShoot an enemy. It vanishes. Score jumps by 10. 🎉
If it crashed

ValueError: list.remove(x): x not in list

This means you tried to delete the same thing twice.
Missing break?one bullet hits two enemies, tries to remove itself twice Missing [:]?the loop lost its place after a delete
Read the red textThe last line of the error tells you the line number in your file. Go there first.
Then check1. Both loops end in [:] · 2. break is the last line of the if · 3. break is indented under the if, not under the for
