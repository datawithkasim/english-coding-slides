Problem

Hard to read. Let's group it!

Concept

What's a function?

A reusable block of code with a name.

def draw_ship(x, y):
    pygame.draw.rect(...)
    pygame.draw.polygon(...)
    pygame.draw.rect(...)

def = "define". Group lines under one name.

Code

Define + call

def draw_ship(x, y):
    pygame.draw.rect(screen, CYAN, (x-20, y, 40, 50))            # body
    pygame.draw.polygon(screen, WHITE, [(x, y-20), (x-20, y), (x+20, y)])  # nose
    pygame.draw.rect(screen, RED, (x-16, y+50, 8, 10))         # thruster L
    pygame.draw.rect(screen, RED, (x+8, y+50, 8, 10))          # thruster R

while running:
    screen.fill(SPACE)
    draw_ship(CENTER_X, HEIGHT - 80)  # 1 line!
    pygame.display.flip()

Indent matters

4 spaces = inside the function. No spaces = outside.

⚠ Edge cases

Gotchas + pitfalls

Mutable default trap
Never use def f(x=[]). Use x=None + check inside.
Forgot return?
No return statement = returns None. Easy to miss when tired.
self first
Inside a class method, first param is always self — Python passes it automatically.
Don't shadow builtins
Avoid list = [1,2,3] — you just broke list() for the rest of the file.

🐛 Debug

The bug

Bug: You can't join a number to a string with +. Python raises TypeError: can only concatenate str (not "int") to str. Wrap it in str().
fixed
age = 12
print("I am " + str(age) + " years old")
