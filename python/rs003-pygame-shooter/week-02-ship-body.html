Concept

What's a constant?

WIDTH = 800
HEIGHT = 600
CENTER_X = WIDTH // 2

A value you don't change. ALL CAPS by tradition.

// = integer divide (no decimal).

상수 = 변하지 않는 값

Why constants?

Change one place, fix everywhere

# BAD: magic numbers everywhere
pygame.draw.rect(screen, color, (400, 520, 40, 50))

# GOOD: named
CENTER_X = WIDTH // 2
pygame.draw.rect(screen, color, (CENTER_X, 520, 40, 50))
Code

Draw a rectangle

pygame.draw.rect(screen, color, rect)

Need 3 things:

  • screen — where to draw
  • color — RGB tuple
  • rect — (x, y, width, height)
Code

Ship body at bottom-center

WIDTH = 800
HEIGHT = 600
SHIP_W = 40
SHIP_H = 50
CENTER_X = WIDTH // 2
CYAN = (80, 220, 255)

body_rect = (CENTER_X - SHIP_W//2,
             HEIGHT - 80,
             SHIP_W, SHIP_H)

pygame.draw.rect(screen, CYAN, body_rect)

⚠️ Mistake

Forgot flip()

screen.fill(...)
pygame.draw.rect(...)
# forgot pygame.display.flip()

Without flip() nothing shows on screen!

Always call it after drawing each frame.

⚠ Edge cases

Gotchas + pitfalls

Frame rate matters
Without a clock, the game runs as fast as the CPU allows — chaos.
Coordinates start top-left
y increases as you go DOWN, not up.
Always handle QUIT
Forget pygame.event.QUIT and your window won't close.
Convert images
img.convert() or .convert_alpha() — way faster than not.
