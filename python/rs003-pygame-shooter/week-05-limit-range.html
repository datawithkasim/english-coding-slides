Problem

Ship escapes! 🏃

┌─────────screen─────────┐
│ │ 🚀 ←off screen!
└────────────────────────┘

Hold an arrow too long → ship flies off the edge.

Concept

Four walls to stay inside

↔️
x limits
left & right walls
↕️
y limits
top & bottom walls

Ship must stay between all 4 edges.

Code

Clamp x — left & right

WIDTH = 800

if ship_x < 20: ship_x = 20
if ship_x > WIDTH - 20: ship_x = WIDTH - 20

Keep the ship's left & right edges inside the window.

Code

Clamp y — top & bottom

HEIGHT = 600

if ship_y < 20: ship_y = 20
if ship_y > HEIGHT - 60: ship_y = HEIGHT - 60

Same idea for up & down — clamp ship_y too.

Watch it!

Clamp inside the window

ship_x = 400 ship_x = 790
ship_x < WIDTH - 20
ship_x stays
ship_x = WIDTH - 20
▸ Result
ship free to move
ship snapped to edge

조건문

Concept

Comparison operators

>greater than
<less than
>=greater or equal
<=less or equal
Shortcut

Clamp with min & max

# same as four if-statements
ship_x = max(20, min(WIDTH - 20, ship_x))
ship_y = max(20, min(HEIGHT - 60, ship_y))

Move first, then snap back if out of bounds.

⚠️ Off-by-one

Watch the edge

ship_x > WIDTH       # 🚫 ship's right edge goes off
ship_x > WIDTH - 20  # ✅ stays inside

Leave room for the ship's half-width at the edge.

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
