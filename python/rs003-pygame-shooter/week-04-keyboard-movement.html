Concept

Speed as a constant

SPEED = 5

if keys[pygame.K_LEFT]:  ship_x -= SPEED

if keys[pygame.K_UP]:    ship_y -= SPEED

Easy to tune — change one value, the ship feels different!

Two variables

Track the ship's position

↔️
ship_x
left / right
↕️
ship_y
up / down

Two variables move the ship anywhere: ship_x and ship_y.

Code

Full setup

WIDTH, HEIGHT = 800, 600
SPEED = 5
ship_x = WIDTH // 2     # start at center
ship_y = HEIGHT - 100   # near the bottom

while running:
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:  ship_x -= SPEED
    if keys[pygame.K_RIGHT]: ship_x += SPEED
    if keys[pygame.K_UP]:    ship_y -= SPEED
    if keys[pygame.K_DOWN]:  ship_y += SPEED

    draw_ship(ship_x, ship_y)
    pygame.display.flip()
Tip

Pass ship_x, ship_y to function

def draw_ship(x, y):
    pygame.draw.rect(screen, CYAN,
        (x - 20, y, 40, 50))  # uses x AND y!

Function takes x and y, draws the ship there.

⚠️ Watch

+= and -= shortcuts

ship_x = ship_x + 5   # long way
ship_x += 5           # short way

ship_y = ship_y - 5
ship_y -= 5

Both work the same. += is faster to type.

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
