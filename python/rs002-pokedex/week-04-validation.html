Catch Bad
Picks

if/else + in / not in

입력값 검증

Problem

What if trainer types nonsense?

"banana"
😵 banana isn't a Pokémon...

Need to handle this safely!

Tool 1

in — is it in the list?

pokemon = ["pikachu", "charmander"]

print("pikachu" in pokemon)
print("banana" in pokemon)
▸ Output
True
False
Tool 2

not in — is it missing?

if choice not in pokemon:
    print("That's not a real Pokémon!")

Opposite of in. Use to reject bad input.

Concept

if / else = two paths

if choice in pokemon:
    print(f"Caught {choice}!")
else:
    print("Try a real Pokémon name.")

Valid → catch! Invalid → tell trainer.

if = 만약, else = 아니면

Better

Ask again with while

choice = input("Pick: ").lower().strip()

while choice not in pokemon:
    print("Not a Pokémon. Try again.")
    choice = input("Pick: ").lower().strip()

print(f"You caught {choice}!")

Loop keeps asking until input is valid.

⚠ Edge cases

Gotchas + pitfalls

Trust no input
Users type weird stuff. Always validate before using.
Catch the right error
Don't except: blindly — name the exception type.
Loop until valid
A while loop with break is the classic pattern for retrying input.
Strip before compare
'yes ' == 'yes' is False. Use .strip() first.
