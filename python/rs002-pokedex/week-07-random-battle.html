⚠ Edge cases

Gotchas + pitfalls

Pseudo-random
Same seed = same sequence. Useful for tests, bad for secrets.
randint includes both ends
random.randint(1, 6) can return 1 or 6, unlike range.
Use secrets for security
For passwords/tokens, use secrets, not random.
choice() needs non-empty
random.choice([]) raises IndexError.
