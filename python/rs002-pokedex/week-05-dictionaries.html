Concept

What's a dictionary?

A box of key → value pairs.

"name": "pikachu",
"hp": 35,
"attack": 55,
"type": "electric"
Watch it!

Look up a key

"hp":35
"type":"electric"
"name":"pikachu"
pikachu["hp""name"]
▸ Output
35
"pikachu"

사전 조회

Code

Make a Pokémon dict

pikachu = {
    "name": "pikachu",
    "hp": 35,
    "attack": 55,
    "type": "electric"
}

Curly braces { }. Key + colon + value.

Code

Get a value: dict[key]

print(pikachu["name"])
print(pikachu["hp"])
print(pikachu["type"])
▸ Output
pikachu
35
electric

⚠ Edge cases

Gotchas + pitfalls

KeyError on missing key
d['x'] raises KeyError if 'x' missing. Use d.get('x', default) for safety.
Keys must hash
Strings, ints, tuples ok. Lists and dicts can't be keys.
Insertion order kept
Since Python 3.7, dicts remember the order you added items in.
Looping iterates keys
Default for k in d = keys only. Use .items() for pairs.

The bug

Bug: input() always returns a string. Comparing a string with a number raises TypeError. Convert with int().
fixed
age = int(input("Age? "))
if age > 18:
    print("Adult")
