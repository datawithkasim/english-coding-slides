Concept

What's a dictionary?

A box of key → value pairs.

"name": "pikachu",
"hp": 35,
"attack": 55,
"type": "electric"
Code

Make a Pokémon dict

pikachu = {
    "name": "pikachu",
    "hp": 35,
    "attack": 55,
    "type": "electric"
}

Curly braces { }. Key + colon + value.

Code

Get a value: dict[key]

print(pikachu["name"])
print(pikachu["hp"])
print(pikachu["type"])
▸ Output
pikachu
35
electric
Lists vs dicts

When to use which?

📋
List
[a, b, c] · ordered
access by [0]
📖
Dict
{key: value} · named
access by ["hp"]
