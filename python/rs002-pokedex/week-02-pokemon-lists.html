Pokémon
Lists

Store + show many Pokémon

리스트로 포켓몬 선택지 만들기

Why?

One name vs many

pokemon = "pikachu"  # only one

A real Pokédex has many! Need a better way.

하나가 아니라 여러 개를 담으려면?

Concept

Lists hold many values

"pikachu"
"charmander"
"squirtle"
"bulbasaur"

Many Pokémon, one variable.

Code

Make a Pokémon list

pokemon = ["pikachu", "charmander",
           "squirtle", "bulbasaur"]
  • Square brackets [ ]
  • Comma between items
  • Quotes around each name
Concept 2

Each Pokémon has an index

"pikachu"
"charmander"
"squirtle"
0
1
2

Counting starts at 0!

Code

Get one Pokémon

pokemon = ["pikachu", "charmander", "squirtle"]
print(pokemon[0])
print(pokemon[2])
▸ Output
pikachu
squirtle
⚠️ Mistake

Index out of range

pokemon = ["pikachu", "charmander"]
print(pokemon[3])  # 💥 ERROR!

2 items → indexes 0 and 1 only.

2개 → 인덱스 0, 1만 있어요

In your Pokédex

Show 4 choices

pokemon = ["pikachu", "charmander",
           "squirtle", "bulbasaur"]

print(f"1: {pokemon[0]}")
print(f"2: {pokemon[1]}")
print(f"3: {pokemon[2]}")
print(f"4: {pokemon[3]}")
