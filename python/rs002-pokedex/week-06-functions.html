Concept

What's a function?

A reusable block of code with a name.

🎁

Define once. Use forever.

한 번 만들고 여러 번 쓰는 코드 묶음

Concept 2

Pass info: parameters

def show_pokemon(p):
    print(f"--- {p['name']} ---")
    print(f"HP: {p['hp']}")
    print(f"Type: {p['type']}")

show_pokemon(pikachu)
show_pokemon(charmander)

p = the Pokémon to show. Different each call!

Concept 3

return — give back a value

def total_power(p):
    return p["hp"] + p["attack"]

power = total_power(pikachu)
print(power)
▸ Output
90

return sends a value back.

In your Pokédex

Search function

def find_pokemon(name, all_pokemon):
    for p in all_pokemon:
        if p["name"] == name:
            return p
    return None

found = find_pokemon("pikachu", all_pokemon)
show_pokemon(found)
Why functions?

Big wins

  • Less typing → no copy-paste
  • Bug fix once → fixed everywhere
  • Code reads like English: show_pokemon(pikachu)
  • Build complex things from simple pieces
⚠️ Watch out

Don't forget to call!

def say_hi():
    print("Hi!")
# Nothing prints — never called

say_hi()  # ✅ now it runs

def defines. Need () to run it.

⚠ Edge cases

Gotchas + pitfalls

Mutable default trap
Never use def f(x=[]). Use x=None + check inside.
Forgot return?
No return statement = returns None. Easy to miss when tired.
self first
Inside a class method, first param is always self — Python passes it automatically.
Don't shadow builtins
Avoid list = [1,2,3] — you just broke list() for the rest of the file.
