The problem

Trainers type messy 🤷

" PIKACHU "
😕 Not the same as "pikachu"

Spaces. Big letters. Computer thinks they're different.

Tool 1

.strip() — kill spaces

name = "  pikachu  "
clean = name.strip()
print(clean)
▸ Output
pikachu

앞뒤 공백 제거

Tool 2

.lower() — small letters

name = "PIKACHU"
small = name.lower()
print(small)
▸ Output
pikachu

대문자 → 소문자

Combine

Chain them in one line

choice = input("Pick: ").lower().strip()

Now ALL these match:

  • "pikachu"
  • "PIKACHU"
  • " Pikachu "
Concept

Check with if

choice = input("Pick: ").lower().strip()

if choice == pokemon[0]:
    print("You picked Pikachu! ⚡")

== = "is equal to". Two equals signs!

⚠ Edge cases

Gotchas + pitfalls

input() returns str
Even if user types '7', it's the string '7'. Cast with int(input(...)) to do math.
Name = case sensitive
hp and Hp are different variables. Pick a style and stick to it.
Snake_case in Python
PEP 8: player_name, not playerName or PlayerName.
Re-assign freely
x = 5 then x = 'hello' is legal. Python infers the type from the value.

Coding practice

Ask the user for a number. Keep asking until they type a valid one. Then print it.
starter
while True:
    raw = input('Number? ')
    try:
        n = int(raw)
        break
    except ValueError:
        print('Not a number — try again.')

print(f'You typed {n}')
