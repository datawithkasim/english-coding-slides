The problem

Trainers type messy 🤷

" PIKACHU "
😕 Not the same as "pikachu"

Spaces. Big letters. Computer thinks they're different.

Tool 1

.strip() — kill spaces

name = "  pikachu  "
clean = name.strip()
print(clean)
▸ Output
pikachu

앞뒤 공백 제거

Tool 2

.lower() — small letters

name = "PIKACHU"
small = name.lower()
print(small)
▸ Output
pikachu

대문자 → 소문자

Combine

Chain them in one line

choice = input("Pick: ").lower().strip()

Now ALL these match:

  • "pikachu"
  • "PIKACHU"
  • " Pikachu "
Concept

Check with if

choice = input("Pick: ").lower().strip()

if choice == pokemon[0]:
    print("You picked Pikachu! ⚡")

== = "is equal to". Two equals signs!

In your Pokédex

Trainer chooses Pokémon

pokemon = ["pikachu", "charmander",
           "squirtle", "bulbasaur"]

choice = input("Which one? ").lower().strip()

if choice == pokemon[0]:
    print("⚡ Pikachu — electric!")
⚠️ Bug

= vs ==

# wrong — sets value
if choice = "pikachu":  💥

# right — compares
if choice == "pikachu":  ✅

One = sets. Two == compares.
