⬆ Your ❤️ and ⭐ up top keep changing — and remember on every slide. That is global game state.

Code

How it works

life = 50
points = 0

def fight():
    global life, points
    life = life - 10
    points = points + 25

fight()   # ❤️40  ⭐25
fight()   # ❤️30  ⭐50

global life, points = "change the ones on the wall."

⚠️ Watch out

Forgot global

✗ crashes
def fight():
    points = points + 25

makes a new empty local → UnboundLocalError

✓ works
def fight():
    global points
    points = points + 25

uses the outside points 👍
