SLOT 8
⚠️ Watch out

The frozen score

✗ broken 
text = font.render(f"Score: {score}", True, BLACK)

while frames < 60:
    score += 1
    screen.blit(text, (20, 20))

Rendered once. The picture never changes. Screen shows Score: 0 forever.

✓ fixed 
while frames < 60:
    score += 1
    text = font.render(f"Score: {score}", True, BLACK)
    screen.blit(text, (20, 20))

Rendered every frame. The number climbs to 60.
