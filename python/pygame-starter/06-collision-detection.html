⚠️ Watch out

Print once, not every frame

✗ broken 
# each frame:
player.x += 5
if player.colliderect(enemy):
    print("collide!")

Overlap lasts 23 frames → prints 23 times.

✓ fixed 
hit = False   # before the loop

# each frame:
player.x += 5
if not hit and player.colliderect(enemy):
    hit = True
    print("collide!")

The flag remembers. Prints once.
