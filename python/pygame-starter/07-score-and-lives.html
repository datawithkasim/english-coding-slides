SLOT 5
Idea 💡

The loop is a heartbeat

score ↑0 → 10 → 20
lives ↓3 → 2 → 1
runningTrue → False

One beat = one frame. The numbers stay alive between beats.

The flag is a switch. Flip it and the heart stops.

반복문은 심장, 깃발은 스위치

SLOT 8
⚠️ Watch out

Where does score = 0 go?

✗ broken 
frames = 0
while frames < 60:
    score = 0
    if frames % 10 == 0:
        score += 10
    frames += 1
print(score)   # 0

The score resets every frame. It never grows.

✓ fixed 
score = 0
frames = 0
while frames < 60:
    if frames % 10 == 0:
        score += 10
    frames += 1
print(score)   # 60

The score sits outside the loop. It keeps its value.
