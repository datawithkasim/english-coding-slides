01 THE IDEA why it prints a box

Your value is another dictionary

A dictionary is key → value. In your menu, every value is a second dictionary.

"americano"→{ "price": 6000, "ingredients": [...] }
"peach ice tea"→{ "price": 3000, "ingredients": [...] }
"apple pie"→{ "price": 4000, "ingredients": [...] }

The big box holds three small boxes. One key opens a small box. A second key opens what is inside it.

딕셔너리 안에 딕셔너리. 열쇠 두 개가 필요해요.

04 COMMON MISTAKE KeyError

The key must match letter for letter

breaks
print(starbucks["Americano"]["price"])
KeyError: 'Americano'
A capital A is a different key.
works
print(starbucks["americano"]["price"])
Same spelling, same capitals, same spaces.

KeyError means Python looked for that key and found nothing. Check your spelling first.

05 YOUR OLD LOOP name vs content

You called it key, but it holds a value

your line
for key in starbucks.values():
    print(key)
.values() gives you the small boxes. So key is a whole box, not a name.
clearer name
for info in starbucks.values():
    print(info["price"])
Now the name says what it holds, and you take the price out of it.

09 PART 3 4 new lines

A loop inside a loop

  1. Go to the bottom of main.py.
  2. Type: for name, info in starbucks.items():
  3. Next line, 4 spaces in: print(name)
  4. Next line, same 4 spaces: for item in info["ingredients"]:
  5. Next line, now 8 spaces in: print("-", item)
  6. Press Run.

The inside loop runs all the way through before the outside loop takes its next turn.

11 COMMON MISTAKE indent

The inside loop must sit inside

wrong indent
for name, info in starbucks.items():
    print(name)
for item in info["ingredients"]:
    print("-", item)
The second loop sits outside now. You get the ingredients of the last drink only.
right indent
for name, info in starbucks.items():
    print(name)
    for item in info["ingredients"]:
        print("-", item)
Both loops sit under the first for, so every drink gets its list.

13 QUOTE RULE inside f-strings

Use ' inside "

risky
print(f"{name} {info["price"]} won")
The same quote twice. Older Python closes the string early and shows a SyntaxError.
safe
print(f"{name} {info['price']} won")
Double quotes outside, single quotes inside. This always works.

Rule to remember: outside ", inside '.
