SLOT 4
Vocab

3 new words

print() shows text on the screen 출력 variable named box that holds a value 변수 input() waits for the player to type 입력
SLOT 5
Concept

Python does 3 jobs 🧠

📢 Show
Put words on the screen for the player to read.
📦 Remember
Keep a value in a named box and use it later.
👂 Ask
Stop, wait, and take what the player types.

SLOT 6
Run it

The dungeon entrance

print("The iron door slams shut.")
name = input("Who are you? ")
print(f"{name}, you are trapped.")
▸ Player types "Mina"
The iron door slams shut.
Who are you? Mina
Mina, you are trapped.
Zoom in 🔍

The f makes the box open

f"{name}, you are trapped."
▸ Output
Mina, you are trapped.

Python swaps {name} for the value inside.

f-문자열: 변수 값을 문장에 넣기

SLOT 8
⚠️ Watch out

Text needs quotes

✗ broken 
print(The torch dies.)

Python reads The as a box name. NameError

✓ fixed 
print("The torch dies.")

Quotes mark it as text.
