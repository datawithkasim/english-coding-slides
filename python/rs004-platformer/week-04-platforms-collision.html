플랫폼 충돌

Concept

Platforms = list of Rects

platforms = [
    pygame.Rect(0, 550, 800, 50),     # ground
    pygame.Rect(200, 450, 120, 20),
    pygame.Rect(400, 350, 120, 20),
    pygame.Rect(600, 250, 120, 20),
]

Each: (x, y, width, height).

Concept

colliderect() — overlap check

player = pygame.Rect(100, 500, 50, 50)
platform = pygame.Rect(100, 540, 200, 20)

if player.colliderect(platform):
    print("touching!")

Two boxes overlap → True.

Tricky

Land only when falling

for plat in platforms:
    if player.colliderect(plat) and velocity_y > 0:
        player.bottom = plat.top
        velocity_y = 0
        on_ground = True

Only land if moving down. Otherwise can pass through from below.

Watch it!

Landing check — both must be true

falling (velocity_y = 5) jumping up (velocity_y = -8)
colliderect(plat) and velocity_y > 0
snap to plat.top, on_ground = True
pass through from below
▸ Result
land on platform
keep moving — no land

Code

Draw all platforms

BROWN = (95, 60, 30)

for plat in platforms:
    pygame.draw.rect(screen, BROWN, plat)

Loop through list → draw each one. for loop wins again!

⚠️ Watch

Set on_ground = False first

on_ground = False            # reset

for plat in platforms:
    if ...:

Otherwise on_ground stays True after walking off a platform!

⚠ Edge cases

Gotchas + pitfalls

Off-by-one is everywhere
range(10) gives 0–9, not 1–10.
Infinite loop
Forgot to update the condition in a while? Ctrl-C to exit.
Don't mutate during for
Modifying the list you're looping over is a common source of bugs.
break vs continue
break exits the loop. continue skips this iteration only.
