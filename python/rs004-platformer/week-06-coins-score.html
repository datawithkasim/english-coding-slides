Concept

Coins = list of Rects

coins = [
    pygame.Rect(180, 410, 20, 20),
    pygame.Rect(380, 340, 20, 20),
    pygame.Rect(580, 280, 20, 20),
]
score = 0

Same pattern as platforms — easy to extend.

Code

Pickup logic

for coin in coins[:]:
    if player.colliderect(coin):
        coins.remove(coin)
        score += 1

Touch coin → remove it from list, +1 score. ✨

coins[:] = a copy (safe to remove during loop).

⚠️ Bug

Don't mutate while looping!

# 🚫 weird behavior
for coin in coins:
    coins.remove(coin)

# ✅ loop a copy
for coin in coins[:]:
    coins.remove(coin)

The [:] trick saves you from skipped items.

Code

Draw coins as circles

GOLD = (255, 215, 0)

for coin in coins:
    pygame.draw.circle(screen, GOLD, coin.center, 10)

coin.center = midpoint of the Rect. Handy!

Concept

Show score with pygame.font

font = pygame.font.SysFont(None, 36)

# in game loop
text = font.render(f"Score: {score}", True, BLACK)
screen.blit(text, (10, 10))

Render text → blit (paste) onto screen at (10, 10).

Bonus

HUD = corner display

def draw_hud():
    text = font.render(f"Score: {score}", True, BLACK)
    screen.blit(text, (10, 10))

# in loop
draw_hud()

Always draw HUD last — on top of everything.

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
