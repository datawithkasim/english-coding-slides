Code

The full loop

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((135, 206, 235))  # sky blue
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

Why 60 FPS?

clock.tick(60)

Locks the loop to 60 frames per second.

  • Smooth animation
  • Same speed on slow/fast computers
  • Standard for 2D games
⚠️ Don't forget

Three musts

  • pygame.init() — start engine
  • pygame.QUIT handler — close window
  • pygame.display.flip() — show frame

Miss any → game won't behave right.

⚠ Edge cases

Gotchas + pitfalls

Frame rate matters
Without a clock, the game runs as fast as the CPU allows — chaos.
Coordinates start top-left
y increases as you go DOWN, not up.
Always handle QUIT
Forget pygame.event.QUIT and your window won't close.
Convert images
img.convert() or .convert_alpha() — way faster than not.
