Code

Open the window

import pygame
pygame.init()

WIDTH, HEIGHT = 800, 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("My Platformer")
clock = pygame.time.Clock()
Code

The full loop

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((135, 206, 235))  # sky blue
    pygame.display.flip()
    clock.tick(60)

pygame.quit()
Concept

Each 0-255: red, green, blue.

Why 60 FPS?

clock.tick(60)

Locks the loop to 60 frames per second.

  • Smooth animation
  • Same speed on slow/fast computers
  • Standard for 2D games
⚠️ Don't forget

Three musts

  • pygame.init() — start engine
  • pygame.QUIT handler — close window
  • pygame.display.flip() — show frame

Miss any → game won't behave right.
