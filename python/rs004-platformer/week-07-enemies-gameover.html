Concept

class = blueprint

class Enemy:
    def __init__(self, x, y, range_x):
        self.rect = pygame.Rect(x, y, 40, 40)
        self.start_x = x
        self.range_x = range_x
        self.direction = 1
        self.speed = 2

Each enemy = an object with its own state.

클래스 = 적 만드는 틀

Code

Patrol logic

    def update(self):
        self.rect.x += self.direction * self.speed

        if self.rect.x > self.start_x + self.range_x:
            self.direction = -1
        if self.rect.x < self.start_x:
            self.direction = 1

Hits boundary → flip direction. Like ping-pong!

Code

Game state machine

game_state = "playing"

if game_state == "playing":
    for enemy in enemies:
        enemy.update()
        if player.colliderect(enemy.rect):
            game_state = "gameover"

One variable tracks the current screen.

⚠ Edge cases

Gotchas + pitfalls

Frame rate matters
Without a clock, the game runs as fast as the CPU allows — chaos.
Coordinates start top-left
y increases as you go DOWN, not up.
Always handle QUIT
Forget pygame.event.QUIT and your window won't close.
Convert images
img.convert() or .convert_alpha() — way faster than not.

🐛 Debug

The bug

Bug: count never changes, so count < 5 is always true — an infinite loop. Add count += 1 inside the loop.
fixed
count = 0
while count < 5:
    print(count)
    count += 1
