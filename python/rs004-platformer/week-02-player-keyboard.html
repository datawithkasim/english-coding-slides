Code

Full weeks 3·4 setup

PLAYER_SPEED = 5
player = pygame.Rect(100, 500, 50, 50)

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:  player.x -= PLAYER_SPEED
    if keys[pygame.K_RIGHT]: player.x += PLAYER_SPEED

    screen.fill(SKY)
    pygame.draw.rect(screen, RED, player)
    pygame.display.flip()
    clock.tick(60)
Tune it

Speed feels matter

PLAYER_SPEED = 3   # slow → frustrating
PLAYER_SPEED = 5   # 👍 just right
PLAYER_SPEED = 15  # too fast → can't aim

Change one number, change the whole feel.

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
