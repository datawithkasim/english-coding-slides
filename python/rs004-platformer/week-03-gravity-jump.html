중력과 점프

Concept

What's velocity?

How fast & which way the player moves.

velocity_y = -5 → moving UP ⬆️
velocity_y = 0 → not moving
velocity_y = +5 → moving DOWN ⬇️

속도 = 방향 + 빠르기

Concept

Gravity = velocity goes up each frame

GRAVITY = 0.7
velocity_y = 0

while running:
    velocity_y += GRAVITY     # +0.7 every frame
    player.y += velocity_y    # move down

Each frame falls a little faster. Like real gravity!

Concept

Jump = sudden negative velocity

JUMP_STRENGTH = -14

if event.type == pygame.KEYDOWN:
    if event.key == pygame.K_SPACE:
        velocity_y = JUMP_STRENGTH

Negative = up. Then gravity slows the rise → falls back down.

Concept

on_ground — only jump when standing

on_ground = True

if event.key == pygame.K_SPACE and on_ground:
    velocity_y = JUMP_STRENGTH
    on_ground = False

Stops infinite jumping in mid-air.

바닥에 있을 때만 점프 가능

Code

Stop at the floor

if player.y >= HEIGHT - 50:
    player.y = HEIGHT - 50
    velocity_y = 0
    on_ground = True

Hit floor → snap to floor, reset velocity, can jump again.

Tune

Find the fun feel 🎮

GRAVITY0.7
JUMP_STRENGTH-14
  • High gravity + low jump = sluggish
  • Low gravity + high jump = floaty
  • Moon mode: gravity 0.2 + jump -8 ✨
⚠️ Tricky

KEYDOWN vs get_pressed

⌨️
KEYDOWN
fires ONCE per press
good for jump
⏬
get_pressed
fires while held
good for movement

Use the right one for each control!

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
