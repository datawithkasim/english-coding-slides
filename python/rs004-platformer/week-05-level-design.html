Code

Build Rects from data

def build_level(level_data):
    return [pygame.Rect(*p) for p in level_data]

platforms = build_level(LEVEL_1)

*p unpacks the tuple → (x, y, w, h) args.

Concept

Level design rules 📐

  • Vertical gap ≤ jump height
  • Horizontal gap ≤ run + jump distance
  • Start clearly visible
  • Goal at the top or far right

Sketch on paper first. Always.

Tip

Reset on fall-off

start_x, start_y = 100, 500
player = pygame.Rect(start_x, start_y, 50, 50)

if player.y > HEIGHT:
    player.x = start_x
    player.y = start_y
    velocity_y = 0

Player falls past screen → respawn at start. No game over yet!

Concept

Constants for spacing

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.

The bug

Bug: You can't join a number to a string with +. Python raises TypeError: can only concatenate str (not "int") to str. Wrap it in str().
fixed
age = 12
print("I am " + str(age) + " years old")
