Concept

Level = data

LEVEL_1 = [
    (0, 550, 800, 50),
    (150, 450, 120, 20),
    (350, 380, 100, 20),
    (550, 320, 100, 20),
    (700, 220, 100, 20),
]

Tuples = simple position+size. Easy to edit!

Code

Build Rects from data

def build_level(level_data):
    return [pygame.Rect(*p) for p in level_data]

platforms = build_level(LEVEL_1)

*p unpacks the tuple → (x, y, w, h) args.

Concept

Level design rules 📐

  • Vertical gap ≤ jump height
  • Horizontal gap ≤ run + jump distance
  • Start clearly visible
  • Goal at the top or far right

Sketch on paper first. Always.

Tip

Reset on fall-off

start_x, start_y = 100, 500
player = pygame.Rect(start_x, start_y, 50, 50)

if player.y > HEIGHT:
    player.x = start_x
    player.y = start_y
    velocity_y = 0

Player falls past screen → respawn at start. No game over yet!

Concept

Constants for spacing

STEP_X = 200  # horizontal gap
STEP_Y = 70   # vertical climb

Tune the whole level by changing 2 numbers.

Tip

Test it like a player

  • Can you reach every platform?
  • Is there a "right path"?
  • Are there shortcuts? Fun!
  • Where do players fall?

Play your own level. Then tune.
