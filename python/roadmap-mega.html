1.3

1.4

Loop control — break · continue

for n in range(100):
    if n == 7:
        break           # exit loop
    if n % 2:
        continue        # skip to next
    print(n)

Two escape hatches inside loops.

1.5

Functions + Lambdas

def greet(name, greeting="Hi"):

Reusable blocks of behaviour. Default args supported.

Dictionaries up close

Stage 2 of 8

Modules & Packages

Reuse code others wrote.

2.1

Modules — split big code into files

# in pokedex.py
POKEMON = [{"name": "pikachu"}, ...]

# in main.py
import pokedex
print(pokedex.POKEMON[7])

One .py file = one module. Import to use.

2.2

Scripts vs modules — __main__

def main():
    print("running directly!")

if __name__ == "__main__":
    main()

Run as script → executes. Import as module → doesn't.

One project, one venv. Avoids "works on my machine" hell.

03
Stage 3 of 8

Object-Oriented
Programming

Group data + behavior into objects.

3.1

Classes + Methods

class Pokemon:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

    def attack(self, target):
        target.hp -= 10

pikachu = Pokemon("Pikachu", 35)
3.2

Class vs Instance

class Pokemon:
    species_count = 0          # class attr (shared)

    def __init__(self, name):
        self.name = name             # instance attr
        Pokemon.species_count += 1

Class = blueprint. Instance = built thing.

3.3

Inheritance + Encapsulation

class Electric(Pokemon):       # inherits
    def thunder(self, target):
        target.hp -= 25

raichu = Electric("Raichu", 60)

Reuse code via parent classes. Hide internals with _underscore.

3.4

Polymorphism + Duck typing

class Dog:
    def speak(self): return "woof"
class Cat:
    def speak(self): return "meow"

for a in [Dog(), Cat()]:
    print(a.speak())

"If it quacks like a duck, it's a duck." Same method, different types.

3.5

Dunder methods __like_this__

__init__
constructor
__str__
how it prints
__eq__
==
__lt__
<
__len__
len()
__iter__
for loops

Hooks Python calls automatically.

3.6

@property — computed attributes

class Circle:
    def __init__(self, r): self.r = r

    @property
    def area(self):
        return 3.14 * self.r ** 2

c = Circle(5)
c.area      # 78.5 — no parens!

Looks like attribute, acts like function.

3.7

Composition vs Inheritance

inherit
"is a" · Dog is an Animal
compose
"has a" · Car has an Engine

Prefer composition. Inheritance trees go bad fast.

3.8

@dataclass — boilerplate killer

from dataclasses import dataclass

@dataclass
class Pokemon:
    name: str
    hp: int = 100

p = Pokemon("Pikachu", 35)

Auto-generates __init__, __repr__, __eq__.

Stage 4 of 8

Advanced Python

Pythonic tricks that read like English.

4.1

Comprehensions

# list comprehension
squares = [x*x for x in range(10)]

# dict comprehension
sqd = {x: x*x for x in range(5)}

# with filter
evens = [x for x in range(20) if x % 2 == 0]

One-line collections. Very Pythonic.

4.2

Generators — lazy + memory-cheap

def count_up(n):
    for i in range(n):
        yield i              # pause + return

# generator expression
big = (x*x for x in range(10_000_000))

Generators don't store everything at once.

4.3

Decorators — wrap functions

def log(fn):
    def wrapper(*args):
        print(f"calling {fn.__name__}")
        return fn(*args)
    return wrapper

@log
def attack(target): ...
4.4

Context managers — auto cleanup

with open("data.txt") as f:
    print(f.read())
# file closes automatically here

# your own context manager:
from contextlib import contextmanager
4.5

*args + **kwargs

def total(*nums):
    return sum(nums)

total(1, 2, 3, 4)  # 10

def make(**opts):
    print(opts)        # dict of kwargs

make(name="pika", hp=35)

Accept any number of args / keyword args.

4.6

Closures + Scope (LEGB)

def counter():
    n = 0
    def tick():
        nonlocal n
        n += 1
        return n
    return tick

Local · Enclosing · Global · Builtin.

4.7

itertools · functools · collections

chain

4.9

match / case — pattern matching (3.10+)

match command.split():
    case ["go", direction]:
        move(direction)
    case ["take", *items]:
        pickup(items)
    case _:
        print("???")

Like switch, but with destructuring.

4.10

Walrus + modern syntax

# walrus := assign inside expression (3.8+)
if (n := len(data)) > 10:
    print(f"too big ({n})")

# positional-only / keyword-only (3.8+)
def f(x, /, y, *, z): ...

Python keeps evolving. Keep up.

Stage 5 of 8

Data Structures
& Algorithms

How to think about cost.

5.1

Big-O — how slow does it grow?

O(1)
instant · dict lookup
O(log n)
binary search
O(n)
scan a list
O(n log n)
good sort
O(n²)
nested loops
O(2ⁿ)
brute recursion
5.2

Lists · Stacks · Queues · Heaps

stack
LIFO · last-in first-out · undo
queue
FIFO · first-in first-out · printer
linked list
node → node → node · O(1) insert
heap
min/max at top · priority queue
5.3

Hash tables — O(1) lookup

users = {"kasim": 12, "Mina": 10}
print(users["kasim"])  # instant!

# sets use hashing too
unique = {1, 2, 2, 3}  # {1, 2, 3}

Python dicts and sets are hash tables under the hood.

5.4

Searching — linear vs binary

# linear: check each — O(n)
for x in data:
    if x == target: break

# binary: halve each step — O(log n)
# requires sorted data
from bisect import bisect_left

Binary search of 1 billion items = ~30 steps.

5.5

Trees + Recursion

def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

Function calls itself with smaller input. Trees are recursion-shaped.

5.6

Graphs · BFS · DFS

graph
nodes + edges · maps, friends, web
BFS
queue · shortest path
DFS
stack/recursion · explore deep
Dijkstra
weighted shortest path
5.7

Sorting Algorithms

bubble · O(n²)
simple, slow
merge · O(n log n)
divide & conquer
quick · O(n log n)
pick pivot, partition
sorted() · TimSort
Python's built-in · use this
5.8

Dynamic programming — remember answers

from functools import cache

@cache
def fib(n):
    if n < 2: return n
    return fib(n-1) + fib(n-2)

Solve big problems by remembering small answers.

Testing & Code Quality

Ship code that doesn't break.

6.1

Testing — prove your code works

# test_battle.py
def test_attack_reduces_hp():
    a = Pokemon("a", 100)
    a.attack(a)
    assert a.hp == 90

pytest is the modern default. unittest ships with Python.

6.2

TDD — Red · Green · Refactor

red
write a failing test
green
make it pass (minimum)
refactor
clean up · still green

Tests describe behaviour first. Code follows.

6.3

pytest fixtures + parametrize

@pytest.fixture
def battle():
    return Battle(p1, p2)

@pytest.mark.parametrize("hp,want", [
    (10, True), (0, False)])
def test_alive(hp, want): ...

Reusable test data + table-driven tests.

6.4

Linters · Formatters · Type checkers

black
opinionated formatter

fast linter (Rust)

Google's formatter

type checker
pyright
MS · fast types

6.5

Static typing — catch bugs before running

def greet(name: str) -> str:
    return f"Hi, {name}!"

greet(42)  # mypy: error — int is not str

Add type hints. Run mypy. Find bugs at write-time.

6.6

Logging > print

import logging
log = logging.getLogger(__name__)

log.debug("detail")
log.info("hp dropped")
log.warning("low hp")
log.error("crashed")

Levels · destinations · filters. print can't do any of these.

6.7

Debuggers — pdb · breakpoint

def attack(self, t):
    breakpoint()       # pauses here
    t.hp -= self.power

Stage 7 of 8

Concurrency & Async

Do many things at once.

7.1

Threading vs Multiprocessing

threading
share memory · I/O bound (network, files)
multiprocessing
separate memory · CPU bound (math)

Why two? Python's GIL stops threads from doing real CPU work in parallel.

7.2

The GIL — Global Interpreter Lock

Only one thread runs Python bytecode at a time, even on 16 cores.

why it exists
memory safety · simpler C extensions
workaround
multiprocessing · C extensions · async
future
PEP 703 · no-GIL build (3.13+)
7.3

asyncio — wait without blocking

import asyncio

async def fetch(url):
    ...
    return data

results = await asyncio.gather(
    fetch("a"),
    fetch("b"),
)

Run thousands of network calls in parallel from one thread.

7.4

concurrent.futures — the easy mode

from concurrent.futures import ThreadPoolExecutor

with ThreadPoolExecutor() as ex:
    results = list(ex.map(fetch, urls))

Pool of workers. Swap Thread ↔ Process with one word.

7.5

Async patterns

gather
run many · wait for all
Queue
producer/consumer
Semaphore
limit concurrency (rate limit)
TaskGroup
structured concurrency (3.11+)
7.6

When NOT to use async

CPU-heavy
math · ML training → multiprocessing
tiny scripts
overhead > benefit · just be sync
sync libs
one sync call freezes everything

Async is for I/O wait time. Wrong tool for CPU work.

Stage 7 checklist

✓ asyncio

✓ GIL

✓ futures

✓ pick right tool
I/O ≠ CPU
