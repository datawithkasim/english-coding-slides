Why this matters

Pseudo-random numbers and choices. For cryptography use secrets instead.

Code

Example

import random
random.random()              # [0.0, 1.0)
random.randint(1, 10)         # 1-10 inclusive
random.choice(['a','b','c'])
random.shuffle(my_list)
random.seed(42)
