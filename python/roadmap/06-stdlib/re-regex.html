Stage 6 · Standard Library

Why

Why this matters

Pattern matching for text. Powerful but cryptic. Use raw strings (r'...') to avoid backslash hell.

Pattern matching for text. Powerful but cryptic. Use raw strings (r'...') to avoid backslash hell.

Code

Example

import re
re.search(r'\d+', 'abc123def')   # match obj
re.findall(r'\w+', text)
re.sub(r'\s+', ' ', text)
p = re.compile(r'^(\w+)@(.+)$')
