Stage 14 · Concurrency + Async

Why

Why this matters

Light-weight threads, share memory. Good for I/O wait (network, disk). Bad for CPU work (GIL).

Light-weight threads, share memory. Good for I/O wait (network, disk). Bad for CPU work (GIL).

Code

Example

import threading
def work(n):
    print(n)

ts = [threading.Thread(target=work, args=(i,)) for i in range(5)]
for t in ts: t.start()
for t in ts: t.join()
