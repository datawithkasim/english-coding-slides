Why

Why this matters

Real parallel processes, separate memory. Good for CPU-heavy work — escapes the GIL by running multiple interpreters.

Code

Example

from multiprocessing import Pool

def square(n): return n * n

with Pool(4) as p:
    print(p.map(square, range(10)))

What's wrong with this code?

buggy
count = 0
while count < 5:
    print(count)

Think first — then click next.

🐛 Debug

The bug

Bug: count never changes, so count < 5 is always true — an infinite loop. Add count += 1 inside the loop.
fixed
count = 0
while count < 5:
    print(count)
    count += 1
