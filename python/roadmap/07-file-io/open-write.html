Open with 'w' to write (overwrites), 'a' to append. Always use with to auto-close.

Code

Example

with open('out.txt', 'w') as f:
    f.write('hello\n')
    f.writelines(['a\n', 'b\n'])

with open('log.txt', 'a') as f:
    f.write('new line\n')
