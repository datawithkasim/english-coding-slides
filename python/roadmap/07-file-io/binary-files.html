Binary files

Stage 7 · Files + I/O

Why

Why this matters

Open with 'rb' / 'wb' to read/write bytes (images, archives, audio). No automatic encoding.

Concept

What is it?

'rb'
read bytes
'wb'
write bytes

Open with 'rb' / 'wb' to read/write bytes (images, archives, audio). No automatic encoding.

Code

Example

with open('img.png', 'rb') as f:
    data = f.read()

with open('copy.png', 'wb') as f:
    f.write(data)
