Code

Example

import schedule, time

def job():
    print('running')

schedule.every(10).minutes.do(job)
schedule.every().day.at('09:00').do(job)

while True:
    schedule.run_pending()
    time.sleep(1)

🐛 Debug

What's wrong with this code?

buggy
count = 0
while count < 5:
    print(count)

Think first — then click next.

🐛 Debug

The bug

Bug: count never changes, so count < 5 is always true — an infinite loop. Add count += 1 inside the loop.
fixed
count = 0
while count < 5:
    print(count)
    count += 1
