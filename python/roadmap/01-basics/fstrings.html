Why

Why this matters

f-strings (formatted string literals, Python 3.6+) embed values inside strings using {expr}. The cleanest way to format text.

Concept

What is it?

f-strings (formatted string literals, Python 3.6+) embed values inside strings using {expr}. The cleanest way to format text.

Code

Example

name = 'Kasim'
hp = 73
print(f'{name} has {hp} HP')
print(f'{hp / 100:.2%}')   # 73.00%
print(f'{name:>10}')        # right-align width 10

The bug

Bug: total with no () prints the function object, not its result. Call it with total().
fixed
def total():
    return 2 + 3
print(total())
