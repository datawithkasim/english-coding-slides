Code

Example

s = '  Hello, World!  '
s.strip()         # 'Hello, World!'
s.upper()         # '  HELLO, WORLD!  '
s.lower()
s.replace('o', '0')
s.split(',')      # ['  Hello', ' World!  ']
s.startswith('  H')

🐛 Debug

The bug

Bug: .append() changes the list in place and returns None. Reassigning makes nums become None. Just call nums.append(4).
fixed
nums = [1, 2, 3]
nums.append(4)
print(nums)
