Code

Example

x = [3, 1, 2]
x.append(4)     # [3,1,2,4]
x.sort()        # [1,2,3,4]
x.pop()         # returns 4
x.reverse()     # in place
x.index(2)      # 1

What's wrong with this code?

buggy
count = 0
while count < 5:
    print(count)

Think first — then click next.

🐛 Debug

The bug

Bug: count never changes, so count < 5 is always true — an infinite loop. Add count += 1 inside the loop.
fixed
count = 0
while count < 5:
    print(count)
    count += 1
