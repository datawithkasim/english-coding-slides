Code

Example

p = {'name': 'pikachu', 'hp': 35}
p['hp']              # 35
p.get('type', '?')   # 'electric' or '?'
p['lvl'] = 12        # add
'name' in p          # True

What's wrong with this code?

buggy
count = 0
while count < 5:
    print(count)

Think first — then click next.

🐛 Debug

The bug

Bug: count never changes, so count < 5 is always true — an infinite loop. Add count += 1 inside the loop.
fixed
count = 0
while count < 5:
    print(count)
    count += 1
