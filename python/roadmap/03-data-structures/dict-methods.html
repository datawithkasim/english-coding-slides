Example

for k, v in d.items():
    print(k, v)

d.update({'c': 3})
d.setdefault('d', []).append(1)
d.pop('a')

The bug

Bug: total with no () prints the function object, not its result. Call it with total().
fixed

    return 2 + 3
print(total())
