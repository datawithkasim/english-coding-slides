bytes + bytearray

Stage 3 · Data Structures

Why

Why this matters

bytes is an immutable sequence of integers 0-255. bytearray is mutable. Used for binary data: files, network, encoding.

Concept

What is it?

bytes is an immutable sequence of integers 0-255. bytearray is mutable. Used for binary data: files, network, encoding.

Code

Example

data = b'hello'
data[0]              # 104 ('h')
ba = bytearray(data)
ba[0] = 72           # mutable

'café'.encode('utf-8')  # bytes
