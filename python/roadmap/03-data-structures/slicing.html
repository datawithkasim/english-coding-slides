Slicing

Stage 3 · Data Structures

Why

Why this matters

Access a sub-section of any sequence with [start:stop:step]. Negative indices count from end. Step can be negative.

Concept

What is it?

[start:stop]
stop excluded
[::step]
every step-th

Access a sub-section of any sequence with [start:stop:step]. Negative indices count from end. Step can be negative.

Code

Example

s = 'abcdefg'
s[1:4]    # 'bcd'
s[:3]     # 'abc'
s[-3:]    # 'efg'
s[::2]    # 'aceg' (every 2nd)
s[::-1]   # 'gfedcba' (reverse)

🐛 Debug

The bug

Bug: input() always returns a string. Comparing a string with a number raises TypeError. Convert with int().
fixed
age = int(input("Age? "))
if age > 18:
    print("Adult")
