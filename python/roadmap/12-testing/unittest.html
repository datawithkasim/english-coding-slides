Python's built-in test framework. Class-based, xUnit-style. Works everywhere — no install.

Code

Example

import unittest

class TestBattle(unittest.TestCase):
    def test_attack(self):
        p = Pokemon('a', 100)
        p.take_damage(10)
        self.assertEqual(p.hp, 90)

if __name__ == '__main__':
    unittest.main()

The bug

Bug: .append() changes the list in place and returns None. Reassigning makes nums become None. Just call nums.append(4).
fixed
nums = [1, 2, 3]
nums.append(4)
