Default arguments

Stage 4 · Functions

Why

Why this matters

Default values are evaluated once at def time. Never use mutable defaults — they persist across calls.

Concept

What is it?

Default values are evaluated once at def time. Never use mutable defaults — they persist across calls.

Code

Example

def greet(name='friend'):
    return f'Hi, {name}'

# DANGER:
def bad(items=[]):     # shared mutable!
    items.append(1)
    return items

# FIX:
def good(items=None):
    items = items or []

🐛 Debug

The bug

Bug: total with no () prints the function object, not its result. Call it with total().
fixed
def total():
    return 2 + 3
print(total())
