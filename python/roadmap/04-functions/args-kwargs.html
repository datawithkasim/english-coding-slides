*args + **kwargs

Stage 4 · Functions

Why

Why this matters

*args collects extra positional args into a tuple. **kwargs collects extra keyword args into a dict. Unpacking in calls works the same.

Concept

What is it?

*args
extra positional
**kwargs
extra keyword

*args collects extra positional args into a tuple. **kwargs collects extra keyword args into a dict. Unpacking in calls works the same.

Code

Example

def total(*nums):
    return sum(nums)

total(1, 2, 3)       # 6

def make(**opts):
    return opts

make(name='pika', hp=35)

The bug

Bug: firstname was never defined — the variable is first_name (with an underscore). Python raises NameError. Names must match exactly.
fixed

print(first_name)
