Why

Why this matters

An inner function that remembers variables from its enclosing scope, even after the outer function returns.

An inner function that remembers variables from its enclosing scope, even after the outer function returns.

Code

Example

def counter():
    n = 0
    def tick():
        nonlocal n
        n += 1
        return n
    return tick

c = counter()
c(); c(); c()   # 1 2 3

The bug
