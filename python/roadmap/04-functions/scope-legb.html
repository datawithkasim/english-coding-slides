Scope — LEGB

Stage 4 · Functions

Why

Why this matters

Python resolves names in order: Local, Enclosing, Global, Builtin. nonlocal modifies enclosing. global modifies module-level.

Concept

What is it?

L
local · inside function
E
enclosing · outer function

Python resolves names in order: Local, Enclosing, Global, Builtin. nonlocal modifies enclosing. global modifies module-level.

Code

Example

x = 'global'

def outer():
    x = 'enclosing'
    def inner():
        nonlocal x
        x = 'local'
    inner()
    print(x)   # 'local'

🐛 Debug

The bug

Bug: .append() changes the list in place and returns None. Reassigning makes nums become None. Just call nums.append(4).
fixed
nums = [1, 2, 3]
nums.append(4)
print(nums)
