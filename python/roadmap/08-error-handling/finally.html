finally + else

Stage 8 · Errors + Exceptions

Why

Why this matters

finally always runs (success or failure). else runs only if no exception. Use finally for cleanup.

finally always runs (success or failure). else runs only if no exception. Use finally for cleanup.

Code

Example

try:
    f = open('x.txt')
except FileNotFoundError:
    print('missing')
else:
    print('opened')
finally:
    print('done')

🐛 Debug

The bug

Bug: You can't join a number to a string with +. Python raises TypeError: can only concatenate str (not "int") to str. Wrap it in str().
fixed
age = 12
print("I am " + str(age) + " years old")
