Linked list

Stage 11 · Data Structures + Algorithms

Why

Why this matters

Sequence of nodes, each pointing to the next. O(1) insert/remove at head, O(n) random access. Python lists are arrays, not linked.

Code

Example

class Node:
    def __init__(self, val):
        self.val = val
        self.next = None

head = Node(1)
head.next = Node(2)
head.next.next = Node(3)
