Why

Why this matters

Recursion = function calls itself. DP = recursion + memoization. Solves big problems by combining small answers.

Code

Example

from functools import cache

@cache
def fib(n):
    if n < 2: return n
    return fib(n-1) + fib(n-2)

fib(100)   # instant
