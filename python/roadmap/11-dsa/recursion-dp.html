Recursion = function calls itself. DP = recursion + memoization. Solves big problems by combining small answers.

The idea

Recursion = call down, then return up

A recursive function calls a smaller copy of itself, then waits. The paused calls stack up until the base case — the smallest problem it can answer without recursing. Then each waiting call gets its answer and combines back up.

There's no loop. The stack of paused calls is the memory of where you were.

See it

Watch the call stack build & unwind

calls stack down to the base case, then values multiply back up
Worked example

fact(4), traced by hand

fact(4) = 4 * fact(3)
        = 4 * (3 * fact(2))
        = 4 * (3 * (2 * fact(1)))
        = 4 * (3 * (2 * 1))      ← base case: fact(1) = 1
        = 4 * (3 * 2)
        = 4 * 6
        = 24

Each line waits for the line below it — exactly the stack in the sim.

Code

Example

from functools import cache

@cache
def fib(n):
    if n < 2: return n
    return fib(n-1) + fib(n-2)

fib(100)   # instant
