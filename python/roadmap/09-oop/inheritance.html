Inheritance

Stage 9 · Object-Oriented Programming

Why

Why this matters

Subclasses inherit from parents. super() calls the parent's method. Prefer composition over deep hierarchies.

Concept

What is it?

Subclasses inherit from parents. super() calls the parent's method. Prefer composition over deep hierarchies.

Code

Example

class Animal:
    def speak(self): return 'noise'

class Dog(Animal):
    def speak(self): return 'woof'
    def fetch(self): ...

Dog().speak()    # 'woof'
Dog().fetch()    # ok

🐛 Debug

The bug

Bug: You can't join a number to a string with +. Python raises TypeError: can only concatenate str (not "int") to str. Wrap it in str().
fixed
age = 12
print("I am " + str(age) + " years old")
