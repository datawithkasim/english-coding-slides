__init__ — constructor

Stage 9 · Object-Oriented Programming

Why

Why this matters

Special method called when you instantiate. Set up initial state here. self is the new instance.

Concept

What is it?

called on creation

Special method called when you instantiate. Set up initial state here. self is the new instance.

Code

Example

class Battle:
    def __init__(self, p1, p2, weather='clear'):
        self.p1 = p1
        self.p2 = p2
        self.weather = weather
        self.turn = 1
