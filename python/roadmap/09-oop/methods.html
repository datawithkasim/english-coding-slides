Functions defined inside a class. First arg is self (the instance). Bound methods know their object.

Code

Example

class Counter:
    def __init__(self):
        self.n = 0
    def tick(self):
        self.n += 1
    def value(self):
        return self.n

c = Counter()
c.tick(); c.tick()
c.value()  # 2
