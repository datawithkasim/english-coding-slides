Multiple Inheritance + MRO

Stage 9 · Object-Oriented Programming

Why

Why this matters

Python supports multiple parents. Order matters — MRO (Method Resolution Order) decides which method wins.

Concept

What is it?

class D(B, C)
syntax
MRO
Method Resolution Order

Python supports multiple parents. Order matters — MRO (Method Resolution Order) decides which method wins.

Code

Example

class A:
    def hi(self): return 'A'
class B(A):
    def hi(self): return 'B'
class C(A):
    def hi(self): return 'C'
class D(B, C): pass

D().hi()       # 'B'
D.__mro__
