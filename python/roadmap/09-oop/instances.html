Stage 9 · Object-Oriented Programming

Why

Why this matters

Class attributes are shared. Instance attributes are per-object. Be careful with mutable class attrs.

Concept

What is it?

Class attributes are shared. Instance attributes are per-object. Be careful with mutable class attrs.

Code

Example

class Dog:
    species = 'Canis lupus'   # class attr
    def __init__(self, name):
        self.name = name      # instance attr

Dog.species
Dog('Rex').name

🐛 Debug

The bug

Bug: input() always returns a string. Comparing a string with a number raises TypeError. Convert with int().
fixed
age = int(input("Age? "))
if age > 18:
    print("Adult")
