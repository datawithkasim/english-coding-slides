Why

Why this matters

Auto-generate __init__, __repr__, __eq__ from class annotations. Less boilerplate, same power.

What is it?

Auto-generate __init__, __repr__, __eq__ from class annotations. Less boilerplate, same power.

Code

Example

from dataclasses import dataclass, field

@dataclass
class Pokemon:
    name: str
    hp: int = 100
    moves: list = field(default_factory=list)
