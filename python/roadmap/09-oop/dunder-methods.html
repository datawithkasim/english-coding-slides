Dunder (__magic__) methods

Stage 9 · Object-Oriented Programming

Why

Why this matters

Python calls these automatically: __str__ for print, __eq__ for ==, __len__ for len(), __iter__ for for-loops.

Concept

What is it?

Python calls these automatically: __str__ for print, __eq__ for ==, __len__ for len(), __iter__ for for-loops.

Code

Example

class Pokemon:
    def __init__(self, name): self.name = name
    def __str__(self):  return self.name
    def __eq__(self, o): return self.name == o.name
    def __repr__(self): return f'Pokemon({self.name!r})'

The bug

Bug: A 3-item list has indexes 0, 1, 2. colors[3] raises IndexError: list index out of range. The last index is len - 1.
fixed

print(colors[2])
