Code

Example

class Pokemon:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

pika = Pokemon('Pikachu', 35)
pika.name      # 'Pikachu'

🐛 Debug

The bug

Bug: .append() changes the list in place and returns None. Reassigning makes nums become None. Just call nums.append(4).
fixed
nums = [1, 2, 3]
nums.append(4)
print(nums)
