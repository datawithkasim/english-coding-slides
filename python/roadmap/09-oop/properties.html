@property

Stage 9 · Object-Oriented Programming

Why

Why this matters

Looks like an attribute, runs as a method. Use for computed values or validated access.

Concept

What is it?

@property
getter
@x.setter
setter

Looks like an attribute, runs as a method. Use for computed values or validated access.

Code

Example

class Circle:
    def __init__(self, r): self._r = r
    @property
    def area(self): return 3.14 * self._r**2
    @area.setter
    def area(self, val):
        raise AttributeError('read-only')
