Decorators

Stage 10 · Advanced Python

Why

Why this matters

Functions that wrap functions. @name above def applies a decorator. Used for caching, logging, auth, retries.

concept

Functions that wrap functions. @name above def applies a decorator. Used for caching, logging, auth, retries.

Code

Example

def log(fn):
    def wrapper(*args, **kw):
        print(f'calling {fn.__name__}')
        return fn(*args, **kw)
    return wrapper
