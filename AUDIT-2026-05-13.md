# Slide Library Pedagogy Audit — 2026-05-13

Audited against `TEMPLATE.md` (12 slots) + `PEDAGOGY.md` + `Desktop/dev/teaching-philosophy/README.md`.

Scope: 56 decks across 7 pre-template courses (rs002, rs003, rs004, web001, web002, web003, ai001). `rs001-text-adventure` excluded as conformant reference.

## Summary

- **Three pillars are systematically missing across every pre-template course**: slot 2 (Recap & Retrieve), slot 4 (Vocab Preview with Korean glosses), and slot 10 (Code Talk Frame / ESL sentence frame). Zero of 56 audited decks have any of these three.
- **PRIMM-P (Predict) is almost universally absent.** Decks open with a "Big picture" / "Problem" / "Concept" slide and jump straight to the worked example. Students never predict output before seeing it. Only a handful (rs002 W5, rs003 W7, rs004 W7, web002 W5, ai001 W1) have anything resembling a hook, and none use a `<details>` reveal pattern.
- **Auto-injected `<!-- INJECTED-EXTRAS-START -->` block is doing double duty as the Common-Mistake slot.** It supplies a generic edge-cases card, a buggy/fixed Debug pair, MCQ quiz, and a Practice task. The Debug pair partially satisfies slot 8 but is generic, not concept-specific, and worst of all, **paste-error contamination is rampant**: web001/002/003 and rs004 frequently show "IndentationError" / "Python raises" explanations for HTML, CSS, and JS bugs (line counts: 30+ instances).
- **Investigate (slot 7, animated trace) is implemented only twice in 56 decks**: rs002 W7 (`.picker`), rs003 W6 (`.viz-5`), rs004 — none, web002 W6 (`.viz-3`). All other procedural-execution lessons (loops, gravity, collision, state machines, events) lack the prebuilt animation classes the template mandates.
- **Strong points across all courses**: slot 1 (Title + Objective with Korean tagline), slot 5 (Concept / Notional Machine usually NO code), slot 6 (Run / Worked Example with code-adjacent output box), slot 11 (Your Turn checklist), slot 12 (Close & Bridge with next-week tease) — these are consistently present and well-executed.
- **MCQ quiz contamination is severe and embarrassing**: the auto-injected "Q2 — Looking at the slide titles…" question yields garbled run-on titles ("Pokémon​Lists", "Catch Bad​Picks", "Setup &​Game Window", "Functions —​Reuse Code"). This is a visible polish bug.
- **Cross-language paste errors in MCQ Q3**: web001 W1 quiz includes Python `pirnt` debug; web002 W4 quiz asks about Python `input()` for a JS lesson; web003 W7 quiz asks Python `if i = 5` for a JS lesson; ai001 throughout uses Python bug fixtures.
