Bonus

"Show me alternatives"

"Show me 2 other ways to write the same
function. Briefly explain why each one
might be useful."

You learn there's no one way. Just trade-offs.

Bonus

"Make it simpler"

"Can this code be simpler?
Use fewer lines if possible. Don't
break what it does."

Often AI rewrites in half the lines. Now you see what's essential.

Concept

The "explain back" test

Read the code. Then close the screen.

Try to explain it out loud to a friend or sibling.

Stuck? Open it again. Read more.

If you can teach it, you got it.

설명할 수 있으면 이해한 것

Tool

Real-time line annotations

Hover over symbols/functions in Replit's editor → docs pop up.

Use both AI explanation AND editor docs together.

⚠️ Watch

AI explanations can lie

Sometimes AI says "this does X" but the code actually does Y.

Trust your running code more than the explanation.

Test the explanation: change something → does it match?

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
