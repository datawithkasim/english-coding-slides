최종 프로젝트

Goal

Build something that's yours

  • Your own idea
  • Broken into 5+ steps
  • 3+ iteration prompts
  • 1+ debugging round
  • You can explain the final code
Idea

How to start

Write a one-liner: "I want to make..."

"...a habit tracker for studying"
"...a meme generator for my friends"
"...a recipe finder for my mom"

한 줄로 시작

Plan

Break into 5 steps

[1] Basic UI — input + list
[2] Add new items
[3] Mark items as done
[4] Save to localStorage
[5] Style it nicely

Write all 5 prompts before running any.

Recap

All 7 weeks combine

  • W1 — first chat
  • W2 — specific prompts
  • W3 — context
  • W4 — step-by-step
  • W5 — iterate
  • W6 — debug
  • W7 — understand
  • W8 — full project!
Track it

Keep a prompt log 📒

Save EVERY prompt you use, in order:

v1 (build): "make todo screen..."
v2 (add): "make 'add' button work..."
v3 (fix): "the X button doesn't..."
v4 (polish): "round the corners..."

프롬프트 노트

Final test

Can you explain it? 🎤

Without looking at code, answer:

  • What does each section do?
  • What was the hardest part?
  • How does the data flow?
  • What would you do without AI?
Pro tip

Real apps need real users

Send your app to:

  • 1 family member
  • 1 friend
  • Watch them try it WITHOUT helping
  • Note what confuses them
  • Iterate one more time!
Your turn!

Ship your app 🚀

  • Pick an idea you'd actually use
  • Plan 5-7 prompt steps
  • Run them in order
  • Iterate + debug
  • Get AI to explain the final code
  • Demo it!
