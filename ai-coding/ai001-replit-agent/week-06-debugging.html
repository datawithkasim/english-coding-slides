Debugging
with AI

Explain bugs clearly

AI에게 오류 설명

Problem

"It doesn't work" isn't enough

"It's broken!"
🤔 ...what's broken? where? when?

AI can't read your screen. Tell it everything.

Recipe

Good debug prompt has 4 parts

  1. What you tried to do
  2. What you expected to happen
  3. What actually happened
  4. The error message (copy-paste)
Code

Example debug prompt

"When I click the +1 button, the score
should go up. But nothing happens.

In the F12 console I see this red error:

  Uncaught TypeError: Cannot read property
  'textContent' of null
  at index.js:7

Find the problem and fix it. Also explain
why it broke in plain words."
Tool

F12 → Console = your friend

  • Press F12 in Chrome
  • Click "Console" tab
  • See errors in red
  • Copy the EXACT message
  • Paste into your prompt

Exact errors = exact fixes.

Pattern

"What did you change?"

After AI fixes the bug, ask:

"Thanks. Now explain what you changed
and why the old code was broken.
Use simple words."

You learn the bug → don't repeat it.

Concept

Edge case bugs too

"The button SHOULD be disabled when
the input is empty.

Right now it's still clickable when empty.
That's wrong. Fix it."

"Should ___ but instead ___" works for non-error bugs.

⚠️ Watch

Trust but verify

AI fixes might:

  • Fix the symptom but not the cause
  • Break something else
  • Be totally wrong

Always RUN the code after a fix. Test the bug + the rest.

Tip

If AI keeps failing → reset

If 3 fix-prompts didn't work, try:

  • Start fresh chat with the file
  • Re-explain context from scratch
  • Ask "what's the simplest version that would work?"

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
