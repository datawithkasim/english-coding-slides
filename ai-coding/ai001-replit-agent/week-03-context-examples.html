Concept

Add 3 things to your prompt

  • Who you are (age, role)
  • Why you're building it
  • For whom (the user)

Code

Add context

"I'm 12 years old and this is my first
coding project.
I'm building a site to share with friends.

Make a Pinterest-style cat photo gallery.
Use cute warm colors. Don't use complex
words in any UI text."
Concept

Add examples = "like this"

"Build a homepage like Notion's homepage —
clean, minimal, big headline, with a
single 'Get started' button.

Reference: notion.so"

AI knows famous sites. Use their names!

Concept

Negative constraints

"Build a quiz app.

Don't use any external libraries.
Don't use complicated words in the UI.
Don't add features I didn't ask for."

"Don't" lines work as well as "do" lines.

Pattern

Full template

[Context] I'm 12, this is my 3rd project
[Goal] Make a recipe app for my mom
[Features] List recipes, search, save
[Style] Like Notion, soft greens
[Don't] No login required
Watch out

Don't overload

  • Pick the most important context
  • 2-3 negative rules max
  • 1-2 example references
  • Wall-of-text → AI gets confused

Brief but rich.

Tip

Save your good prompts!

Keep a notebook (digital or paper) of prompts that worked.

Reuse them with small tweaks for the next project.
