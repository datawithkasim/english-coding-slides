What's a prompt?

A prompt = the instruction you give the AI.

"Make a webpage that says Hello"

↑ that sentence is a prompt.

⚠ Edge cases

Gotchas + pitfalls

Be specific
Vague prompts get vague code. Name the file, function, inputs, expected output.
Read the diff
The AI rewrote your file? Always read what changed before accepting.
Small steps win
One feature per prompt > one giant 'build my app' prompt.
Test what it wrote
AI-written code looks right and breaks. Always run it.

Coding practice

Write a specific, well-scoped prompt that fixes ONE bug in a file. Include the filename, the function, and the expected behavior.
starter
# Example prompt structure:
# In <filename>, the function <name>() <does X> but should <do Y>.
# Change just <which line/section> so that <expected behavior>.
# Don't touch <other functions / files>.

Open your editor. Save as practice.py (or .html). Run it. Iterate.
