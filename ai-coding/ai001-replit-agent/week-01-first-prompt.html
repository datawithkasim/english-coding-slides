Concept

What's a prompt?

A prompt = the instruction you give the AI.

"Make a webpage that says Hello"

↑ that sentence is a prompt.

AI에게 주는 지시

First steps

Open Replit Agent

  • Sign in to Replit
  • Create new Repl → choose Agent
  • Type your prompt in the chat box
  • Watch AI build files

Replit 계정 + Agent 활성화

Code

First prompt example

"Build a simple web page.
The title says 'Hello World',
the background is light yellow,
and the text is dark green."

Hit send. AI makes the file. Click Run. ✨

After

Read what AI made 👀

  • What files did it create?
  • Click each file — read it
  • Don't worry if you don't get every line
  • Run it — see if it does what you asked

Don't blindly accept!

Iterate

Ask for changes

"Make the title bigger and add a smiley emoji"

AI updates the same files. Run again — instant.

계속 수정 요청

⚠️ Watch

AI can mess up

  • Sometimes wrong code
  • Sometimes weird design choices
  • Sometimes too much or too little
  • That's fine — fix it next prompt!

First try ≠ final result.
