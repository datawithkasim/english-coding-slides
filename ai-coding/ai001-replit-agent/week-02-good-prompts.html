What makes a good prompt

🎯
Specific
🖼️

Compare

3 levels

❌ Bad: "make a cool web page"
🟡 Mid: "make an about-me page"
✅ Good: "make an about-me page with sections for name, age, hobbies, in pastel colors"
Concept

Be specific about features

"Build a calculator web app:
• +, −, ×, ÷ buttons
• Number buttons 0-9
• Display screen
• Reset button
Use a blue theme with rounded buttons."

List features. AI ticks them off one by one.

Concept

Be clear about look

  • Color theme: "blue", "warm earth tones"
  • Style: "minimal", "playful", "kid-friendly"
  • Vibe: "like a Notion page"
  • Specifics: "rounded corners", "big buttons"
Concept

Constraints help too

"...
• Don't use any libraries
• Keep it under 50 lines
• Use only HTML and CSS, no JavaScript
• Make it responsive"

"Don't" rules are powerful. AI follows them.

Pattern

The 3-part recipe 📝

1. What to build
2. Features it must have
3. Look + constraints
⚠️ Watch

Don't say "make it nice"

"Nice" means nothing to AI.

Replace with:

  • "clean Apple-style design"
  • "big text, lots of white space"
  • "buttons with shadows"

Specific = consistent.

⚠ Edge cases

Gotchas + pitfalls

Be specific
Vague prompts get vague code. Name the file, function, inputs, expected output.
Read the diff
The AI rewrote your file? Always read what changed before accepting.
Small steps win
One feature per prompt > one giant 'build my app' prompt.
Test what it wrote
AI-written code looks right and breaks. Always run it.
