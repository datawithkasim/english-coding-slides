Iterate —
Tweak Results

First try is rarely final

수정과 반복

Big idea

Don't restart. Refine.

If AI's result is 70% right → don't kill it.

Tell AI exactly what to change.

Iteration is the secret.

반복은 부끄러운 게 아닙니다

Concept

Be specific about changes

"Make these changes:

• Submit button: orange → green
• Menu font: a bit smaller
• Hero section: leave alone"

Bullet list. Clear. Includes "leave alone" too.

Pattern

"Keep ___ but change ___"

"I love the layout. Keep that.

But change:
- Title font to a serif
- Background from white to cream"

Says what you like + what to change. AI doesn't blow up the good parts.

Concept

Constraints save you

"Change the button color to green.

DON'T change:
- The button size
- The button position
- Anything outside the button"

Belt and suspenders. Stops AI from "improving" things you didn't ask for.

Concept

Reference what you see

"The blue gradient on the homepage —
make it darker.

The card on the right of the gallery —
add a shadow."

Point at things by location/color. AI can find them.

Tip

Iterate small

  • 1-3 tweaks per iteration prompt
  • Run after each → check it worked
  • If AI breaks something → revert + try again
  • Save versions you like!
⚠️ Watch

Don't be too vague

"Make it better"  // 🚫 better how?

"Make it more professional"  // 🚫 too vague

"Move the button 8px right"  // ✅ specific

Specific words = specific results.

Pro tip

Track what changed

Note one line per iteration: "what did this prompt change?"

v1 — base layout
v2 — bigger title
v3 — green submit button
v4 — added card shadows

⚠ Edge cases

Gotchas + pitfalls

Test small
Run with a tiny input first. If that breaks, big input won't help.
Read the error
Python tells you the line and the type. Copy the exact text.
One change at a time
If you change three things and it breaks, you don't know which broke it.
Save often
Ctrl-S after every change. Or use a real editor that autosaves.
