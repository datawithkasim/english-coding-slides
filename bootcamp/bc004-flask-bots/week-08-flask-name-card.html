SLOT 10
🐛 Debugactivity

Static path wrong

<link href="static/style.css">
404 — CSS doesn't load on /about page
Reveal fix

Use leading slash: /static/style.css. Or url_for('static', filename='style.css').

🐛 Debugactivity

Image 404

URLs are case-sensitive. Match: me.png.

SLOT 12
🐛 Debugactivity

MIME type

<link href="/static/style">
# file: style (no extension)

Rename to style.css. Extension tells browser the file kind.
