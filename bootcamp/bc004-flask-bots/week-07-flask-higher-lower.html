SLOT 9
⚠️ Watch out

Forgot the converter

✗ broken 
@app.route("/guess/<g>")
def play(g):
    return g + 1

→ TypeError: str + int

✓ fixed 
@app.route("/guess/<int:g>")
def play(g):
    return str(g + 1)

→ g is int, return str

SLOT 10
🐛 Debugactivity

int cast on URL param

@app.route("/guess/<g>")
def play(g):
    if g < target: ...
TypeError: '<' not supported between str and int
Reveal fix

URL parts are strings. Add <int:g> or cast: int(g).

URL은 항상 문자열 — int 변환 필요
