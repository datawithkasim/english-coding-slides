SLOT 6
Run it

Save a message

from flask import Flask, request, render_template

@app.route("/msg", methods=["GET", "POST"])
def msg():
    if request.method == "POST":
        name = request.form["name"]
        text = request.form["text"]
        return f"Thanks, {name}!"
    return render_template("form.html")

SLOT 9
⚠️ Watch out

Forgot the method

✗ broken 
@app.route("/save")
def save():
    request.form["x"]

→ 405 Method Not Allowed

✓ fixed 
@app.route("/save",
            methods=["POST"])

→ accepts POST

GET vs POST

<form action="/save">
  <input name="text">
</form>
Data shows up in URL: /save?text=hi
Reveal fix

Add method="POST" to the form. Default is GET (URL params).
