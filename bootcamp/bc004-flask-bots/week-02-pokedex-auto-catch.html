SLOT 6
Run it

Catch them all

import time
driver.get("file:///pokedex.html")

for i in range(10):
    btn = driver.find_element(By.ID, "catch")
    name = driver.find_element(By.ID, "who").text
    print(f"Caught {name}!")
    btn.click()
    time.sleep(0.4)
▸ Output
Caught Pikachu! Caught Bulbasaur! …

SLOT 9
⚠️ Watch out

No safety exit

✗ broken 
while True:
    btn.click()

→ forever, your laptop hangs

✓ fixed 
for i in range(10):
    btn.click()

→ 10 then stops

SLOT 11
🐛 Debugactivity

Race condition

btn.click()
name = driver.find_element(By.ID, "who").text
StaleElementReferenceException — page changed too fast
Reveal fix

Add time.sleep(0.3) after click, OR use WebDriverWait.

클릭 후 페이지 바뀌는 시간 — 잠깐 기다리기

SLOT 12
🐛 Debugactivity

Infinite loop guard

while driver.find_element(By.ID, "catch"):
    btn.click()
Runs forever — find_element raises, doesn't return None
Reveal fix

Use a counter: for i in range(20). Always cap loops.
