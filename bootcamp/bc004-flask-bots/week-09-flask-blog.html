SLOT 9
⚠️ Watch out

Missing endfor

✗ broken 
{% for p in posts %}
  <h2>{{ p.title }}</h2>

→ TemplateSyntaxError

✓ fixed 
{% for p in posts %}
  <h2>{{ p.title }}</h2>
{% endfor %}

→ closes the loop

SLOT 11
🐛 Debugactivity

Autoescape

posts = [{"body": "<b>Bold</b>"}]
# template: {{ p.body }}
Shows literal <b>Bold</b> not bold text
Reveal fix

Jinja auto-escapes HTML (safety). Use {{ p.body | safe }} if you trust the source.

HTML 자동 이스케이프 — | safe 필터
