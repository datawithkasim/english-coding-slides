SLOT 9
⚠️ Watch out

Missing @ decorator

✗ broken 
app.route("/")
def home(): return "hi"

→ route not registered

✓ fixed 
@app.route("/")
def home(): return "hi"

→ @ wraps the function

Import error

🐛 Debugactivity

Port in use

app.run()
OSError: port 5000 already in use
Reveal fix

Another server is running. Stop it (Ctrl-C) or pick a new port: app.run(port=5050).
