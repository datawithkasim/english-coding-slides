SLOT 6
Run it

Fill the local form

from selenium import webdriver
from selenium.webdriver.common.by import By

driver = webdriver.Chrome()
driver.get("file:///volunteer.html")

driver.find_element(By.ID, "name").send_keys("Mia")
driver.find_element(By.ID, "grade").send_keys("5")
driver.find_element(By.ID, "submit").click()
▸ Local file only — no real website
Form submitted ✓

SLOT 10
🐛 Debugactivity

Element not found

driver.find_element(By.ID, "Name")
NoSuchElementException: id="Name"
Reveal fix

IDs are case-sensitive. HTML had id="name" (lowercase).

ID는 대소문자 구분 — HTML과 똑같이 쓰기

SLOT 11
🐛 Debugactivity

Wait too short

driver.get(url)
driver.find_element(By.ID, "submit").click()
ElementNotInteractable — page still loading
Reveal fix

Add WebDriverWait or time.sleep(1) before clicking.

페이지 다 로드되기 전에 클릭하면 안 됨
