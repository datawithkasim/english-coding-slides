SLOT 6
Run it

Log one reading

import speedtest, datetime

st = speedtest.Speedtest()
mbps = st.download() / 1_000_000
now  = datetime.datetime.now().strftime("%H:%M")

with open("log.txt", "a") as f:
    f.write(f"{now} · {mbps:.1f} Mbps\n")
▸ log.txt now has
14:02 · 52.3 Mbps

SLOT 9
⚠️ Watch out

Wrong file mode

✗ broken 
open("log.txt", "w")

→ erases old log each run

✓ fixed 
open("log.txt", "a")

→ keeps history

SLOT 12
🐛 Debugactivity

Parse Mbps wrong

mbps = st.download()
print(mbps)  # 52000000.0
Output is in bits per second, not Mbps
Reveal fix

Divide by 1 million: mbps = st.download() / 1_000_000.

bps → Mbps 변환 필요
