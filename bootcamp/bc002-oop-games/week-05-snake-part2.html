SLOT 6
Run it

Food class

from turtle import Turtle
import random

class Food(Turtle):
    def __init__(self):
        super().__init__("circle")
        self.color("red")
        self.penup()
        self.refresh()

    def refresh(self):
        x = random.randint(-280, 280)
        y = random.randint(-280, 280)
        self.goto(x, y)

SLOT 9
⚠️ Watch out

Forgot super().__init__

✗ broken 
class Food(Turtle):
    def __init__(self):
        self.color("red")

AttributeError — turtle not set up.

✓ fixed 
class Food(Turtle):
    def __init__(self):
        super().__init__()
        self.color("red")

Parent init must run first.
