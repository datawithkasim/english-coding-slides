Concept

The turtle is a pen 🖊️

forward(n)go n steps
right(d)turn d degrees
color(c)change ink

SLOT 9
⚠️ Watch out

Window closes instantly

✗ broken 
t = Turtle()
t.forward(100)

Script ends → window closes.

✓ fixed 
t = Turtle()
t.forward(100)
Screen().mainloop()

mainloop keeps window open.

SLOT 10
🐛 Debugactivity

No window stays open

from turtle import Turtle
t = Turtle()
t.forward(100)
Window flashes open, then closes
Reveal fix

Import Screen and call Screen().mainloop() at the end.

mainloop() 빠지면 창이 바로 닫힘

SLOT 11
🐛 Debugactivity

Wrong color

t.color("kimchi")
TurtleGraphicsError: bad color string: kimchi
Reveal fix

Use a real color name: "red", "orange", or hex "#ff7849".

색 이름은 영어 표준 — 또는 hex 코드

SLOT 12
🐛 Debugactivity

Drawing off-screen
