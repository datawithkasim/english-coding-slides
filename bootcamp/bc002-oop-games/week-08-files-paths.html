SLOT 9
⚠️ Watch out

Wiped your data

✗ broken 
f = open("notes.txt", "w")
f.write(note)

"w" overwrites old notes.

✓ fixed 
with open("notes.txt", "a") as f:
    f.write(note + "\n")

"a" keeps history.

SLOT 10
🐛 Debugactivity

Wrong mode

with open("notes.txt", "r") as f:
    f.write("hello")
io.UnsupportedOperation: not writable
Reveal fix

Open with "w" or "a" to write. "r" is read-only.

쓰기는 "w" 또는 "a" 모드 필요

SLOT 11
🐛 Debugactivity

Forgot to close

f = open("notes.txt", "w")
f.write("hi")
# file never closed
Sometimes writes are not flushed to disk
Reveal fix

Use with open(...) as f: — auto-closes safely on exit.

with 문이 자동으로 close 처리

SLOT 12
🐛 Debugactivity

File not found

with open("diary.txt") as f:
    text = f.read()
FileNotFoundError: [Errno 2] No such file
Reveal fix

Check the path. File must exist for read mode. Or open with "a" first to create it.

읽기 전에 파일이 존재해야 함
