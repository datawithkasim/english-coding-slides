SLOT 9
⚠️ Watch out

Method vs call

✗ broken 
if today.weekday == 0:
    print("Monday!")

Never True — comparing method object.

✓ fixed 
if today.weekday() == 0:
    print("Monday!")

Call with () to get the number.

🐛 Debugactivity

Timezone mismatch

today = datetime.utcnow()
print(today.day)
Korea is +9h ahead — UTC date can be wrong
Reveal fix

Use datetime.now() for local time, or set a timezone with zoneinfo.

SLOT 12
🐛 Debugactivity

Missing pad zeros

now = datetime.now()
print(f"{now.month}-{now.day}")
Output "5-7" — not "05-07"
Reveal fix

Pad with format: f"{now.month:02d}-{now.day:02d}".
