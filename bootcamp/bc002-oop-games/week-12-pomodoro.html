Countdown

def count_down(secs):
    label.config(text=f"{secs:02d}")
    if secs > 0:
        win.after(1000, count_down, secs - 1)
    else:
        label.config(text="Done!")

SLOT 9
⚠️ Watch out

Timer runs once

✗ broken 
def tick():
    secs -= 1
    label.config(text=secs)

No re-schedule.

✓ fixed 
def tick(secs):
    label.config(text=secs)
    if secs > 0:
        win.after(1000, tick, secs-1)

Chain after() each call.

SLOT 10
🐛 Debugactivity

after() not chained

def count(s):

TypeError: count() missing 1 required positional argument: 's'
Reveal fix

Pass the next value: win.after(1000, count, s-1).

Type confusion

secs = entry.get()  # str!
