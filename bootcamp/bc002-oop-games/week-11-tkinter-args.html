SLOT 6
Run it

Mile to Km

import tkinter as tk

def convert():
    miles = float(entry.get())
    label.config(text=f"{miles*1.609:.1f} km")

win = tk.Tk()
entry = tk.Entry(win); entry.pack()
tk.Button(win, text="Go", command=convert).pack()
label = tk.Label(win, text="--"); label.pack()

win.mainloop()

⚠️ Watch out

Window never appears

✗ broken 
win = tk.Tk()

Script ends, no event loop.

✓ fixed 
win = tk.Tk()
tk.Label(win, text="hi").pack()
win.mainloop()
