SLOT 6
Run it

Arrow keys move turtle

from turtle import Turtle, Screen

t = Turtle()
screen = Screen()

def go():    t.forward(10)
def left():  t.left(10)

screen.listen()
screen.onkey(go,   "w")
screen.onkey(left, "a")
screen.mainloop()
▸ Press W
turtle steps forward 10

SLOT 9
⚠️ Watch out

Called instead of passed

✗ broken 
screen.onkey(go(), "w")

Runs go once now. Press W: nothing.

✓ fixed 
screen.onkey(go, "w")

Pass the function. Runs on each press.

SLOT 10
🐛 Debugactivity

Pressing W does nothing

screen.onkey(go(), "w")
screen.listen()
go() ran once at startup, then never again
Reveal fix

Remove the () from go(). Pass the function reference: onkey(go, "w").

함수를 전달할 때는 () 없이

SLOT 11
🐛 Debugactivity

Shared state

t = Turtle()
t.forward(100)
t.forward(50)
print(t.xcor())
Expected 50, got 150 — values stack on same turtle
Reveal fix

One instance keeps its own position. Make a new Turtle() if you want a fresh start.

같은 인스턴스는 상태가 이어짐

SLOT 12
🐛 Debugactivity

Listener missing

Call screen.listen() before mainloop() so the screen accepts keys.
