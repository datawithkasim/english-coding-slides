SLOT 9
⚠️ Watch out

Choppy animation

✗ broken 
while game_on:
    snake.move()

Repaints between each segment — flicker.

✓ fixed 
screen.tracer(0)
while game_on:
    snake.move()
    screen.update()

tracer off → one update per tick.

SLOT 10
🐛 Debugactivity

Snake flickers

snake = Snake()
while game_on:
    snake.move()
Flicker — turtle auto-redraws each segment
Reveal fix

Set screen.tracer(0) once and call screen.update() in the loop.

tracer(0) + update() 로 한 번에 그리기

SLOT 11
🐛 Debugactivity

Body doesn't follow

for i in range(0, len(segs)):
    new = segs[i-1].pos()
    segs[i].goto(new)
Head jumps onto tail — wrong loop direction
Reveal fix

Move tail first: range(len(segs)-1, 0, -1), then forward the head.

꼬리부터 거꾸로 이동시켜야 함

SLOT 12
🐛 Debugactivity

Too fast to see

while game_on:

Add time.sleep(0.1) between ticks to slow the loop.

sleep 빠지면 너무 빨라서 안 보임
