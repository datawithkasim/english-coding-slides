SLOT 9
⚠️ Watch out

Bare except hides bugs

✗ broken 
try:
    risky()
except:
    pass

Hides every error — even typos.

✓ fixed 
try:
    risky()
except ValueError as e:
    print(e)

Catch only what you expect.

SLOT 10
🐛 Debugactivity

Bare except hides bug

try:
    score = int(input("Score? "))
    print(scoer)  # typo

User sees "bad" — but real bug is a typo
Reveal fix

Catch ValueError specifically. Then the typo surfaces as NameError.
