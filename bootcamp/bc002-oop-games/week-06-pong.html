SLOT 9
⚠️ Watch out

Paddle escapes

✗ broken 
def go_up(self):
    self.goto(self.xcor(),
            self.ycor() + 20)

Goes past the wall.

✓ fixed 
def go_up(self):
    if self.ycor() < 250:
        self.goto(self.xcor(),
                self.ycor() + 20)

Clamp at 250.

SLOT 11
🐛 Debugactivity

Ball bounces wrong

if ball.ycor() > 280:
    ball.x_move *= -1
Top hit flips X instead of Y — sideways escape
Reveal fix

Top/bottom walls flip y_move. Left/right walls flip x_move.

위/아래는 y 반전, 좌/우는 x 반전

SLOT 12
🐛 Debugactivity

Score not updating

class Score(Turtle):
    def point(self):
        self.score += 1
Score increments internally but screen text never changes
Reveal fix

Call self.clear() then self.write(...) after every change.

점수 변경 후 clear + write 다시 호출
