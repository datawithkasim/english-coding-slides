SLOT 9
⚠️ Watch out

Forgot the parentheses

✗ broken 
quiz = QuizBrain
quiz.next_question()

No object made — class itself stored.

✓ fixed 
quiz = QuizBrain(qs)
quiz.next_question()

() builds the object.

SLOT 10
🐛 Debugactivity

Forgot ()

quiz = QuizBrain
print(quiz.score)
AttributeError: type object 'QuizBrain' has no attribute 'score'
Reveal fix

Add (): quiz = QuizBrain(qs). Without () you only kept the class.

() 빠지면 객체가 안 만들어짐

SLOT 11
🐛 Debugactivity

Wrong attribute name

quiz = QuizBrain(qs)
print(quiz.scor)
AttributeError: 'QuizBrain' object has no attribute 'scor'
Reveal fix

Typo: scor → score. Match the exact name set in __init__.

속성 이름은 정확히 같아야 함

SLOT 12
🐛 Debugactivity

Class vs instance

QuizBrain.next_question()
TypeError: missing 1 required positional argument: 'self'
Reveal fix

Call methods on the instance, not the class. quiz.next_question().
