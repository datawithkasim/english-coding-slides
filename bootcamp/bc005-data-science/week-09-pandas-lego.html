SLOT 6
Run it

Merge + summarize

sets    = pd.read_csv("sets.csv")
themes  = pd.read_csv("themes.csv")

both = pd.merge(sets, themes,
                left_on="theme_id",
                right_on="id")

by_year = both.groupby("year")\
              ["num_parts"].mean()
print(by_year.tail())
▸ Mean parts per set by year
2021 267.4
2022 283.2

SLOT 9
⚠️ Watch out

Duplicate rows after merge

✗ broken 
pd.merge(sets, themes, on="id")

Wrong key — sets has many per theme.

✓ fixed 
pd.merge(sets, themes,
         left_on="theme_id",
         right_on="id")

SLOT 10
🐛 Debugactivity

Find the bug — missing key

pd.merge(sets, themes, on="set_id")
KeyError: 'set_id' not in themes
Reveal fix

themes uses id, not set_id. Use left_on + right_on.

두 표의 키 이름 다를 때 left_on / right_on 사용

SLOT 11
🐛 Debugactivity

Find the bug — lost rows

both = pd.merge(sets, themes,
                left_on="theme_id",
                right_on="id")
print(both.shape)  # fewer than sets
10k rows after merge — but sets had 12k
Reveal fix

Default is inner. To keep every set, use how="left".

inner 조인은 매칭 안 되면 행을 버림 — left 조인 사용

SLOT 12
🐛 Debugactivity

Find the bug — duplicates

both = pd.merge(sets, themes,
                left_on="theme_id",
                right_on="id")
print(both.shape)  # 24k, double!
Each set appears twice — themes has duplicate ids
Reveal fix

Check + clean: themes.drop_duplicates("id", inplace=True).
