SLOT 10
🐛 Debugactivity

Find the bug — nothing shows

plt.plot(years, py)
plt.xlabel("Year")
Script runs, prints nothing, no chart window
Reveal fix

Add plt.show() at the end. In notebooks, also use %matplotlib inline.

plt.show() 호출해야 창이 열림

SLOT 11
🐛 Debugactivity

Find the bug — length mismatch

x = [2018, 2019, 2020]
y = [10,   20]
plt.plot(x, y)
ValueError: x and y must have same first dimension
Reveal fix

Lists must match length. Drop the extra x value or add the missing y.

x와 y 길이 같아야 함

SLOT 12
🐛 Debugactivity

Find the bug — no legend

plt.plot(x, py)
plt.plot(x, java)
plt.legend(["Python", "Java"])
Legend shows but feels fragile — order-based
Reveal fix

Pass label= on each plot, then call plt.legend(). Robust to order.

각 선에 label= 붙이고 legend() 호출이 안정적
