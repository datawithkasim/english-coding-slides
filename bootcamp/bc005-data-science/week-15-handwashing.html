SLOT 6
Run it

Two-sample t-test

from scipy.stats import ttest_ind

before = df[df.washed == False]["death_rate"]
after  = df[df.washed == True]["death_rate"]

t, p = ttest_ind(before, after, equal_var=False)
print(f"t = {t:.2f}, p = {p:.4f}")
▸ Output
t = 6.43, p = 0.0000

⚠️ Watch out

p-value misreading

✗ broken 
"p = 0.001 means
the effect is 99.9% real"

Misstatement of probability.

✓ fixed 
"If no real difference,
this result is rare."

p is about the data given H₀.

SLOT 10
🐛 Debugactivity

Find the bug — groups mixed up

before = df.death_rate
after  = df[df.washed]["death_rate"]
ttest_ind(before, after)
"before" includes washed rows — groups overlap
Reveal fix

Define both sides cleanly: before = df[~df.washed][...], after = df[df.washed][...].

두 그룹이 서로 겹치면 안 됨

SLOT 11
🐛 Debugactivity

Find the bug — wrong tail

t, p = ttest_ind(before, after)
# claim: "handwashing is BETTER"
print(p)  # two-tailed
Direction claim uses a two-tailed p — over-conservative
Reveal fix

For a one-direction claim use alternative="greater" (modern scipy).

방향 있는 가설 = 단측 검정

SLOT 12
🐛 Debugactivity

Find the bug — wrong sentence

p = 0.20
# "There is no difference."
Not significant ≠ no difference exists
Reveal fix

Say: "We did not find a significant difference." Small samples can hide real effects.

"차이 없음"이 아니라 "차이 못 찾음"
