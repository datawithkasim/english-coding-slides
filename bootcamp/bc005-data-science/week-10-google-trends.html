Find the bug — wrong dtype

df.resample("ME").mean()

Parse before indexing: df["date"] = pd.to_datetime(df["date"]). Confirm with df.dtypes.

date 컬럼 datetime으로 변환 필요

SLOT 11
🐛 Debugactivity

Find the bug — deprecated alias

monthly = df.resample("M").mean()
FutureWarning: 'M' is deprecated, use 'ME' instead
Reveal fix

In modern pandas, use "ME" (month-end) or "MS" (month-start).

최신 pandas는 'M' 대신 'ME' 사용

SLOT 12
🐛 Debugactivity

Find the bug — tz mismatch

a = pd.to_datetime("2024-01-01", utc=True)
b = pd.to_datetime("2024-01-01")
print(a == b)
TypeError: cannot compare tz-naive and tz-aware
Reveal fix

Match timezones — either both UTC: b.tz_localize("UTC"), or both naive.
