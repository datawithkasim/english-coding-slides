SLOT 9
⚠️ Watch out

Secrets in git

✗ broken 
app.secret_key = "super-secret"

Anyone on GitHub can read it.

✓ fixed 
app.secret_key = os.environ["SECRET_KEY"]

Set in DO dashboard, never in code.

SLOT 10
🐛 Debugactivity

Find the bug — build fails

# build log
ERROR: Could not find a version
that satisfies the requirement Flask==99.0.0
Build failed — bad version pin
Reveal fix

Check requirements.txt. Use real versions: flask==3.0.3. Or freeze locally: pip freeze > requirements.txt.

requirements.txt 버전 잘못 — 실제 존재하는 버전으로

SLOT 11
🐛 Debugactivity

Find the bug — ModuleNotFoundError

# DO runtime log
ModuleNotFoundError: No module
named 'flask_login'
App imports flask_login — but DO didn't install it
Reveal fix

Add flask-login to requirements.txt and push again.

로컬에 설치만 했고 requirements.txt 누락

SLOT 12
🐛 Debugactivity

Find the bug — env var missing

app.secret_key = os.environ["SECRET_KEY"]
KeyError: 'SECRET_KEY'
Reveal fix

Set the env var in the DO app settings, or use os.environ.get("SECRET_KEY", "dev") for safe default.

DO 대시보드에서 환경 변수 설정 필요
