🐛 Debugactivity

Find the bug — permission leak

@login_required
def delete(id):
    post = Post.query.get_or_404(id)
    db.session.delete(post)
    db.session.commit()
Any user can delete any post
Reveal fix

Add ownership check: if post.author_id != current_user.id: abort(403).

로그인만 확인하지 말고 작성자 일치도 확인

SLOT 12
🐛 Debugactivity

Find the bug — foreign key

class Post(db.Model):
    author_id = db.Column(db.Integer)  # no FK
post.author_id = 9999 saves fine — but no User 9999 exists
Reveal fix

Declare the FK: db.ForeignKey("user.id"). DB will reject orphans.

ForeignKey 선언 안 하면 잘못된 ID 막지 못함
