SLOT 9
⚠️ Watch out

Returning the raw object

✗ broken 
return post  # dict

TypeError — Flask needs a Response.

✓ fixed 
return jsonify(post)

jsonify wraps dict + sets headers.

SLOT 11
🐛 Debugactivity

Find the bug — can't serialize

from datetime import date
post = {"title": "Hi", "date": date.today()}
return jsonify(post)
TypeError: Object of type date is not JSON serializable
Reveal fix

Convert to string first: "date": date.today().isoformat().

날짜는 문자열로 바꿔야 JSON 가능

SLOT 12
🐛 Debugactivity

Find the bug — ID mismatch

@app.route("/api/posts/<id>")  # no int:
def one_post(id):
    return jsonify(posts[id])
TypeError: list indices must be int, not str
Reveal fix

Convert <int:id> in route, or int(id) inside.

URL 파라미터는 문자열 — 정수 변환 필요
