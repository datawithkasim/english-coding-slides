SLOT 9
⚠️ Watch out

Verb in the URL

✗ broken 
POST /addSong
GET  /deleteSong/5

Action twice — verb + URL clash.

✓ fixed 
POST   /songs
DELETE /songs/5

URL = noun. Verb = HTTP method.

SLOT 10
🐛 Debugactivity

Find the bug — wrong status

@app.route("/songs", methods=["POST"])
def add_song():
    songs.append(request.get_json())
    return jsonify(songs), 200
Frontend logs "OK" — but it was a create, not a fetch
Reveal fix

A new resource was created → return 201, not 200.

생성은 201, 조회 성공은 200

SLOT 11
🐛 Debugactivity

Find the bug — route conflict

@app.route("/songs/<int:id>")
def song_detail(id): ...

@app.route("/songs/<int:id>")
def song_again(id): ...
AssertionError: View function mapping is overwriting
Reveal fix

Two functions, same URL + method = clash. Rename one route or split by HTTP method.

같은 경로 두 번 등록하면 충돌

SLOT 12
🐛 Debugactivity

Find the bug — missing JSON

def add_song():
    data = request.get_json()
    title = data["title"]
TypeError: 'NoneType' object is not subscriptable
Reveal fix

Client sent no JSON or wrong header. Guard: if not data: return "Bad request", 400. Set header Content-Type: application/json.

JSON 헤더 빠지면 None 반환
