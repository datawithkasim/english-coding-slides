Find the bug — wrong target

X = df[["score"]]

model = LinearRegression().fit(X, y)
Predicts hours from score — we wanted score from hours

Swap: X = df[["hours"]], y = df["score"]. Target is what you predict.

SLOT 11
🐛 Debugactivity

Find the bug — scale gap

X = df[["hours", "income_won"]]
# hours: 0–10, income: 0–10,000,000
income dominates — hours barely matters in some models
Reveal fix

Scale features: StandardScaler().fit_transform(X). Plain linear regression is OK, but matters for many ML algos.
