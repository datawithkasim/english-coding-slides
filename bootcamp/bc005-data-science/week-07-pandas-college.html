SLOT 9
⚠️ Watch out

Bracket types

✗ broken 
df["Major", "Total"]

KeyError — that's a tuple key.

✓ fixed 
df[["Major", "Total"]]

Double brackets = list of columns.

Find the bug — column typo

df = pd.read_csv("majors.csv")

KeyError: 'total'
Reveal fix

Case matters. Real column is "Total". Use df.columns to confirm.

SLOT 11
🐛 Debugactivity

Find the bug — copy warning

cs = df[df.Major == "CS"]
cs["Total"] = cs["Total"] / 1000
SettingWithCopyWarning: A value is trying to be set on a copy
Reveal fix

Take an explicit copy first: cs = df[df.Major == "CS"].copy().

필터링 결과를 수정하려면 .copy() 명시

SLOT 12
🐛 Debugactivity

Find the bug — NaN values

print(df["Median"].mean())
Output: nan
Reveal fix

Missing values poison the math. Drop them: df["Median"].dropna().mean(). Or inspect with df.isna().sum().

NaN 있으면 평균도 NaN — 먼저 처리
