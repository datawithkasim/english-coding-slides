SLOT 10
🐛 Debugactivity

Find the bug — bad contrast

body {
  background: #fffacd;
  color:      #f0e68c;
}
Text is invisible — yellow on yellow
Reveal fix

Pick high-contrast pair: dark text on light bg. Try color:#111;.

글자색과 배경색 차이가 커야 잘 보임

SLOT 11
🐛 Debugactivity

Find the bug — font pile-on

h1 { font-family: Papyrus; }
h2 { font-family: Comic Sans; }
p  { font-family: Impact; }
Page feels chaotic — 3 different fonts
Reveal fix

Use 1 or 2 fonts max. Headings in one, body in another. That's it.

폰트는 1~2개만 — 너무 많으면 어수선함

SLOT 12
🐛 Debugactivity

Find the bug — no whitespace

.card { padding: 0; margin: 0; }
img   { margin: 0; }
h1    { margin: 0; }
Everything smushed together — no breathing room
Reveal fix

Add padding to the card and margin around blocks: padding: 24px; + margin-bottom: 16px;.

여백 없이 붙이면 답답함
