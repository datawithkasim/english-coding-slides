SLOT 9
⚠️ Watch out

Plain-text password

✗ broken 
user.password = form_pw
if user.password == form_pw: ...

DB leak → all passwords exposed.

✓ fixed 
user.password = generate_password_hash(form_pw)
check_password_hash(user.password, form_pw)

Hash one-way — leak is harmless.

Find the bug — plaintext

def signup():
    user = User(email=form.email,
                password=form.password)
    db.session.add(user); db.session.commit()
DB stores password as plain text
Reveal fix

Hash first: password=generate_password_hash(form.password).

DB에 비밀번호 그대로 저장 금지 — 반드시 해시

SLOT 11
🐛 Debugactivity

Find the bug — session

app = Flask(__name__)
login_manager = LoginManager(app)

# app.secret_key never set
session["user"] = 7
RuntimeError: secret key not set
Reveal fix

Set app.secret_key = os.environ["SECRET_KEY"]. Sessions need a key to sign cookies.

세션 사용하려면 secret_key 설정 필수

SLOT 12
🐛 Debugactivity

Find the bug — logout

@app.route("/logout")
def logout():
    return redirect("/")
User still appears logged in
Reveal fix

Call logout_user() before the redirect. Otherwise the session keeps the cookie.

logout_user() 호출해야 세션 종료
