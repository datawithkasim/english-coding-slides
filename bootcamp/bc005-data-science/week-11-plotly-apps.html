SLOT 6
Run it

One scatter chart

import plotly.express as px
import pandas as pd

df = pd.read_csv("apps.csv")
df["price"] = df["price"].astype("float")

fig = px.scatter(df,
    x="size_mb", y="rating",
    color="category",
    hover_name="app",
    title="App Store: size vs rating")
fig.show()
▸ Browser opens
Dots colored by category, hover reveals app name

SLOT 9
⚠️ Watch out

Numbers as strings

✗ broken 
df["price"] = df["price"]\
    .str.replace("$", "")
fig = px.scatter(df, x="price", y="rating")

x-axis sorts "10" < "2" — string order.

✓ fixed 
df["price"] = df["price"]\
    .str.replace("$", "").astype("float")

Cast to number after cleaning.

SLOT 10
🐛 Debugactivity

Find the bug — wrong dtype

print(df["downloads"].dtype)  # object
fig = px.scatter(df, x="downloads", y="rating")
Axis sorted as strings: "1,000,000" < "999"
Reveal fix

Clean commas, convert to int: df["downloads"] = df["downloads"].str.replace(",","").astype(int).
