SLOT 10
🐛 Debugactivity

Find the bug — shape mismatch

a = np.array([[1, 2, 3]])     # (1,3)
b = np.array([[4], [5]])      # (2,1)
c = a + b                          # OK
d = a + np.array([[7, 8]])   # bad
ValueError: operands could not be broadcast (1,3) (1,2)
Reveal fix

Sizes must match or be 1. (1,3) + (1,2) doesn't fit. Reshape or fix data.

broadcast 규칙: 모양이 맞거나 1이어야 함

SLOT 11
🐛 Debugactivity

Find the bug — wrong axis

scores = np.array([[90, 80],
                   [85, 95]])
# average per student (row)
print(scores.mean(axis=0))
Got per-column average, not per-student
Reveal fix

Per row = axis=1. Memory hook: axis=0 collapses rows ↓.

행마다 = axis=1, 열마다 = axis=0

SLOT 12
🐛 Debugactivity

Find the bug — overflow

a = np.array([200], dtype="int8")
print(a + a)
Output: [-112] — overflowed int8 (max 127)
Reveal fix

Use a bigger dtype: dtype="int32" or default int. int8 wraps around.

int8 범위 -128~127 — 더 큰 dtype 사용
