SLOT 6
Run it

Add one book row

import requests, os
url   = "https://api.sheety.co/abc/myBooks/books"
token = os.getenv("SHEETY_TOKEN")
headers = {"Authorization": f"Bearer {token}"}
body  = {"book": {
    "title": "Charlotte's Web",
    "pages": 192,
    "finished": "yes",
}}
r = requests.post(url, json=body, headers=headers)
print(r.status_code)
▸ Output
200 — row added!

SLOT 11
🐛 Debugactivity

JSON shape wrong

body = ["Charlotte", 192]
r = requests.post(url, json=body, headers=headers)
400 — expected object, got list
Reveal fix

Sheety wants a dict with column names: {"book": {"title":..., "pages":...}}.

JSON 구조 확인 — 리스트 말고 dict
