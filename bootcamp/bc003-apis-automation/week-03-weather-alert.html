SLOT 6
Run it

Print a warning

import requests, os
key  = os.getenv("OWM_KEY")
url  = "https://api.openweathermap.org/data/2.5/weather"
data = requests.get(url, params={"q":"Seoul", "appid":key}).json()
main = data["weather"][0]["main"]
if main in ["Rain", "Snow"]:
    print(f"⚠️ {main} in Seoul — bring umbrella")
▸ Output (rainy day)
⚠️ Rain in Seoul — bring umbrella

SLOT 9
⚠️ Watch out

Don't paste the key

✗ broken 
key = "abc123-MYSECRET"

Key in code = leaked on GitHub.

✓ fixed 
key = os.getenv("OWM_KEY")

Reads from .env, never committed.

SLOT 10
🐛 Debugactivity

Key pasted in code

key = "a1b2c3-real-secret-key"
url = f"…&appid={key}"
Risk: anyone who reads the file gets your key
Reveal fix

Move key to .env. Add .env to .gitignore. Use os.getenv("OWM_KEY").

키는 코드에 직접 쓰지 말기 — .env 사용

SLOT 11
🐛 Debugactivity

401 Unauthorized

r = requests.get(url, params={"q":"Seoul"})
print(r.status_code)
Status: 401 — key missing or wrong
Reveal fix

Add "appid": key to params. Check the key string is correct.
