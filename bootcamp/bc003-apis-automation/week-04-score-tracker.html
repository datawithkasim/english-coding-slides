SLOT 6
Run it

Last match alert

import requests, os
key = os.getenv("SPORTS_KEY")
url = "https://api.football-data.org/v4/teams/73/matches"
data = requests.get(url, headers={"X-Auth-Token":key}).json()

for m in data["matches"][-3:]:
    home, away = m["homeTeam"]["name"], m["awayTeam"]["name"]
    score = m["score"]["fullTime"]
    print(f"{home} {score['home']}-{score['away']} {away}")
▸ Output
Tottenham 2-1 Chelsea

SLOT 9
⚠️ Watch out

Too many requests

✗ broken 
while True:
    requests.get(url)

429 — rate limit hit.

✓ fixed 
import time
while True:
    requests.get(url)
    time.sleep(60)

Wait between calls.

SLOT 10
🐛 Debugactivity

Rate limit hit

for i in range(200):
    r = requests.get(url)
    print(r.status_code)
Status: 429 — Too Many Requests
Reveal fix

Add time.sleep(6) in the loop. Cache results so you don't refetch.

429 = 너무 많이 요청 — sleep로 천천히
