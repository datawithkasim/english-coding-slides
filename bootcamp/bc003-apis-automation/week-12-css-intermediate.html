SLOT 9
⚠️ Watch out

!important misuse

✗ broken 
p { color: red !important; }
p.special { color: blue; }

special class can't win.

✓ fixed 
p { color: red; }
p.special { color: blue; }

Let specificity work.

SLOT 10
🐛 Debugactivity

Margin collapse

.a { margin-bottom: 30px; }
.b { margin-top:    20px; }
Gap is 30px, not 50
Reveal fix

Vertical margins collapse — the bigger one wins. Use padding or a wrapper if you need the full sum.

위아래 margin은 합쳐짐 — 큰 값만 적용

SLOT 11
🐛 Debugactivity

Padding moved layout wrong

.box {
  width: 100px;
  padding: 30px;
}
Box is wider than expected — layout breaks
Reveal fix

Add box-sizing: border-box to include padding in width.

padding이 박스 너비 늘림 — box-sizing 설정

SLOT 12
🐛 Debugactivity

!important everywhere

h1 { color: red !important; }
.title { color: blue !important; }
.special { color: green !important; }
Can't predict which wins — fight
Reveal fix

Remove !important. Use specificity: h1.special beats h1.

!important 남용 금지 — 우선순위로 해결
