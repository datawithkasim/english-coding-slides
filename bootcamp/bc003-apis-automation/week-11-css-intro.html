SLOT 9
⚠️ Watch out

Missing semicolons

✗ broken 
h1 {
  color: red
  font-size: 32px;
}

Size ignored — first rule fails.

✓ fixed 
h1 {
  color: red;
  font-size: 32px;
}

End each line.

SLOT 10
🐛 Debugactivity

Missing semicolon

p {
  color: blue
  font-weight: bold;
}
Bold not applied — color rule "eats" the next line
Reveal fix

Add ; after each value.
