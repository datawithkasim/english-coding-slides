SLOT 6
Run it

One trivia round

import requests, html
url  = "https://opentdb.com/api.php?amount=5"
data = requests.get(url).json()
score = 0
for q in data["results"]:
    text = html.unescape(q["question"])
    ans  = input(text + " ")
    if ans == q["correct_answer"]:
        score += 1
print(f"Score: {score}/5")
▸ Output
Score: 3/5
