SLOT 9
⚠️ Watch out

NoneType on missing tag

✗ broken 
title = soup.find("h2").text

AttributeError if no h2.

✓ fixed 
tag = soup.find("h2")
if tag: print(tag.text)

Check before use.

SLOT 11
🐛 Debugactivity

Attribute is None

a = soup.find("a")
print(a["href"])
KeyError or NoneType — no href
Reveal fix

Use a.get("href") — returns None instead of crashing.

없을 수도 있으면 .get() 사용

SLOT 12
🐛 Debugactivity

Bad HTML breaks parse

html = "<ul><li>A<li>B</ul>"
soup = BeautifulSoup(html, "html.parser")
Items merge / nest weirdly
Reveal fix

Use "lxml" parser (install lxml) — more forgiving.

파서를 lxml로 바꾸면 더 잘 동작

2 fast questions

1. To get ALL matches use…

Nope — that's first only.
B. .find_all() / .select()
✓ Returns a list.

A. tag["href"]
Crashes if missing.
B. tag.get("href")
✓ Returns None if missing.
