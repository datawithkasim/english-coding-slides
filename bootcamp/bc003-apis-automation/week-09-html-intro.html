SLOT 11
🐛 Debugactivity

Uppercase tag (not wrong, but weird)

<H1>Hi</H1>
Works but is non-standard; tools complain
Reveal fix

Use lowercase: <h1>Hi</h1>. Matches every guide.

HTML 태그는 소문자가 표준

SLOT 12
🐛 Debugactivity

Wrong nesting

<p><h1>Hi</p></h1>
Crossed tags — browser auto-fixes wrong
Reveal fix

Close in reverse order: open <p><h1>…</h1></p>. Or don't nest h1 in p.

중첩 순서: 마지막에 연 것부터 닫기
