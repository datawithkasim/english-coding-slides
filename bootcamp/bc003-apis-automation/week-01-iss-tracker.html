SLOT 6
Run it

Get ISS lat + lon

import requests
url  = "https://api.open-notify.org/iss-now.json"
data = requests.get(url).json()

lat = data["iss_position"]["latitude"]
lon = data["iss_position"]["longitude"]
print(f"ISS: {lat}, {lon}")
▸ Output
ISS: -23.41, 142.07

SLOT 9
⚠️ Watch out

Forgot .json()

✗ broken 
data = requests.get(url)
print(data["iss_position"])

TypeError — Response not dict.

✓ fixed 
data = requests.get(url).json()
print(data["iss_position"])

.json() turns body into dict.
