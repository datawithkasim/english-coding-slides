SLOT 10
🐛 Debugactivity

Tiny on phone

<head>
  <title>My Site</title>
</head>
Site looks zoomed-out on phone — letters too small
Reveal fix

Add <meta name="viewport" content="width=device-width,initial-scale=1"> in head.

모바일에서 정상 크기로 보이려면 viewport meta 필수

SLOT 11
🐛 Debugactivity

Broken image

<img src="C:/me.png">
Image shows broken-link icon
Reveal fix

Use a relative path: put the file next to the html. src="me.png" or src="img/me.png".

이미지 경로는 절대 경로 X — 상대 경로 사용

SLOT 12
🐛 Debugactivity

Image spills off phone

img { width: 800px; }
Photo wider than the screen on mobile
Reveal fix

Use max-width: 100% and height: auto. Image shrinks to fit.

반응형: max-width: 100%로 화면에 맞게 줄어들게
