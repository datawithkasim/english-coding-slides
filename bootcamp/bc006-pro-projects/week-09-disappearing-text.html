SLOT 6
Run it

Tkinter writer

import tkinter as tk, time

root = tk.Tk()
text = tk.Text(root)
text.pack()

last = time.time()
def on_key(e):
    global last
    last = time.time()

def check():
    if time.time() - last > 5:
        text.delete("1.0", "end")
    root.after(500, check)

text.bind("<Key>", on_key)
check()
root.mainloop()

SLOT 9
⚠️ Watch out

Missing global

✗ broken 
def on_key(e):
    last = time.time()

Creates local var — outer last never updates

✓ fixed 
def on_key(e):
    global last
    last = time.time()

Now updates outer var.

SLOT 10
🐛 Debugactivity

Double timers

def restart():
    check()  # schedules a new check loop
    check()
Two check loops run — text wipes 2x faster, app stutters
Reveal fix

Save the id and cancel before restarting: root.after_cancel(timer_id).

after를 다시 시작하기 전에 after_cancel

SLOT 11
🐛 Debugactivity

Wipes too fast

if time.time() - last > 0.5:
    text.delete("1.0", "end")
Half a second between words = wipe. Kid can't write!
Reveal fix

Raise threshold to 5 seconds: > 5. Match the spec.

기준 시간을 5초로 (0.5초는 너무 짧음)

SLOT 12
🐛 Debugactivity

Keys don't register

root.bind("<Key>", on_key)
Bound to root, but Text widget steals focus → on_key never fires
Reveal fix

Bind on the Text widget itself: text.bind("<Key>", on_key).

bind는 포커스 있는 위젯에 — Text에 직접 bind
