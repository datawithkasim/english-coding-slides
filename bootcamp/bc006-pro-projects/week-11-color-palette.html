SLOT 6
Run it

Top 5 colors

from PIL import Image
from collections import Counter

img = Image.open("photo.jpg").convert("RGB")
img = img.resize((100, 100))

pixels = list(img.getdata())
top5   = Counter(pixels).most_common(5)

for color, count in top5:
    print(color, count)

SLOT 10
🐛 Debugactivity

Hangs forever

img = Image.open("4k_photo.jpg")
pixels = list(img.getdata())  # 8M pixels
Counter loops 8 million tuples — slow + memory heavy
Reveal fix

Resize first: img.resize((100,100)). Sample is enough for palette.

큰 이미지는 100×100으로 축소 후 분석

Ugly print

Reveal fix

디자이너용으로 hex (#ff5733) 변환

SLOT 12
🐛 Debugactivity

Empty palette

n   = int(input("How many? "))
top = Counter(pixels).most_common(n)
User types 0 → empty list, blank output
Reveal fix

Clamp the value: n = max(1, min(n, 10)). Always 1–10 colors.

입력값 범위 제한 (1~10)
