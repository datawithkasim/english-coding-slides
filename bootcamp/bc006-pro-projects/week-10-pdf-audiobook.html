SLOT 6
Run it

Read book aloud

import pyttsx3
from PyPDF2 import PdfReader

pdf = PdfReader("my_notes.pdf")
text = ""
for page in pdf.pages:
    text += page.extract_text() or ""

engine = pyttsx3.init()
engine.say(text[:500])
engine.runAndWait()

🐛 Debugactivity

Silent output

pdf = PdfReader("scan.pdf")
text = "".join(p.extract_text() or ""
              for p in pdf.pages)
print(len(text))
Prints 0 — engine has nothing to say
Reveal fix

PDF is scanned images, not text. Use OCR (pytesseract) or pick a text-PDF.

🐛 Debugactivity

No sound

engine = pyttsx3.init()
engine.say("hi")
# no runAndWait
Function ends, voice never plays
Reveal fix

Always call engine.runAndWait() after say(). It blocks until done.
