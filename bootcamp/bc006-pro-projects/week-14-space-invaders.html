SLOT 6
Run it

Spawn invader wave

import turtle
invaders = []

for col in range(8):
    inv = turtle.Turtle("square")
    inv.color("green")
    inv.penup()
    inv.goto(col*50 - 200, 200)
    invaders.append(inv)

dx = 3
while True:
    for inv in invaders:
        inv.setx(inv.xcor() + dx)

⚠️ Watch out

Modify-while-iterating

✗ broken 
for i in invaders:
    if hit(i):
        invaders.remove(i)

Skips items, weird behavior

✓ fixed 
for i in invaders[:]:
    if hit(i):
        invaders.remove(i)

Iterate a copy.
