SLOT 6
Run it

Mini timer

import time
target = "the quick brown fox"

input("Press Enter to start")
start = time.time()

typed = input("Type it: ")
elapsed = time.time() - start

words = len(typed.split())
wpm   = words / (elapsed / 60)
print(f"{wpm:.0f} WPM")

SLOT 9
⚠️ Watch out

Divide by zero

✗ broken 
wpm = words / 0

ZeroDivisionError if test instant

✓ fixed 
mins = max(elapsed/60, 0.01)
wpm  = words / mins

Floor the divisor.

🐛 Debugactivity

Timer never stops

def update():
    label.config(text=str(time.time()))
    root.after(100, update)
Even after submit, label keeps counting forever
Reveal fix

Store the after() id and call root.after_cancel(timer_id) on submit.

SLOT 12
🐛 Debugactivity

Counts double

typed = "hi !!!"
words = len(typed.split())
"!!!" counts as a word — gives 2 instead of 1
Reveal fix

Filter punctuation-only tokens: [w for w in typed.split() if w.isalnum()].
