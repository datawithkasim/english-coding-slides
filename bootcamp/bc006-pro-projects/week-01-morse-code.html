SLOT 9
⚠️ Watch out

Lowercase breaks lookup

✗ broken 
text = input("? ")
out  = MORSE[text[0]]

KeyError on "s" — dict has "S"

✓ fixed 
text = input("? ").upper()

Normalize first, then look up.

SLOT 10
🐛 Debugactivity

Punctuation crash

text = "HI!"
out  = " ".join(MORSE[c] for c in text)
KeyError: '!'
Reveal fix

Use .get(c, "") to skip unknown letters, or filter: if c in MORSE.

dict에 없는 키는 .get() 또는 if c in 으로 걸러야 함
