SLOT 6
Run it

Add + list

todos = []

@app.route("/", methods=["GET","POST"])
def home():
    if request.method == "POST":
        task = request.form["task"]
        todos.append(task)
        return redirect("/")
    return render_template("index.html",
                           todos=todos)

Accidental delete

<a href="/delete/0">X</a>
