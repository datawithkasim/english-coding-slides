SLOT 6
Run it

Ball + paddle bounce

import turtle
screen = turtle.Screen()
ball   = turtle.Turtle("circle")
dx, dy = 3, 3

while True:
    screen.update()
    ball.setx(ball.xcor()+dx)
    ball.sety(ball.ycor()+dy)
    if abs(ball.xcor()) > 290: dx = -dx
    if abs(ball.ycor()) > 290: dy = -dy

Ball through brick

if ball.distance(brick) == 0:
    brick.hideturtle()
Ball passes through — distance rarely exactly 0
Reveal fix

Use a radius: if ball.distance(brick) < 25:. 25 ≈ ball + brick half-size.

distance == 0 대신 < 25 (반지름 합)으로 충돌 감지
