SLOT 10
🐛 Debugactivity

Empty list

@app.route("/cafes")
def cafes():
    rows = Cafe.query.all()
    return render_template("cafes.html",
                           cafes=rows)
Page loads, but shows zero cafes
Reveal fix

DB is empty. Add a seed: db.session.add(Cafe(name="Toz")), then db.session.commit().

DB가 비어있음 — seed 데이터 추가 후 commit

SLOT 11
🐛 Debugactivity

Form lets blanks through

name = request.form["name"]
db.session.add(Cafe(name=name))
User submits empty name — saved as ""
Reveal fix

Validate before save: if not name.strip(): return "Name required", 400.

저장 전 빈 값 체크 (.strip()로 공백만도 차단)

SLOT 12
🐛 Debugactivity

Crash on deploy

app.run(debug=True)
Host says: gunicorn missing PORT env var
Reveal fix

Don't call app.run() in production. Use a Procfile: web: gunicorn app:app.

배포: app.run() 대신 gunicorn 사용 (Procfile)
