SLOT 11
🐛 Debugactivity

Return too early

def sum_list(nums):
    total = 0
    for n in nums:
        total += n
        return total
sum_list([1,2,3,4]) → 1 (not 10)
Reveal fix

Move return total OUT of the loop. Otherwise it exits after the first number.

return이 for 안에 있으면 한 번만 돌고 끝남

SLOT 15
Quick checkactivity

2 fast questions

1. return does what?
A. Prints a value
Nope — that's print.
B. Sends a value back to the caller
✓ Yes — it's the function's output.
C. Ends the program
Nope — just exits the function.
2. A function with no return gives back…
A. 0
Nope.
B. None
✓ Always None.
