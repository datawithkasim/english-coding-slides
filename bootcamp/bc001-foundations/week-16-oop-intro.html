SLOT 6
Run it

Use the Quiz Bot

from quiz import QuizBrain

bot = QuizBrain()

while bot.has_more():
    q = bot.next_question()
    ans = input(f"{q} (y/n) ")
    bot.check_answer(ans)

print(f"Score: {bot.score}")
▸ End of quiz
Score: 3

SLOT 9
⚠️ Watch out

Class vs object

✗ broken 
QuizBrain.next_question()

Calls method on the blueprint — error.

✓ fixed 
bot = QuizBrain()
bot.next_question()

Build the object, then call.

SLOT 10
🐛 Debugactivity

Forgot the parentheses

bot = QuizBrain
print(bot.score)
AttributeError: type object 'QuizBrain' has no attribute 'score'
Reveal fix

Add () to instantiate: bot = QuizBrain().

() 없으면 객체가 안 만들어짐 — 그냥 클래스 자체

SLOT 11
🐛 Debugactivity

Method on the class, not the instance

bot = QuizBrain()
QuizBrain.check_answer("y")
TypeError: missing 1 required positional argument: 'self'
Reveal fix

Call on the instance: bot.check_answer("y").

메서드는 객체에서 호출 — 클래스 직접 호출 X

SLOT 12
🐛 Debugactivity

Attribute typo

bot = QuizBrain()

Spell it right: bot.score. Python is strict on attribute names.
