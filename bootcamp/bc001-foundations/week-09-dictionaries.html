SLOT 9
⚠️ Watch out

List vs dict access

✗ broken 
bids = {"Min": 10000}
print(bids[0])

→ KeyError: 0

✓ fixed 
bids = {"Min": 10000}
print(bids["Min"])

→ 10000

SLOT 10
🐛 Debugactivity

Find the bug — missing key

bids = {"Min": 10000}
print(bids["Tae"])
KeyError: 'Tae'
Reveal fix

Add the key first, or use bids.get("Tae", 0) for a safe default.

없는 키는 KeyError — get()으로 기본값 반환 가능

Find the bug — overwriting

bids["Min"] = 5000

print(bids["Min"])

Reveal fix

Same key overwrites. To keep many bids per person, store a list as the value.
