SLOT 9
⚠️ Watch out

String math is not math

✗ broken 
a = input("Num? ")
b = input("Num? ")
print(a + b)

Inputs 5, 3 → "53"

✓ fixed 
a = int(input("Num? "))
b = int(input("Num? "))
print(a + b)

Inputs 5, 3 → 8

SLOT 10
🐛 Debugactivity

Forgot to cast

bill   = input("Bill? ")
people = int(input("People? "))
each   = bill / people
TypeError: unsupported operand type(s) for /: 'str' and 'int'
Reveal fix

Wrap bill: float(input(...)). Can't divide a string.

input은 항상 문자열 — 숫자로 쓰려면 float() 또는 int()

SLOT 11
🐛 Debugactivity

Whole vs fraction division

total  = 10
people = 3
print(total / people)
Output: 3.3333333333333335 (not whole)
Reveal fix

For a whole number, use // (floor div) or round().

/ 는 실수 나눗셈, // 는 몫만 (정수)

SLOT 12
🐛 Debugactivity

Ugly long decimal

each = 48000 / 7
print(f"Each: {each}")
Output: Each: 6857.142857142857
Reveal fix

Format inside f-string: {each:.0f} (0 decimals) or {each:.2f} (2 decimals).

f-string 안에 :.0f 붙이면 소수점 자릿수 조절
