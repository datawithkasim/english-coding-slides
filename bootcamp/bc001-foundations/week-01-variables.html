SLOT 10
🐛 Debugactivity

Find the bug — typo

city = input("City? ")
pet  = input("Pet? ")
print(cityy + " " + pet)
NameError: cityy is not defined
Reveal fix

Line 3 has cityy (two y's). Variable was named city. Delete one y.

SLOT 11
🐛 Debugactivity

Find the bug — missing quotes

print(greeting)
NameError: Hello is not defined
Reveal fix

Strings need quotes. Hello → "Hello".

문자열은 따옴표 안에 — 안 그러면 변수로 읽음

SLOT 12
🐛 Debugactivity

Find the bug — wrong type

age  = 12
name = "Kasim"
print(name + " is " + age)
TypeError: can only concatenate str to str
Reveal fix

Wrap the number: str(age). Or use f-string: f"{name} is {age}".

숫자는 문자열과 직접 더할 수 없음 — str()로 변환

SLOT 15
Quick checkactivity

3 fast questions

1. Which line stores text in a box named x?
A. x == "hi"
Nope — that's comparison.
B. x = "hi"
✓ Single = assigns.
C. "hi" = x
Nope — name goes on the left.
2. What does input("Name? ") return?
A. A number
Nope.
B. A string (what the user types)
✓ Always a string.
