SLOT 9
⚠️ Watch out

Shadow trap

✗ broken 
total = 10

def show():
    total = total + 1
    print(total)

UnboundLocalError

✓ fixed 
total = 10

def show():
    global total
    total = total + 1

Works — explicit global.

SLOT 10
🐛 Debugactivity

Outer didn't change

lives = 3

def lose():
    lives = lives - 1

lose()
print(lives)
UnboundLocalError: local variable 'lives' referenced before assignment
Reveal fix

Add global lives as the first line inside lose().

SLOT 11
🐛 Debugactivity

Shadowed name

name = "Mina"

def greet():
    name = "Kasim"

greet()
print(name)
Output: Mina (expected Kasim)
Reveal fix

Either declare global name or return the new value and reassign.

SLOT 12
🐛 Debugactivity

Used name that doesn't exist out here

def make():
    secret = 42

make()
print(secret)
NameError: name 'secret' is not defined
Reveal fix

Return it: return secret, then secret = make().
