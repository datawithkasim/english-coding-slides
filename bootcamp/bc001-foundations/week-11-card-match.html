🐛 Debugactivity

Same cards every game

deck = [2,3,4,5,6,7,8,9,10]

computer = deck[1]

Reveal fix

Use random.choice(deck) — or random.shuffle(deck) first.

SLOT 11
🐛 Debugactivity

Tie at 21 mishandled

if player == 21:
    print("player wins")
elif computer == 21:
    print("computer wins")
Both 21 → prints "player wins" (should be draw)

동시 21은 무승부 — 동률 먼저 검사
