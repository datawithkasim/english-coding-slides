Run it

One order

menu = {
    "mango":      5000,
    "strawberry": 6000,
    "milk":       4000,
}
flavor = input("Flavor? ")
coins  = int(input("Coins? "))
price  = menu[flavor]

if coins >= price:
    change = coins - price
    print(f"Enjoy! Change: {change}")
else:
    print(f"Need {price - coins} more")
▸ Inputs: mango, 6000
Enjoy! Change: 1000
