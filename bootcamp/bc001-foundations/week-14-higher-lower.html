SLOT 6

One round

import random
data = [
    {"name": "Pinkfong",   "subs": 75},
    {"name": "Cocomong",   "subs": 12},
    {"name": "JFlaMusic",  "subs": 18},
]
a, b = random.sample(data, 2)
guess = input(f"{a['name']} or {b['name']}? ")
winner = a if a["subs"] > b["subs"] else b
print("Right!" if guess == winner["name"] else "Wrong.")

Pinkfong vs Cocomong → Pinkfong

🐛 Debugactivity

Score not reset on replay

score = 0
while True:
    play_round()
    again = input("Replay? ")
    if again != "y": break
Score keeps growing across replays — never resets
Reveal fix

Move score = 0 INSIDE the while loop, or reset before the next game.

SLOT 11
🐛 Debugactivity

Off-by-one in rounds

score = 0
for r in range(1, 5):
    print(f"Round {r} of 5")
Only 4 rounds run (1, 2, 3, 4) — missing round 5
Reveal fix

range(1, 5) stops at 4. Use range(1, 6) for 5 rounds.

range는 끝값 미포함 — +1 해줘야 함
