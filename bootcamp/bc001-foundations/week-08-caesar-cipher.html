SLOT 10
🐛 Debugactivity

Find the bug — past 'z'

def shift(c, n):
    return chr(ord(c) + n)

print(shift("y", 5))
Output: '~' (past 'z', not a letter)
Reveal fix

Wrap with modulo: (ord(c) - ord("a") + n) % 26 + ord("a").

z 넘어가면 a로 — % 26 로 순환

SLOT 11
🐛 Debugactivity

Find the bug — uppercase ignored

def encrypt(text, n):
    out = ""
    for c in text:
        out += chr(ord(c) + n)
    return out

print(encrypt("Hi", 1))
Output: "Ij" — but "I" should stay as letter
Reveal fix

Lowercase first: text = text.lower(). Or handle upper case separately.

대문자 처리 — 보통 lower() 먼저
