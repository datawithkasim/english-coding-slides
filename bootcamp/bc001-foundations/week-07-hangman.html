SLOT 6
Run it

One guess loop

import random
words = ["bts", "tiger", "kimchi"]
word = random.choice(words)
guessed = []
lives = 5

while lives > 0:
    g = input("Letter? ").lower()
    if g in word:
        guessed.append(g)
    else:
        lives = lives - 1

SLOT 9
⚠️ Watch out

Case sensitivity

✗ broken 
word = "cat"
g = input("? ")
if g in word: ...

User types "C" → not found

✓ fixed 
word = "cat"
g = input("? ").lower()
if g in word: ...

Always lowercase first

SLOT 10
🐛 Debugactivity

Find the bug — case mismatch

word = "Tiger"
g = input("? ")
if g in word:
    print("hit")
User types "t" → no hit, even though word starts with T
Reveal fix

Lowercase both sides: word.lower() and g.lower().
