SLOT 6
Run it

Make a 6-char password

import random
chars = ["a", "B", "7", "!", "k", "9"]
pw = ""
for i in range(6):
    pw = pw + random.choice(chars)
print(pw)
▸ One run
B7!ka9

SLOT 9
⚠️ Watch out

Body not indented

✗ broken 
for i in range(3):
print(i)

→ IndentationError

✓ fixed 
for i in range(3):
    print(i)

→ prints 0, 1, 2

SLOT 10
🐛 Debugactivity

Find the bug — wrong count

for i in range(1, 5):
    print("step", i)
Output: step 1, step 2, step 3, step 4 (only 4 steps, not 5)
Reveal fix

range(1, 5) stops before 5. For 1–5, use range(1, 6).

range는 끝 숫자 미포함 — 5까지면 range(1, 6)

SLOT 11
🐛 Debugactivity

Find the bug — body outside loop

pw = ""
for i in range(4):
    x = random.choice(chars)
pw = pw + x

SLOT 12
🐛 Debugactivity

Find the bug — never stops

n = 5
while n > 0:
    print(n)
Infinite loop — keeps printing 5 forever
Reveal fix

Update n inside: n = n - 1. Loop needs progress.

루프 안에서 조건 값을 바꿔야 멈춤
