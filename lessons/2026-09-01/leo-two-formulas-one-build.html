Concept

The hand-over

Right hand takes the answer.

SLOT 14
Reuse or re-create?

Where you put h1 and h2

✓ reuse — kept across turns 
    h1 = 1
    h2 = 1
    for i in range(6):
        y = h1 + h2

y = 2, 3, 5, 8, 13, 21 → a growing skyline.

✗ re-create — fresh every turn 
    for i in range(6):
        h1 = 1
        h2 = 1
        y = h1 + h2

y = 2, 2, 2, 2, 2, 2 → a flat row.

Above the loop = remembers. Inside the loop = forgets.

    x = 2
    spacing = 2
    h1 = 1
    h2 = 1
    for i in range(6):
        y = h1 + h2
        blocks.fill(QUARTZ_BLOCK,
            pos(x, 0, 0),
            pos(x, y, 0), REPLACE)
        x = x + spacing
        h1 = h2
        h2 = y
