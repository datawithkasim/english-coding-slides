The plan

Fall unless you jump 🦘

In the shooter you flew. Here you fall, all the time.

Today's whole idea, two lines:

player["vy"] += GRAVITY
player["y"]  += player["vy"]

Everything else today hangs off those two.

GRAVITY = 0.6 every frame
Concept

On screen, up is negative

y = 0 is the top of the window. y gets bigger going down.

So to move up you subtract. A jump is a negative vy.

You already did this. Your bullets went up with a minus.

y = 0    <- top of window
   |
   |  vy = -12   🡅  jumping
   |  vy =   0   —  hanging
   |  vy = +12   🡇  falling
   v
y = 400  <- ground

화면은 아래로 갈수록 y가 커져요. 위로 = 마이너스

Concept

Gravity = one small add, every frame

vy does not jump to a big number. It grows a little each frame.

frame   vy      y        what you see
  0    -12.0   300.0     shoot up fast
  1    -11.4   288.6     still going up
  2    -10.8   277.8     slower
 ...
 20     +0.0   228.0     top of the arc
 ...
 39    +11.4   300.0     back on the ground

Every frame: add GRAVITY to vy, then add vy to y. That is the whole arc.

한 프레임마다 vy에 조금씩 더해요. 그게 포물선이 돼요.

v4 · it jumpsSTEP 4 / 4

Space to jump

🔍 FIND for event in pygame.event.get(): · 📍 inside that for loop · indent 8

    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE and player["on_ground"]:
                player["vy"] = JUMP_POWER
                player["on_ground"] = False

🟣 JUMP_POWER is -12. Negative sends it up.
🟣 and player["on_ground"] is what stops flying. No key, no double jump.
