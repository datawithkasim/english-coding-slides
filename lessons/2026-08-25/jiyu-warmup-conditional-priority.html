⚠️ Watch out

if if ≠ if elif

Gold ahead — gold is also "not air".

✗ two ifs — both run
if sign_ahead == GOLD_BLOCK:
    agent.turn(LEFT_TURN)
if sign_ahead != AIR:
    agent.turn(RIGHT_TURN)

Two turns. The agent faces backwards.

✓ elif — one winner
if sign_ahead == GOLD_BLOCK:
    agent.turn(LEFT_TURN)
elif sign_ahead != AIR:
    agent.turn(RIGHT_TURN)

One turn. Left wins, right skipped.
