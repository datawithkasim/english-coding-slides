SLOT 9
⚠️ Watch out

The missing semicolon

✗ broken 
nav {
  display: flex
  gap: 24px;
}

No ; → both lines die. Nav stays stacked.

✓ fixed 
nav {
  display: flex;
  gap: 24px;
}

Every CSS line ends with ;

This one caught you on 8/13. Semicolon first, then run.
