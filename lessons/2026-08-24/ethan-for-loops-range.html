EXTRA
Harder 🌶️OPTIONAL

A loop inside a loop

for n in range(2, 10):
    for i in range(1, 10):
        print(n, "x", i, "=", n * i)
    print()
▸ Output starts
2 x 1 = 2 … 2 x 9 = 18
3 x 1 = 3 … 3 x 9 = 27

The inside loop finishes all 9 rows before n changes.
