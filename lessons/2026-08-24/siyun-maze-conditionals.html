SLOT 6b
Run it

Three choices: if · elif · else

while not agent.detect(BLOCK, DOWN):
    if not agent.detect(BLOCK, FORWARD):
        agent.move(FORWARD, 1)
    elif not agent.detect(BLOCK, RIGHT):
        agent.turn(RIGHT_TURN)
    else:
        agent.turn(LEFT_TURN)

The first True branch runs. Python skips the rest.
