SLOT 11
⚠️ Watch out

One indent level short

✗ broken 
while True:
    agent.move(FORWARD, 1)
    block = agent.inspect(...)
if block == GOLD_BLOCK:
    agent.move(UP, 1)

The if sits outside the loop, so it never runs.

✓ fixed 
while True:
    agent.move(FORWARD, 1)
    block = agent.inspect(...)
    if block == GOLD_BLOCK:
        agent.move(UP, 1)

Inside the loop, and the move is inside the if.

SLOT 12
🐛 Debugactivity

Find the bug — never climbs

while True:
    agent.move(FORWARD, 1)
    block = agent.inspect(AgentInspection.BLOCK, DOWN)
    if block == GOLD_BLOCK:
        agent.move(UP, 1)
block is always GRASS. The agent walks straight into the gold wall.
Reveal fix

DOWN looks at the floor. The wall is ahead, so inspect FORWARD.

방향 하나만 틀려도 답이 달라져요

Give the loop a door out:
