SLOT 9
⚠️ Watch out

Turn after you walk

Goal: walk 3 forward, then head right.

✗ broken
agent.turn(RIGHT)
agent.move(FORWARD, 3)

Leaves the path at once.

✓ fixed
agent.move(FORWARD, 3)
agent.turn(RIGHT)

Walks first, then faces right.

SLOT 11
🐛 Debug 2

He walks. No blocks appear.

Goal: a stone path 5 blocks long.

buggy
for i in range(5):
    agent.move(FORWARD, 1)
▸ Show the bug
Placing is off. Nothing tells him to drop a block.
for i in range(5):
    agent.place(DOWN)
    agent.move(FORWARD, 1)

place on means every step leaves a block. Give him stone first: agent.set_item(STONE, 1, 1)

SLOT 12
🐛 Debug 3

Five blocks in one spot

Goal: a path 5 blocks long.

buggy
for i in range(5):
    agent.place(DOWN)
agent.move(FORWARD, 1)
▸ Show the bug
move is not indented, so it runs once at the end.
for i in range(5):
    agent.place(DOWN)
    agent.move(FORWARD, 1)

Indented lines repeat. Flat lines do not.

Code
OPTIONAL

A wall, 5 wide and 3 tall

for row in range(3):
    for i in range(5):
        agent.place(FORWARD)
        agent.move(RIGHT, 1)
    agent.move(UP, 1)
    agent.move(LEFT, 5)
▸ Output
3 rows × 5 blocks = 15 blocks. Two indent levels.
Code
OPTIONAL

One number controls the size

size = 5

    for side in range(4):

        agent.turn(RIGHT)
