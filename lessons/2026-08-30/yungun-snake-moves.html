SLOT 17
Build v4 ⌨️

v4 — the key picks the slot

    snake_pos[0] = snake_pos[0] + 10OLD    snake_pos[1] = snake_pos[1] + 10OLD    keys = pygame.key.get_pressed()NEW    if keys[pygame.K_RIGHT]: snake_pos[0] = snake_pos[0] + 10NEW    if keys[pygame.K_LEFT]:  snake_pos[0] = snake_pos[0] - 10NEW    if keys[pygame.K_DOWN]:  snake_pos[1] = snake_pos[1] + 10NEW    if keys[pygame.K_UP]:    snake_pos[1] = snake_pos[1] - 10NEW

📍 Delete the two OLD lines. Type the five NEW lines in their place. Left and right pick slot 0. Up and down pick slot 1.
