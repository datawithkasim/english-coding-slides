SLOT 7
Watch it!

Peel one layer at a time

>>> print(search)
{'type': 'electric', 'moves': [{...}, {...}, {...}]}
>>> print(search["moves"])
[{...}, {...}, {...}]
>>> print(search["moves"][0])
{'name': 'thunderbolt', 'type': 'electric', 'power': 90}

One more [ ] = one layer deeper.

SLOT 10
Debug 1

The double lookup

search = pokedex[name]
print(pokedex[search]["moves"])
TypeError: unhashable type: 'dict'
▸ Show the fix
search already holds the inner dictionary. Look up once: print(search["moves"])

You hit this last time. Read the variable before you use it.

SLOT 11
Debug 2

The empty loop body

for i in range(3):
print("done")
IndentationError: expected an indented block
▸ Show the fix
A for needs at least one indented line under it. Add print(search["moves"][i]), four spaces in.

Nothing is indented under the for. Write the inside line before you run it.

SLOT 12
Debug 3

Counting past the end

# pikachu has 3 moves
for i in range(4):
    print(search["moves"][i])
IndexError: list index out of range
▸ Show the fix
Indexes are 0 1 2. Use range(3), or safer: range(len(search["moves"]))
Debug 4 OPTIONAL
