SLOT 10
⚠️ Watch out

The window that vanishes

✗ flashes 
screen = pygame.display.set_mode((800,600))

File ends → Python quits → window closes.

✓ stays 
while running:
    pygame.display.flip()

The loop never ends, so the window stays.

SLOT 15
🐛 Debugactivity

Bug 1 — the empty loop

while running:

pygame.display.flip()
IndentationError: expected an indented block
Reveal fix

A loop needs at least one line indented under it. Push flip() in by four spaces.

반복문 안은 비워둘 수 없어요

SLOT 16
🐛 Debugactivity

Bug 2 — the quoted colour

BLACK = (0, 0, 0)

screen.fill("BLACK")
ValueError: invalid color argument
Reveal fix

Quotes mean the five letters B-L-A-C-K. Drop them to reach the variable: screen.fill(BLACK).

따옴표 빼야 변수예요

SLOT 17
🐛 Debugactivity

Bug 3 — the black window

while running:
    screen.fill(BLACK)
    pygame.draw.rect(screen, GREEN, (380, 500, 40, 40))
No crash. No error. The window is empty.
Reveal fix

You painted, but never showed it. Add pygame.display.flip() last, inside the loop.

flip() 해야 보여요

SLOT 18
Build v4 ⏱️

v4 — steady speed

clock = pygame.time.Clock()NEWwhile running:    screen.fill(BLACK)    pygame.draw.rect(screen, GREEN, (380, 500, 40, 40))    pygame.display.flip()    clock.tick(60)NEW

📍 clock = goes above the loop. clock.tick(60) is the last line inside it. Now the loop runs 60 times a second.
