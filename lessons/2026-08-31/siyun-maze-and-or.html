🐛 Debugactivity

Find the bug — wrong order

if agent.detect(BLOCK, FORWARD):
    agent.turn(RIGHT_TURN)
elif agent.detect(BLOCK, FORWARD) and \
     agent.detect(BLOCK, RIGHT):
    agent.turn(LEFT_TURN)
At a dead end the agent still turns right.
Reveal fix

The wide test runs first and swallows the narrow one. Put the and test on top.

if agent.detect(BLOCK, FORWARD) and \
   agent.detect(BLOCK, RIGHT):
    agent.turn(LEFT_TURN)
elif agent.detect(BLOCK, FORWARD):
    agent.turn(RIGHT_TURN)
