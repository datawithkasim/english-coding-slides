SLOT 9
⚠️ Watch out

What goes inside the { }

✗ broken 
print(f"number x i = number * i")

Prints: number x i = number * i 😕

✓ fixed 
print(f"{number} x {i} = {number * i}")

Prints: 7 x 3 = 21 ✓

No braces = plain letters. Braces = the value.

중괄호 없으면 그냥 글자
