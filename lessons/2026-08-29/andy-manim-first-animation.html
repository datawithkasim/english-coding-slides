Setup

Inside app.english-coding.co.uk

  • Type Python in the editor. Press Run.
  • No terminal. No install. No commands.

⚠️ Watch out

Mistake 1 — the missing self.

✗ broken 
        play(Create(circle))

→ NameError: name 'play' is not defined

✓ fixed 
        self.play(Create(circle))

→ the scene plays it

self means this scene. Drop it and Python hunts for a loose play that does not exist.

self 빼먹으면 못 찾아요

⚠️ Watch out

Mistake 2 — flat body

✗ broken 
    def construct(self):
    circle = Circle()

→ IndentationError: expected an indented block after function definition on line 4

✓ fixed 
    def construct(self):
        circle = Circle()

→ 8 spaces, inside the function

JavaScript used { }. Python uses spaces. The spaces are the brackets.

Mistake 3 — shape is not animation

✗ broken 
        self.play(circle)

→ TypeError: ... cannot be converted to an animation

✓ fixed 
        self.play(Create(circle))

→ Create wraps the shape in an animation

Circle() is a thing. Create(circle) is a doing. self.play only takes doings.

Read backOPTIONAL

Your whole file

from manim import *

class FirstScene(Scene):
    def construct(self):
        circle = Circle(color=BLUE, radius=2)
        circle.set_fill(BLUE, opacity=0.5)
        self.play(Create(circle))
        square = Square()
        self.play(Transform(circle, square))
        title = Text("Math Motion")
        self.play(Write(title))
        self.play(title.animate.shift(UP * 3))
        self.play(circle.animate.scale(2))

Five self.play lines = five animations, in order, top to bottom.
