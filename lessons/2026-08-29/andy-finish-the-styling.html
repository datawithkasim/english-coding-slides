STEP 1 / 17

Fix the font

🔍 Find in main.cssfont-family: 'cursive'
OLD
* {
    font-family: 'cursive'
}
NEW
* {
    box-sizing: border-box;
    font-family: "Comic Sans MS", "Segoe UI", cursive;
}
🟣 Quotes turned cursive into a font name. Without quotes it is a keyword the browser understands.
✅ The whole page changes font.
Why it broke

Quotes make a name

✗ broken 
font-family: 'cursive';

→ hunts for a font called "cursive" → never finds it

✓ fixed 
font-family: cursive;

→ a keyword the browser knows

box-sizing: border-box stops padding making boxes wider than you asked.

따옴표를 쓰면 폰트 이름이 돼요

STEP 15 / 17

Bigger checkboxes

📍 main.css — new rule, straight after the input rule
NEW
input[type="checkbox"] {
    width: 20px;
    height: 20px;
    accent-color: #722F37;
    cursor: pointer;
}
🟣 input[type="checkbox"] picks only the checkboxes, not the text boxes. accent-color recolours the tick itself.
✅ Checkboxes get bigger and tick in dark red.
Selector 🔬

Square brackets pick an attribute

input                      /* every box — text AND checkbox */
input[type="checkbox"]     /* only the ticky ones */
input[type="text"]         /* only the typing ones */

Your .content-gen and .plan-for-day boxes are both type="text". They stay small.

대괄호는 속성으로 골라요

STEP 16 / 17

Finally use .done

🔍 Find in scripts.jsstatusText.textContent = "TASKS DONE: " + tasksDone;
OLD

    if (event.target.checked) {

NEW — one new line at the bottom
function updateCount(event) {
    if (event.target.checked) {
        tasksDone = tasksDone + 1;
    } else {
        tasksDone = tasksDone - 1;
    }
    statusText.textContent = "TASKS DONE: " + tasksDone;
    event.target.parentElement.classList.toggle("done", event.target.checked);
};
🟣 .done has been sitting in your CSS since day one with nothing ever wearing it.
✅ Tick a task — the whole card fades to 40%.
Read the line 🔬

What that line says

event.target        /* the checkbox you clicked */
.parentElement      /* the .todo-item card it sits in */
.classList.toggle("done", event.target.checked)

toggle with a true/false second word means: add the class when ticked, remove it when unticked.

.done sat in your CSS since day one with nothing wearing it.
