⚠️ Watch out

Degrees are not radians

✗ broken 
a1 = math.cos(60 * side)

→ Python reads 60 as radians. Corners land anywhere — the hexagon melts.

✓ fixed 
a1 = math.cos(
    math.radians(60 * side))

→ radians() first, then cos. Clean corners.

SLOT 16
Code ▶

The hexagon — slide corner to corner

↓ replace  dx, dy = 0, 0  in your hexagon branch ↓
    radius = 55
    per_side = count // 6
    side = min(i // per_side, 5)
    pos = i % per_side
    t = pos / per_side

    a1 = math.radians(60 * side)
    a2 = math.radians(60 * (side + 1))
    x1 = math.cos(a1) * radius
    y1 = math.sin(a1) * radius
    x2 = math.cos(a2) * radius
    y2 = math.sin(a2) * radius
    dx = x1 + (x2 - x1) * t
    dy = y1 + (y2 - y1) * t

6 corners on a circle, 60° apart — your 120° inside angle, free. t slides ships between corners.
