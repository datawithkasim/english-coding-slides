🚨 When it breaks

The machine names the part

빨간색은 혼내는 게 아니라 어디가 문제인지 알려주는 거예요

debug 1

Why is nothing lit?

def loop(t, sensors):
    return {"on": (tt // 30) % 2 == 0}
error led.py, line 2: name 'tt' is not defined
Reveal fix

The tick counter is called t, with one letter. tt is a name nothing ever made. Delete one t.

이름 오타예요. 만든 적 없는 이름은 쓸 수 없어요

debug 2

No error, but no blink

def loop(t, sensors):
    return {"on": (t // 30) % 2}
result The light stays on the whole time.
Reveal fix

This returns 0 or 1, not True or False. Add == 0 so it becomes a yes-or-no answer.

숫자가 아니라 참/거짓이 필요해요

debug 3

The board flashes on D3

The code is perfect. The LED is in D3.
The tier asked for D2.
error Still to place: LED in D2
Reveal fix

Click the LED that is in D3. It comes back into your hand. Click D2. Not every bug is in the code.

모든 문제가 코드에 있는 건 아니에요

SLOT 9
⚠️ The classic

Seconds are not ticks

✗ broken 
(t // 1) % 2 == 0

→ flips 60 times a second. A blur.

✓ fixed 
(t // 30) % 2 == 0

→ flips twice a second. One full blink.

1초는 60틱이에요. 절반은 30틱

modify 1

Blink twice as fast

return {"on": (t // ___) % 2 == 0}
Reveal

15. Half the ticks means twice the speed.

modify 2

On for a quarter of the time

return {"on": (t % 60) < ___}
Reveal

15. One second is 60 ticks; a quarter of 60 is 15.

Careful: tier 1 wants about half, so this one does not pass it. That is the point of trying it.

SLOT 15
Quick check

Two questions

1. How many ticks is one second?
A. 1
No — that is one tick.
B. 60
Yes. loop runs 60 times a second.
C. 1000
No — that is milliseconds, a different unit.
2. What must loop give back?
A. a number
No — the sim would not know what it means.
B. a dictionary like {"on": True}
Yes. The key says what, the value says how much.
C. nothing
Then the part does nothing at all.

Tier 3 · Raspberry Pi

A number, not a yes-or-no

def loop(t, sensors):
    if t % 30 == 0:
        print(sensors["distance"])
    return {"on": sensors["distance"] < 20}
▸ Output panel
118.0 · 74.5 · 31.0 · 12.5 ← light comes on here

거리는 숫자예요. 참/거짓으로 바꾸려면 비교해야 해요

⚠️ Careful

Do not print every tick

✗ unreadable 
print(sensors["distance"])

→ 60 lines a second. Nobody can read that.

✓ readable 
if t % 30 == 0:
    print(sensors["distance"])

→ twice a second. Comfortable.
