AI Coding — Build apps by talking to AI.
학부모님께: 자녀가 이 과정에서 매주 만나는 핵심 영어 코딩 단어들입니다. 직접 코딩하실 필요는 없습니다 — 단어를 함께 읽어 보시고, 자녀에게 자기 말로 다시 설명해 달라고 해 주세요. 옆의 짧은 예시는 실제 코드에서의 모습입니다.

W1

단어의미간단한 예시
prompt the instruction you give the AI 
"Make a to-do list app"
specificity the more concrete, the better the answer 
"red button, top-right"
scope how much you ask for in one prompt 
one feature at a time

W2

단어의미간단한 예시
context background info the AI needs 
"This is a school app for kids"
constraint a rule the AI must follow 
"Use only Python"
expected output what you want back, said upfront 
"Return a CSV file"

W3

단어의미간단한 예시
few-shot showing examples of what you want 
"Like this: ..."
anchor example one sample answer that sets the pattern 
"Format: Name - Age"
explicit say it plainly — don't make AI guess 
"Always add comments"

W4

단어의미간단한 예시
decomposition breaking one big problem into steps 
1) form 2) save 3) show
milestone a checkpoint you verify before moving on 
"First, just the layout"
scope creep asking for too much in one prompt 
10 features at once ✗

W5

단어의미간단한 예시
iterate improve through repeated small changes 
"Now make it bigger"
refine make a working answer better 
"Same, but blue"
revert go back to a previous working version 
undo last change

W6

단어의미간단한 예시
expected vs actual what should happen vs what does 
"Should add, but it multiplies"
trace the error path the program took 
read the red error text
reproduce make the bug happen on demand 
"Click twice → it crashes"

W7

단어의미간단한 예시
annotate add comments that explain the code 
# this saves the file
explain back describe the code in your own words 
"This loop counts items"
ownership knowing your code well enough to change it 
you can edit it yourself

W8

단어의미간단한 예시
MVP minimum viable product — smallest useful version 
just login + list
ship release something real to real users 
share the live link
retrospective review what worked and what didn't 
what to do better next
