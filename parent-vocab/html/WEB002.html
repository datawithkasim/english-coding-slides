단어의미간단한 예시
console.log print a message to the browser console 
console.log("hi")
script tag <script>…</script> — runs JS in HTML 
<script>alert(1)</script>
statement one instruction ending with a semicolon 
let x = 5;

W2

단어의미간단한 예시
let / const declare a variable (const can't change) 
const name = "Sam";
DOM the tree of elements built from the HTML 
document.body
querySelector find one element by CSS selector 
document.querySelector("#title")
textContent the text inside an element 
el.textContent = "New!"

W3

단어의미간단한 예시
event something that happens (click, keypress) 
"click"
addEventListener run a function when an event fires 
btn.addEventListener("click", go)
callback the function passed in to run later 
setTimeout(go, 1000)

단어의미간단한 예시
input element <input> tag the user types into 
<input id="name">
.value the current text in an input field 
input.value
submit the action of sending a form 
form.addEventListener("submit", ...)

W5

단어의미간단한 예시
if / else if / else a three-way branch on a condition 
if (x > 0) { ... } else { ... }
=== / !== strict equal / strict not equal 
5 === "5"   // false
boolean a value that is either true or false 
let done = true;

W6

단어의미간단한 예시
array an ordered list of values in [ ] 
let nums = [1, 2, 3];
for loop repeat code a fixed number of times 
for (let i=0; i<3; i++) {}
.forEach run a function once per array item 
nums.forEach(n => console.log(n))

W7

단어의미간단한 예시
function a reusable block of code

parameter an input the function expects 
function greet(name) { ... }
return the value the function gives back 
return total;
arrow function short syntax: () => { … } 
const add = (a,b) => a+b;

단어의미간단한 예시
state the data describing what's on screen now

render update the DOM to match the state

event-driven code that reacts to user actions 
on click → update
