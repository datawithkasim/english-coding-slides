학부모님께: 자녀가 이 과정에서 매주 만나는 핵심 영어 코딩 단어들입니다. 직접 코딩하실 필요는 없습니다 — 단어를 함께 읽어 보시고, 자녀에게 자기 말로 다시 설명해 달라고 해 주세요. 옆의 짧은 예시는 실제 코드에서의 모습입니다.

W1

단어의미간단한 예시
tag the angle-bracket label that names an element 
<h1>Title</h1>
element an open tag, its content, and a close tag 
<p>Hello</p>
attribute extra info inside a tag (src, href) 
<img src="cat.png">
nesting putting one element inside another 
<ul><li>Item</li></ul>

W2

단어의미간단한 예시
selector which element the style applies to 
p { color: red; }
property what you're changing (color, font-size) 
color: blue;
value the new setting for the property 
font-size: 20px;
hex code a 6-digit color like #ff7849 
color: #ff7849;

W3

단어의미간단한 예시
padding space INSIDE the box, around content 
padding: 16px;
margin space OUTSIDE the box, between boxes 
margin: 24px;
border the line at the edge of the box 
border: 2px solid black;
box-sizing whether width includes padding or not 
box-sizing: border-box;

W4

단어의미간단한 예시
flex container the parent that arranges children in a row 
display: flex;
justify-content spacing along the main axis 
justify-content: center;
align-items spacing along the cross axis 
align-items: center;
gap space between flex items 
gap: 12px;

W5

단어의미간단한 예시
hero section the big banner at the top of a page 
<section class="hero">
background-image a CSS image set behind an element 
background-image: url(bg.jpg);
alt text description of an image for screen readers 
<img alt="A red car">

W6

단어의미간단한 예시
media query CSS that applies only at certain sizes 
@media (max-width: 600px) { ... }
breakpoint the width where the layout changes 
max-width: 768px
viewport the visible area of the browser window 
<meta name="viewport" ...>

W7

단어의미간단한 예시
:hover style applied when the mouse is over it 
button:hover { color: red; }
transition a smooth change between two states 
transition: 0.3s;
transform move, rotate, or scale an element 
transform: scale(1.1);

W8

단어의미간단한 예시
layout the overall arrangement of sections 
header / main / footer
hierarchy what looks most important to the eye 
<h1> bigger than <p>
